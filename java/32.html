第 1 节 · P32

字符串相加：遇到字符串就拼接

规则："+"操作中出现字符串时，这个 + 就是字符串连接符，而不是算术运算符了。它会把前后的数据拼接起来，产生一个新的字符串。

  • "123" + 123 是 246 还是 "123123"？是 "123123"：有字符串参与，做的是拼接。有没有觉得像贪吃蛇？
  • 连续加的时候，从左到右逐个执行。1 + 99 + "年黑马"：先算 1 + 99，没有字符串，就是普通加法得 100；再和 "年黑马" 拼接，结果 "100年黑马"，不是 "199年黑马"。

五个小练习，能说出理由，字符串相加就没问题了：

表达式结果理由
3.7 + "abc""3.7abc"有字符串，拼接
"abc" + true"abctrue"有字符串，拼接
'中' + "abc" + true"中abctrue"从左到右：字符和字符串拼成"中abc"，再和 true 拼接
"我的年龄是" + age + "岁"
"我的年龄是" + "age" + "岁"		"我的年龄是18岁"
"我的年龄是age岁"		没加双引号的 age 是变量，拼接的是它的值；加了双引号就是普通字符串，原样拼接
1 + 2 + "abc" + 2 + 1"3abc21"最难的一题：1+2 先算成 3；3+"abc" 拼成"3abc"；之后都是字符串在拼，"3abc2"、"3abc21"

所以要抓住两个核心：有字符串参与就是拼接；连续加从左到右依次计算。变量和字符串拼接时，变量前后不能加双引号。

练习：改进数值拆分。之前拆三位数打印出来的是 3、2、1，不看题目根本不知道哪个是个位。用拼接加上说明：

System.out.println("个位是：" + ge); System.out.println("十位是：" + shi); System.out.println("百位是：" + bai);

输入 123，打印"个位是：3""十位是：2""百位是：1"，阅读性好多了。后面会大量用到字符串拼接。

动手：一步一步算"+"

输入一串用 + 连起来的值（数字、"字符串"、'字'、true/false，可以用 age 代表变量 18），看每一步是加法还是拼接。

第 2 节 · P32

字符相加：查 ASCII 码表

隐式转换里说过：byte、short、char 运算时都先提升为 int。byte 和 short 本来就是数字，好提升；char 是个字符，怎么提升？

char c = 'a'; int result = c + 0; System.out.println(result); // 97

字符 a 加数字 0 居然得到 97。规则是：字符 + 字符、字符 + 数字时，会把字符通过 ASCII 码表查到对应的数字，再进行计算。ASCII 码表（美国信息交换标准码，P22 讲过）里每个字符都和一个唯一的数字对应，操作系统内置，不用下载。只需要记住两个：

  • 'a' 对应 97
  • 'A' 对应 65

所以 1 + 'a' 是 98；而 'a' + "abc" 有字符串参与，做的是拼接，结果是 "aabc"。两者规则不一样，上面的演示里都能试。

算术运算符总结：

  • 加：数字相加，类型不一样要先转成一样（隐式转换 / 强制转换）；字符串相加，有字符串就拼接；字符相加，查 ASCII 码表得到数字再算。
  • 减、乘：数字和字符的运算规律和加法一样；但字符串没有减、乘、除这些操作。
  • 除和取模：都是做除法，除取的是商，取模取的是余数。整数和整数操作，结果只能是整数；要得到小数，必须有小数参与。
补充：几个顺手的 ASCII 规律 数字字符 '0'~'9' 对应 48~57，所以 '7' - '0' 等于 7，这是把数字字符变成整数的常用写法。大小写字母正好差 32：'a' - 'A' 是 32，小写转大写就是减 32。
想打印字符本身而不是数字，结果要是 char 类型：char next = (char) ('a' + 1); 打印出来是 b。直接 System.out.println('a' + 1); 打印的是 98，因为相加后是 int。
第 3 节 · P33

自增自减运算符

这个知识点相对简单：自增 ++ 把变量里的值加 1，自减 -- 把变量里的值减 1。可以写在变量后面（a++，叫"后加加"），也可以写在前面（++a，叫"先加加"）。

用法一：单独写一行。不管放在前面还是后面，结果都一样，都是把变量加 1 或减 1。

int a = 10; a++; System.out.println(a); // 11 ++a; System.out.println(a); // 12 ← 注意不是 11，上面已经自增过一次了 a--; System.out.println(a); // 11 --a; System.out.println(a); // 10

应用场景：

  • 过生日：变量 age 记录 1 岁，过一个生日 age++，变成 2 岁；
  • 购物车里的商品数量：点一次"+"变量自增一次，点一次"−"自减一次（老师的朋友帮女朋友"清空购物车"就是一直点减）；
  • 统计：数一数图里有几个美女，心里先记 0，从左往右数，遇到一个就 ++，最后记的数就是结果。这个"心里记的数"就是一个变量。

用法二：参与计算。这种比较难，实际开发用得很少，了解即可。参与计算时，先加加和后加加的结果不一样：

int b = a++;后加加，口诀先用后加：先把 a 的值拿出来用（赋值给 b），用完 a 再自增a = 10 时：b 是 10，a 变成 11
int b = ++a;先加加，口诀先加后用：a 先自增，再把自增之后的值赋值给 ba = 10 时：a 变成 11，b 是 11

练习：int x = 10; int y = x++; int z = ++x; 之后，x、y、z 分别是多少？答案是 x = 12，y = 10，z = 12。第二行先用后加：y 拿到自增前的 10，x 变 11；第三行先加后用：x 再自增成 12（它已经自增过一次了），z 拿到 12。下面一步步看：

补充：++ 自带强转，别和自己赋值 和下一节的 += 一样，++ 也隐含强制转换：byte b = 127; b++; 不报错，b 变成 −128。另外，千万别写 a = a++;：先用后加，右边先把 a 的旧值拿出来，a 自增了，接着又把旧值赋回给 a，结果 a 根本没变。这是面试里的经典坑题。
第 4 节 · P34

赋值运算符：+= 里藏着强制转换

最常见的赋值运算符就是 =：int a = 10; 把右边的 10 赋值给左边的变量 a。此外还有扩展的赋值运算符：+=、-=、*=、/=、%=，两个符号之间没有空格。规则都类似，学会一个就会全部。

以 += 为例，叫"加后赋值"：a += b 把左右两边相加，再把结果赋值给左边的变量。

int a = 10; int b = 20; a += b; // 相当于 a = a + b; → a 是 30，b 还是 20 System.out.println(a); // 30 System.out.println(b); // 20

换成 -= 就相当于 a = a - b，其余同理。

细节：

short s = 1; s += 1; System.out.println(s); // 2

结果是 2，好理解。但这行代码有点怪：说好 s += 1 相当于 s = s + 1，可 short 参与计算会先提升为 int，s + 1 的结果是 int，把 int 赋值给 short 是大给小，为什么没报错？

因为 +=、-=、*=、/=、%= 底层都隐藏了一个强制类型转换，转成什么类型由左边变量的类型决定。所以：

s += 1; // 实际上等同于 s = (short) (s + 1); a += b; // 实际上等同于 a = (int) (a + b);
补充：隐藏的强转也会"偷偷出错" 正因为自动强转，+= 永远不会因为类型报错，但数据过大时也会像强制转换一样悄悄出错：byte b = 127; b += 1; 编译通过，b 变成了 −128。而写成 b = b + 1; 编译就会报错，反倒提醒了你。写的时候心里要有数。
第 5 节 · P34

关系运算符（比较运算符）

关系运算符也叫比较运算符，就是拿左右两边做一个判断。一共六种：

a == b判断 a 和 b 是否相等，成立为 true，不成立为 false
a != b判断是否不相等
a > b　a >= b大于、大于等于
a < b　a <= b小于、小于等于

和小学、初中数学几乎一模一样，只要知道两个注意点：

  1. 关系运算符的结果都是 boolean 类型，要么 true，要么 false；
  2. 千万不要把 == 写成 =：两个等号是判断，一个等号是赋值。另外两个符号中间都没有空格。
int a = 10; int b = 10; int c = 20; System.out.println(a == b); // true System.out.println(a == c); // false

练习：约会

需求（斯坦福大学 Java 入门练习）您和您的约会对象在餐厅里约会。键盘录入两个整数，表示您和约会对象衣服的时髦程度（0~10 之间的整数）。如果您的时髦程度大于对象的时髦程度，相亲成功，输出 true，否则输出 false。

分析：键盘录入两次，然后直接比较。

Scanner sc = new Scanner(System.in); System.out.println("请输入我们自己的衣服时髦度"); int myFashion = sc.nextInt(); System.out.println("请输入相亲对象衣服的时髦度"); int girlFashion = sc.nextInt(); boolean result = myFashion > girlFashion; System.out.println(result);

为什么用 > 而不是 >=？因为题目说的是"大于"。题目要是说"大于等于"，就得用 >=。代码一定要和题目的业务逻辑吻合。输入 10 和 5，true；穿着睡衣去相亲，时髦度 1，对方的可爱睡衣是 3，false。

第 6 节

小结

字符串相加有字符串参与就是拼接，产生新字符串；连续加从左到右
字符相加字符+字符、字符+数字：查 ASCII 码表转成数字再算（'a' = 97，'A' = 65）
自增自减++ 加 1，-- 减 1。单独一行前后都一样；参与计算时 a++ 先用后加，++a 先加后用（少用）
赋值运算符= += -= *= /= %=；扩展的赋值运算符底层隐含强制类型转换
关系运算符== != > >= < <=，结果是 boolean；== 别写成 =
一句话 "+"看两边：有字符串就拼接，有字符就查码表；+= 自带强转；比较的结果只有 true 和 false。

自测

1. System.out.println(1 + 2 + "abc" + 2 + 1); 打印什么？
3abc21。从左到右：1+2=3（没有字符串，普通加法）；3+"abc" 拼接成 "3abc"；后面都是字符串在拼接。
2. System.out.println('a' + 1); 和 System.out.println('a' + "1"); 分别打印什么？
98 和 a1。前者是字符加数字，查 ASCII 码表 'a' = 97，再加 1；后者有字符串参与，是拼接。
3. int x = 10; int y = x++; int z = ++x; 之后 x、y、z 各是多少？
x = 12，y = 10，z = 12。y = x++ 先用后加，y 拿到 10，x 变 11；z = ++x 先加后用，x 变 12，z 拿到 12。
4. short s = 1; s = s + 1; 报错，s += 1; 却不报错，为什么？
s + 1 中 short 先提升为 int，结果 int 不能直接赋值给 short；而 += 底层隐含了强制类型转换，等同于 s = (short) (s + 1);
5. int a = 5; System.out.println(a = 6); 和 System.out.println(a == 6); 有什么区别？
第一个是赋值：把 6 赋给 a，打印赋值的结果 6；第二个是比较：判断 a 是否等于 6，打印 true 或 false。所以 == 千万别写成 =。
