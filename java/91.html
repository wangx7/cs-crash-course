第 2 节 · P91

题 1　文字版格斗游戏（基础版）必做

需求 游戏里每个角色的姓名、血量都不一样，在选定人物（也就是创建对象）的时候，这些信息就应该被确定下来。现在有两个角色（课上是乔峰和鸠摩智，血量都是 100），模拟回合制游戏：你打我一下，我打你一下，每一下造成 1 ~ 20 点随机伤害。谁的血量先变成 0，就提示"某某 K.O 了某某"，游戏结束。

先看看要做成什么样

（控制台）每次的伤害是随机的，多运行几次，两个人都可能赢

课上的分析只有两步，先想清楚再动手：

  • 先写一个 JavaBean 描述角色：类名 Role，私有的成员变量 name 和 blood，空参构造、全参构造、每个成员变量的 get 和 set 方法；
  • 角色有攻击的行为，要定义一个方法。这里要思考的是谁攻击谁。测试类里肯定是先创建 r1、r2，然后拿 r1 去调用攻击的方法、把 r2 传进去：r1.attack(r2);。所以从语法上讲，攻击方向是方法的调用者去攻击参数。上一篇说过，this 表示方法的调用者，那么方法里就是拿着 this 去打参数 role。
提示 1　attack 方法里要做哪几件事
  1. 计算造成的伤害：1 ~ 20 随机，r.nextInt(20) + 1；
  2. 算出挨揍的人的剩余血量：先把原有的血量 get 出来，再减去伤害；
  3. 把剩余血量 set 回去，真正修改挨揍的人的血量；
  4. 打印这句话：打人的是 this.getName()，挨揍的是 role.getName()。
提示 2　测试类里的循环怎么写

不知道要打多少轮游戏才结束，所以用 while (true)。循环里 r1 先打 r2，打完马上判断 r2 的血量是不是 0，是就打印 K.O 并 break；然后 r2 还手，同样判断一次 r1。

参考代码　Role 类、GameTest 测试类
import java.util.Random; public class Role { private String name; // 姓名 private int blood; // 血量 // 空参构造、全参构造、get / set 方法：用 IDEA 生成，这里省略 // 攻击：方法的调用者（this）去打参数（role） public void attack(Role role) { // 计算造成的伤害，1 ~ 20 随机 Random r = new Random(); int hurt = r.nextInt(20) + 1; // 挨揍的人的剩余血量；减成负数不合理，修正为 0 int remainBlood = role.getBlood() - hurt; remainBlood = remainBlood < 0 ? 0 : remainBlood; // 修改挨揍的人的血量 role.setBlood(remainBlood); System.out.println(this.getName() + "举起拳头，打了" + role.getName() + "一下，" + "造成了" + hurt + "点伤害，" + role.getName() + "还剩下了" + remainBlood + "点血"); } } public class GameTest { public static void main(String[] args) { // 1. 创建第一个角色 Role r1 = new Role("乔峰", 100); // 2. 创建第二个角色 Role r2 = new Role("鸠摩智", 100); // 3. 开始格斗：回合制，不知道要打多少轮，用 while (true) while (true) { // r1 攻击 r2 r1.attack(r2); // 判断 r2 的剩余血量 if (r2.getBlood() == 0) { System.out.println(r1.getName() + " K.O 了" + r2.getName()); break; } // r2 还手 r2.attack(r1); if (r1.getBlood() == 0) { System.out.println(r2.getName() + " K.O 了" + r1.getName()); break; } } } }

易错点：剩余血量有可能是负数。比如最后只剩 5 点血，又挨了 20 点伤害，直接一减就成了负数，不合理。所以要验证一下：小于 0 就修正为 0，否则还是原来的值，课上用的是三元运算符 remainBlood = remainBlood < 0 ? 0 : remainBlood;。

为什么每打一下就要判断一次 测试类里的判断写了两遍，r1 打完判断 r2，r2 打完判断 r1。如果偷懒合成一遍、等一轮打完再判断，就会出现血量已经是 0 的 r2 还能再还手打 r1 一下的情况。另外判断条件写的是 == 0，它依赖 attack 里"负数修正为 0"那一步；如果忘了修正，血量会直接从正数跳到负数，循环就停不下来了，写成 <= 0 更保险。
第 3 节 · P91

新知识　printf 与 %s新知识点

基础版的输出每次都是"谁举起拳头打了谁一下"，有点单调。升级版想打印带武功招式的句子，资料里给的句子长这样：结果%s退了半步，毫发无损。里面的 %s 是什么？这要用到一个新的输出语句 System.out.printf（在 IDEA 里敲 souf 可以生成）。它的参数分为两部分：

  • 第一部分参数：要输出的内容，里面可以写 %s，把它理解成占位，先占一个坑；
  • 第二部分参数：填充的数据，拿去填前面占的坑。
System.out.printf("你好啊%s", "张三"); // 你好啊张三 System.out.printf("%s你好啊%s", "张三", "李四"); // 张三你好啊李四

两个细节：

  • 占了几个坑，后面就要拿几个数据去填，按顺序对应：张三填第一个坑，李四填第二个坑。写了两个占位却只给一个数据，运行会报错；
  • printf 只输出，没有换行效果。连着写两个 printf，两句话会显示在同一行。想换行，就在后面加一句 System.out.println();，小括号里什么都不写，表示只换行。
报的是什么错，还有哪些占位符 两个 %s 只给一个数据，本机 JDK 8 实测：控制台先打印出 张三你好啊，然后报 java.util.MissingFormatArgumentException: Format specifier '%s'。它是运行时才报的，编译能通过。

%s 之外常用的还有：%d 填整数，%.2f 填小数并保留两位，%n 表示换行（可以直接写在第一部分里，省掉后面那句 println）。

需求 在题 1 的基础上优化：
  1. 人物多两个属性：性别和长相。长相是随机的：男的从 boyfaces 数组里随机，女的从 girlfaces 数组里随机；

  3. 开打之前，先展示两个角色的信息。

数据在课程资料里，粘贴到 Role 类里就行：

String[] boyfaces = {"风流俊雅", "气宇轩昂", "相貌英俊", "五官端正", "一塌糊涂", "面目狰狞"}; String[] girlfaces = {"眉清目秀", "亭亭玉立", "相貌平平", "惨不忍睹"}; // 攻击描述：第一个 %s 是打人的，第二个 %s 是挨揍的 String[] attacks_desc = { "%s使出了一招【背心钉】，转到对方的身后，一掌向%s背心的灵台穴拍去。", "%s使出了一招【游空探爪】，飞起身形自半空中抓向%s。", "%s运气于掌，一瞬间掌心变得通红，一式【掌心雷】，推向%s。", "%s阴手翻起阳手跟进，一招【没遮拦】，结结实实地捶向%s。" }; // 受伤描述：从轻到重，一共 8 条，%s 是挨揍的 String[] injureds_desc = { "结果%s退了半步，毫发无损", "结果给%s造成一处瘀伤", "结果一击命中，%s痛得弯下腰", "结果%s闷哼了一声，连退了好几步", "结果%s脚下不稳，一跤摔倒在地", "结果%s脸色发白，半天站不起来", "结果%s吐出一口鲜血", "结果%s一声惨叫，像滩软泥般塌了下去" };

升级版跑起来的样子

（控制台）

课上最后点出的两个难点：

  • 长相不是别人赋值的，而是随机的，要想明白在哪随机：在 setFace 方法里随机，然后在构造方法里直接调用它；
  • attack 方法里的顺序：先把攻击的描述打印出来，再计算伤害、修改挨揍的人的剩余血量，然后根据剩余血量进行不同的受伤描述。
提示 1　setFace 怎么写

把形参改成性别：setFace(char gender)。先判断 gender：是 '男' 就在 boyfaces 里随机，是 '女' 就在 girlfaces 里随机，都不是就给一个默认的长相（课上用的是"面目狰狞"）。随机的是索引：r.nextInt(boyfaces.length)，索引只是个数字，还要再通过索引把数组里的长相拿出来，赋给成员变量 face。构造方法的参数里只加 gender，不加 face，最后一行写 setFace(gender);。

提示 2　attack 里怎么用 printf

随机一个索引，从 attacks_desc 里拿到招式（课上变量名叫 KungFu），它里面有两个 %s：第一个是打人的，填 this.getName()；第二个是挨揍的，填 role.getName()。受伤描述里只有一个 %s，填挨揍的人。

八个范围就是多个 else if。程序是从上往下挨个判断的，走到第二个判断时一定已经不大于 90 了，所以 remainBlood > 80 后面的 && remainBlood <= 90 其实可以省略；课上为了提高代码的阅读性还是写上了。最后一种情况直接用 else 收尾。

提示 3　运行出来所有字都挤在一行

课上第一次运行就是这样：打斗过程全在一行，K.O 也跟在最后。原因是 printf 没有换行效果。打印完攻击描述之后、打印完受伤描述之后，各加一句 System.out.println();。

参考代码　升级版 Role 类

0 : remainBlood; role.setBlood(remainBlood); // 3. 受伤描述不随机：按剩余血量从轻到重选 if (remainBlood > 90) { System.out.printf(injureds_desc[0], role.getName()); } else if (remainBlood > 80 && remainBlood <= 90) { System.out.printf(injureds_desc[1], role.getName()); } else if (remainBlood > 70 && remainBlood <= 80) { System.out.printf(injureds_desc[2], role.getName()); } else if (remainBlood > 60 && remainBlood <= 70) { System.out.printf(injureds_desc[3], role.getName()); } else if (remainBlood > 40 && remainBlood <= 60) { System.out.printf(injureds_desc[4], role.getName()); } else if (remainBlood > 20 && remainBlood <= 40) { System.out.printf(injureds_desc[5], role.getName()); } else if (remainBlood > 10 && remainBlood <= 20) { System.out.printf(injureds_desc[6], role.getName()); } else { System.out.printf(injureds_desc[7], role.getName()); } System.out.println(); } public void showRoleInfo() { System.out.println("姓名为：" + getName()); System.out.println("血量为：" + getBlood()); System.out.println("性别为：" + getGender()); System.out.println("长相为：" + getFace()); } }

题 3　商品数组热身

需求 定义数组存储 3 个商品对象。商品的属性：id、名字、价格、库存。创建三个商品对象，并把它们存入数组。

用读题拆解法走一遍：数组里存的是商品对象，要创建对象就得先写一个类去描述商品，所以第一步是写 Goods 这个 JavaBean（id 有可能出现字母，用 String；价格用 double；库存用 int）。然后在测试类里：创建数组 → 创建三个商品对象 → 把商品添加到数组中 → 遍历验证。

提示　动态初始化、形参顺序、i 和 arr[i]
  • 数组用动态初始化 new Goods[3]：现在还不知道商品对象是什么，先把数组创建出来，有了对象再添加；
  • 全参构造的参数顺序记不住，不用点开 Goods 类去对：光标点在小括号里按 Ctrl + P，会列出两行，一行是没有参数（空参构造），一行是全参构造的顺序；
  • 遍历时 i 表示索引，arr[i] 才表示元素。先用一个变量把 arr[i] 接出来，再用它调 get 方法。这句话课上每道题都重复了一遍。
参考代码　GoodsTest
public class GoodsTest { public static void main(String[] args) { // 1. 创建一个数组：对象还没有，先用动态初始化 Goods[] arr = new Goods[3]; // 2. 创建三个商品对象 Goods g1 = new Goods("001", "华为P40", 5999.0, 100); Goods g2 = new Goods("002", "保温杯", 227.0, 50); Goods g3 = new Goods("003", "枸杞", 12.7, 70); // 3. 把商品添加到数组中 arr[0] = g1; arr[1] = g2; arr[2] = g3; // 4. 遍历：i 是索引，arr[i] 才是元素 for (int i = 0; i < arr.length; i++) { Goods goods = arr[i]; System.out.println(goods.getId() + ", " + goods.getName() + ", " + goods.getPrice() + ", " + goods.getCount()); } } }

输出三行：001, 华为P40, 5999.0, 100、002, 保温杯, 227.0, 50、003, 枸杞, 12.7, 70。

新知识　键盘录入的两套体系新知识点

下一题的数据要从键盘录入，先把键盘录入的其他方法和细节讲清楚。Scanner 接收数据的方法分成两套：

方法接收什么什么时候停止接收
第一套nextInt()整数。录小数或字符串会报错遇到空格、制表符（Tab）、回车就停止，这些符号后面的数据本次不会接收
nextDouble()小数。录的是 10，接到的也是 10.0
next()字符串。录的是 123，也当字符串接
第二套nextLine()字符串，一整行空格、制表符都能接收，遇到回车才停止

"后面的数据本次不会接收"不等于丢掉了，它们还留在内存里，会交给下一次键盘录入。课上的三个实验：

  • 连着两次 nextInt()，输入 123 123 再回车：第一次遇到空格就停，只接到 123；第二次没有让你重新输，直接把内存里剩下的 123 接走了。两次 next() 输入 abc bcd 也一样，分别接到 abc 和 bcd；
  • 连着两次 nextLine()，输入 abc bcd 回车：第一次就把整行全部接走，然后停下来等你输入第二行；
  • 混用：先 nextInt() 再 nextLine()，输入 123 回车：字符串根本没让你输，程序就结束了。你看到自己输入的是 123，实际上还录了一个回车；nextInt 只把 123 接走，回车还在内存里，被下面的 nextLine 接走了，于是它接收不到数据。

动手：看内存里剩下了什么

内存里的数据（␣ 是空格，↵ 是回车；虚线格子已经被接走，橙色格子还留着）
课上的建议 两套体系不能混用：先用 nextInt 再用 nextLine，会导致 nextLine 接收不到数据，这种问题写在代码里可能很久都找不到原因。目前先用第一套；第二套等学完类型转换之后再用，那时不管数据带不带空格、制表符，都能接收进来。
"学完类型转换之后"是什么写法 就是全部用 nextLine()，一次接一整行，要数字时再把字符串转成数字：int num = Integer.parseInt(sc.nextLine());（本机实测：先输 123 回车，再输 abc bcd 回车，两次都正常接到）。每次都把回车取走，内存里不会留东西，也就没有混用的问题。

另外两个实测结果：第一套方法开始接收前会先跳过开头的空白，所以上一次留下的回车不影响下一个 nextInt 或 next；nextInt 遇到不是整数的内容（比如 abc、12.5），报的是 java.util.InputMismatchException。

参考代码　CarTest
import java.util.Scanner; public class CarTest { public static void main(String[] args) { // 1. 创建一个数组用来存储 3 个汽车对象 Car[] arr = new Car[3]; // 2. 创建汽车对象，数据来自键盘录入 Scanner sc = new Scanner(System.in); for (int i = 0; i < arr.length; i++) { // 每一轮都创建一个新的汽车对象（一定要写在循环里面） Car c = new Car(); System.out.println("请输入汽车的品牌"); String brand = sc.next(); c.setBrand(brand); System.out.println("请输入汽车的价格"); int price = sc.nextInt(); c.setPrice(price); System.out.println("请输入汽车的颜色"); String color = sc.next(); c.setColor(color); // 数据有了，还要把汽车对象放进数组 arr[i] = c; } // 3. 遍历数组 for (int i = 0; i < arr.length; i++) { Car car = arr[i]; System.out.println(car.getBrand() + ", " + car.getPrice() + ", " + car.getColor()); } } }

动手：new 写在循环里和循环外

堆里的汽车对象

题 5　平均值与统计必做

需求 5a 定义数组存储 3 部手机对象。手机的属性：品牌、价格、颜色。要求计算出三部手机的平均价格。（课上的数据：小米 1999 白色、华为 4999 蓝色、魅族 3999 红色。）
需求 5b 定义数组存储 4 个女朋友的对象。属性：姓名、年龄、性别、爱好。
  1. 计算出四个女朋友的平均年龄；
  2. 统计年龄比平均值低的女朋友有几个，并把她们的所有信息打印出来。
（课上的数据：小诗诗 18 岁、小丹丹 19 岁、小惠惠 20 岁、小莉莉 21 岁。）
提示　累加思想、统计思想
  • 价格在手机对象里面，所以求平均值之前要先遍历数组、得到每一个手机对象。在循环上面定义变量 sum，循环里每拿到一个价格就累加进去（累加思想）。注意累加的不是对象本身，而是对象里 get 出来的价格或年龄；
  • 循环结束，总和除以个数。个数不要写 3，写 arr.length：数据能不写死，尽量不写死。以后上面数组的长度变了，下面这行不用跟着改；
  • 5b 的第二问，把数组再遍历一遍，拿每个人的年龄和平均值比较，小于就打印信息。统计有几个用统计思想：定义变量 count，满足要求时自增一次。
参考代码　核心部分（JavaBean 和创建对象同前几题）

5a 手机的平均价格：

// 累加思想：先求总和 int sum = 0; for (int i = 0; i < arr.length; i++) { Phone phone = arr[i]; sum = sum + phone.getPrice(); } // 再求平均值：个数不要写死成 3 int avg = sum / arr.length; System.out.println(avg); // 3665 double avg2 = sum * 1.0 / arr.length; System.out.println(avg2); // 3665.6666666666665

5b 女朋友的平均年龄与统计：

// 1. 求和，再求平均年龄 int sum = 0; for (int i = 0; i < arr.length; i++) { GirlFriend gf = arr[i]; sum = sum + gf.getAge(); // 累加的是对象里的年龄 } int avg = sum / arr.length; // 2. 再遍历一遍：比平均值低的，打印并计数 int count = 0; for (int i = 0; i < arr.length; i++) { GirlFriend gf = arr[i]; if (gf.getAge() < avg) { count++; System.out.println(gf.getName() + ", " + gf.getAge() + ", " + gf.getGender() + ", " + gf.getHobby()); } } System.out.println(count + "个");

课上的结果：手机的平均价格是 3665。想要小数的话，以现在的知识只能把 sum 先乘以 1.0 变成小数再除，得到 3665.6666666666665，很长；小数直接参与计算，结果有可能不精确。想精确运算、保留两位小数、还要四舍五入，要用到后面学的 BigDecimal。5b 的平均年龄是 19，比平均值低的只有小诗诗 1 个。

整数除法悄悄改了 5b 的答案 四个人的年龄之和是 78，78 / 4 是整数除法，得 19；真实的平均值是 19.5。拿 19 去比，只有 18 岁的小诗诗比它低；按 19.5 算，19 岁的小丹丹也比平均值低，答案应该是 2 个。把平均值改成 double avg = sum * 1.0 / arr.length;，本机实测输出就变成两个人。平均值要参与后面的比较时，不要随手用 int。

另外，如果只是想把 3665.666… 显示成两位小数，上面学的 printf 就能做到：System.out.printf("%.2f", avg2); 实测打印 3665.67。它只改变显示出来的样子，变量里的值没有变；要让计算本身精确，还是得等 BigDecimal。

题 6　学生数组的增删改必做 · 重点

这是对象数组的最后一个练习，难度很大。讲它是为了分享：业务比较复杂的时候，该如何思考、如何分析题目。很多零基础的同学刚学完 Java 都有同一个特点：读不懂题目，一听就懂，一写就废。这不是学得不好，而是还不会分析题目。

需求 定义一个长度为 3 的数组，数组里存储 1 ~ 3 名学生对象作为初始数据，学生对象的学号、姓名各不相同。学生的属性：学号、姓名、年龄。
  • 要求 1：再次添加一个学生对象，并在添加的时候进行学号的唯一性判断；
  • 要求 2：添加完毕之后，遍历所有学生信息；
  • 要求 3：通过 id 删除学生信息。如果存在，则删除；如果不存在，则提示删除失败；
  • 要求 4：删除完毕之后，遍历所有学生信息；
  • 要求 5：查询数组中 id 为 2 的学生，如果存在，则将他的年龄 +1 岁。
学号按道理应该用字符串（可能有字母，比如 heima001），但字符串怎么比较还没学，所以 id 先用 int，学完再改回来。课上的初始数据：1 张三 23、2 李四 24、3 王五 25；要添加的是 4 赵六 26。要求 1 ~ 2、3 ~ 4、5 课上分别写在三个测试类里，各自从同样的初始数据开始。

课上的分析：读题拆解，再局部细化

题目的主体很容易：创建数组、创建学生对象、放进数组。难在要求 1，一句话里让我们做的事情太多了。拆：

  • 先一分为二。左半句"再次添加一个学生对象"：那得先有一个学生对象 stu4。右半句"添加的时候进行唯一性判断"，继续细化；
  • 添加有两种情况。数组已经存满：只能创建一个新数组，长度是老数组的长度 + 1，把老数组里原来的数据拷贝过去，再把 stu4 添加进去。数组没有存满：直接添加；
  • 唯一性判断写在添加的前面还是后面？先想它的目的：让 id 不重复。判断完一定有两个结果：当前 id 已存在，就不用添加了；不存在，表示可用，才把学生对象添加进数组。所以唯一性判断是添加数据的先决条件，写在前面。

自己写的时候，先别忙着写代码，先把分析过程写成注释：

// 1. 创建一个长度为 3 的数组 // 2. 创建学生对象 // 3. 把学生对象添加到数组当中 // 4. 再次创建一个学生对象 // 5. 唯一性判断 // 5.1 已存在：提示重复 // 5.2 不存在：添加学生对象 // 6. 添加学生对象 // 6.1 老数组已经存满 // 6.2 老数组没有存满

课上的要求是：看完讲解先别去看老师的代码，照着这份主体逻辑，试试能不能自己把代码写出来。

提示 1　要抽取哪几个方法

每定义一个方法，还是问自己三个问题：我要干嘛？我干这件事需要什么才能完成？调用处是否需要继续使用方法的结果？

方法我要干嘛需要什么（形参）要不要返回
contains判断 id 在数组中是否存在数组、id，两个都得告诉我要。调用处根据结果走不同的逻辑；只有两种状态，boolean
getCount判断数组中已经存了几个元素数组要，int
creatNewArr创建长度 + 1 的新数组，把老数组的元素拷贝过去老数组要，把新数组返回，Student[]
printArr遍历打印（存满和没存满两处都要遍历，代码重复）数组不用，void
getIndex找到 id 在数组中的索引（要求 3、5 用）数组、id要，int；不存在返回 -1，因为没有 -1 索引
提示 2　contains 里的 return false 写在哪

循环里比较，相同就 return true。那什么时候返回 false？不能写在 else 里。假设数组里是 id 为 1、2、3 的三个学生，要查的是 3：i 等于 0 时拿到 1，和 3 不一样，如果这时候就返回 false 就错了，应该接着往后比。数组里所有的都比完了还没有找到一样的，才能认为不存在，所以 return false 写在循环的外面。getIndex 的 return -1 同理。

提示 3　怎么知道存了几个、新学生该存到哪个索引

Student 类型的数组，没存东西的位置是默认初始化值 null。所以 getCount 就是数一数数组里有几个位置不是 null。

没存满时要直接添加，添加到哪个索引？不用重新计算。假设数组里是 stu1、stu2、null，getCount 得到 2。这个 2 表示已经有了两个元素，它还有一层隐含的意思：下一次要添加数据，就添加到 2 索引的位置。所以直接写 arr[count] = stu4;。存满的情况也一样，新数组前面拷贝了老元素，只有最后一个空着，还是 newArr[count] = stu4;。

提示 4　删除和修改

两问都不能直接动手，因为不知道这个 id 在不在：先用 getIndex 找到 id 在数组中对应的索引，再对索引做判断，大于等于 0 表示存在，否则是 -1，不存在。两个分支先写简单的那个（一句提示就搞定）。

  • 删除：把 index 索引上的元素直接置为 null，arr[index] = null;；
  • 修改：先通过索引把这个学生对象拿出来，get 出原来的年龄加 1，得到新的年龄；最后还要用 setAge 塞回去，不塞回去，原来的年龄没有变化。
参考代码 ①　要求 1、2：添加和遍历
public static void main(String[] args) { // 1. 创建一个数组用来存储学生对象 Student[] arr = new Student[3]; // 2. 创建学生对象，3. 添加到数组当中 Student stu1 = new Student(1, "张三", 23); Student stu2 = new Student(2, "李四", 24); Student stu3 = new Student(3, "王五", 25); arr[0] = stu1; arr[1] = stu2; arr[2] = stu3; // 要求 1：再次添加一个学生对象，添加时进行学号的唯一性判断 // 4. 再创建一个学生对象 Student stu4 = new Student(4, "赵六", 26); // 5. 唯一性判断：是添加的先决条件，写在前面 boolean flag = contains(arr, stu4.getId()); if (flag) { // 5.1 已存在：不用添加，提示重复 System.out.println("当前id重复，请修改id后再进行添加"); } else { // 5.2 不存在：6. 添加学生对象 int count = getCount(arr); if (count == arr.length) { // 6.1 老数组已经存满：创建新数组，把老元素拷贝过去，再放新元素 Student[] newArr = creatNewArr(arr); newArr[count] = stu4; // 要求 2：遍历所有学生信息（遍历的是新数组） printArr(newArr); } else { // 6.2 没有存满：count 既是已有元素的个数，也是下一个要存入的索引 arr[count] = stu4; printArr(arr); } } } // 判断 id 在数组中是否存在 public static boolean contains(Student[] arr, int id) { for (int i = 0; i < arr.length; i++) { Student stu = arr[i]; if (stu != null) { // 数组没存满时，后面是 null int sid = stu.getId(); if (sid == id) { return true; } } } // 循环结束还没找到一样的，才能说不存在 return false; } // 统计数组中已经存了几个元素 public static int getCount(Student[] arr) { int count = 0; for (int i = 0; i < arr.length; i++) { if (arr[i] != null) { count++; } } return count; } // 创建一个新数组，长度 = 老数组的长度 + 1，并把老数组的元素拷贝过去 public static Student[] creatNewArr(Student[] arr) { Student[] newArr = new Student[arr.length + 1]; for (int i = 0; i < arr.length; i++) { newArr[i] = arr[i]; } return newArr; } // 遍历打印，跳过 null public static void printArr(Student[] arr) { for (int i = 0; i < arr.length; i++) { Student stu = arr[i]; if (stu != null) { System.out.println(stu.getId() + ", " + stu.getName() + ", " + stu.getAge()); } } }
参考代码 ②　要求 3、4：删除
// 要求 3：通过 id 删除学生信息 // 先找到 id 在数组中对应的索引 int index = getIndex(arr, 2); if (index >= 0) { // 存在：把这个位置置为 null，就是删除 arr[index] = null; // 要求 4：删除完毕，遍历所有学生信息 printArr(arr); } else { // 不存在 System.out.println("当前id不存在，删除失败"); } // 找到 id 在数组中的索引；不存在返回 -1 public static int getIndex(Student[] arr, int id) { for (int i = 0; i < arr.length; i++) { Student stu = arr[i]; if (stu != null) { int sid = stu.getId(); if (sid == id) { return i; } } } return -1; }
参考代码 ③　要求 5：修改
// 要求 5：查询 id 为 2 的学生，存在就把年龄 +1 int index = getIndex(arr, 2); if (index >= 0) { Student stu = arr[index]; // 先把这个学生对象拿出来 int newAge = stu.getAge() + 1; // 原来的年龄 + 1 stu.setAge(newAge); // 再塞回去 printArr(arr); } else { System.out.println("当前id不存在，修改失败"); }

运行结果对一对：初始存满三个，添加后打印四行（张三、李四、王五、赵六）；把初始数据删成两个再运行，数组不用扩容，打印三行；把 stu4 的 id 改成 1，提示"当前id重复"。删除 id 为 2 的，打印张三、王五；删除 id 为 4 的，提示删除失败。修改后李四变成 25 岁；查 id 为 4 的，提示修改失败。

易错点：

  • null 不能直接使用。课上把初始数据删成两个之后，程序就报错了。读报错信息要从下往上看：先是 main 方法的某一行，那一行在调用方法，继续往上是 contains 方法里 stu.getId() 那一行。数组没装满，这里拿到的是 null，用 null 去调用方法就会报错。所以凡是遍历这个数组的地方，都要先做非空判断，不是 null 才往下做；
  • 遍历的是哪个数组。存满时 stu4 放进的是新数组，要遍历 newArr；没存满时放进的是老数组，遍历 arr。两处都要写，所以才抽成 printArr；
  • 对 boolean 类型的变量做判断，不要写 ==，直接把变量写在小括号里：if (flag)。写 == 很容易少写一个变成 =，那就不叫判断，叫赋值了。
把三问连起来跑，会发现两个坑 课上三问分别写在三个测试类里，每次都从"三个学生"重新开始，所以没有遇到下面的情况。

① 先删除、再添加，会覆盖别人。删掉 id 为 2 的李四之后，数组是 [张三, null, 王五]。这时再添加赵六：getCount 数出来是 2，没存满，执行 arr[2] = stu4;，王五被覆盖了（本机实测，最后打印的是张三、赵六）。"count 就是下一个要存入的索引"成立的前提，是元素从 0 索引开始挨着存、中间没有空位。改法有两种：添加时去找第一个是 null 的位置；或者删除时把后面的元素往前挪一格。

② 扩容之后，新数组只在 if 里看得见。newArr 是在 if 的大括号里定义的，出了大括号就用不了，后面要接着删除、修改的话，拿到的还是没有赵六的老数组。更顺手的写法是 arr = creatNewArr(arr);，让 arr 直接指向新数组，后面统一用 arr，遍历也不用分两种情况写。

这些麻烦事（存满了自动扩容、删除后自动挪位置）正是后面要学的集合 ArrayList 替你做掉的。

自测

1. r1.attack(r2); 执行时，attack 方法里的 this 和形参 role 分别是谁？谁的血量变了？
this 是方法的调用者 r1，role 是传进来的 r2。方法里调用的是 role.setBlood(…)，所以是 r2（挨揍的人）的血量变了。
2. 连着写 System.out.printf("%s打了%s", "A", "B"); 和 System.out.printf("结果%s毫发无损", "B");，输出是什么样？
A 填第一个坑，B 填第二个坑。printf 没有换行效果，所以两句连在同一行：A打了B结果B毫发无损。想分成两行，中间加一句 System.out.println();。
3. 先 sc.nextInt() 再 sc.nextLine()，键盘输入 123 然后回车。nextLine 接到了什么？为什么？
接到的是空的字符串，而且没有停下来让你输入。实际录入的是"123 + 回车"，nextInt 只把 123 接走，回车还留在内存里；nextLine 遇到回车就停止，一上来就碰到了这个回车。
4. 录入三辆车时把 Car c = new Car(); 写在了 for 循环外面，遍历打印出来是什么？
三行都是第三辆车的数据。整个程序只有一个汽车对象，每一轮循环只是修改它的属性，再把同一个地址值存进数组；数组三个位置指向的是同一个对象，看到的都是最后一次修改的结果。
5. contains 方法里，return false; 为什么不能写在循环里的 else 中？
写在 else 里，只要第一个学生的 id 不一样就返回 false 了，后面的根本没比。要把数组里所有的都比完，还没找到一样的，才能说不存在，所以写在循环的外面。
6. 数组是 [stu1, stu2, null]，getCount 返回几？这个数字还有一层什么意思？什么情况下这层意思不成立？
返回 2：已经存了两个元素。它还表示下一次添加数据要存到 2 索引。前提是元素从 0 索引开始挨着存；如果中间有被删除后留下的 null（比如 [stu1, null, stu3]），count 是 2，但 2 索引上有人，直接存会把 stu3 覆盖掉（见题 6 的补充框）。
