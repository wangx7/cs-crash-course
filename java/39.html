顺序结构与 if

Sequential Flow & the if Statement

到现在为止，程序都是从上往下一行一行执行的。可现实里经常要"如果……就……"：酒量大于 2 斤才夸你，钱够 100 才吃网红餐厅，分数不同奖励不同。这一篇学流程控制里的顺序结构和 if 的三种格式，从这一章开始，这样的代码以后每天都要写。

第 1 节 · P39

流程控制语句与顺序结构

学习就像闯关：计算机基础、Java 基础语法、运算符三关都过了，接下来是第四关流程控制语句。地图上六关全部通关，就可以开始写游戏了。这一章内容不多，但非常重要，重要到以后每天都会写这样的代码。

学习方法也要变一变：以前学的多是概念和格式（数据类型、类型提升、运算符……），记住了多练就行；从这一章开始，每天学的内容少一点，但要分析题目的逻辑、多思考、多练习。

流程控制语句：通过一些语句控制程序的执行流程。分三类：顺序结构、分支结构、循环结构。

最简单的是顺序结构：main 方法里写四条打印语句，从上往下依次执行。它是 Java 程序默认的执行流程，按代码的先后顺序从上往下执行。

分支结构包含两种语句：if（判断）和 switch（选择）。先学 if，它有三种格式：

格式一：一种情况

if (关系表达式) {
    语句体;
}
满足就执行，不满足就不执行

格式二：二选一

if (关系表达式) {
    语句体1;
} else {
    语句体2;
}
满足执行 1，不满足执行 2

格式三：多选一

if (关系表达式1) {
    语句体1;
} else if (关系表达式2) {
    语句体2;
}
…
else {
    语句体 n+1;
}
从上往下依次判断
第 2 节 · P40

if 的第一种格式

为什么要有 if？老师的朋友去见老丈人，老丈人问：能喝多少？喝不到 2 斤就不行。按以前学的，可以定义变量 wine = 10 表示酒量，再打印"小伙子，不错嘛"。可要是把 wine 改成 1，这句话还会打印，就不合理了：小于 2 斤，老丈人应该不搭理。能不能对变量做个判断，大于 2 才执行这句话？这就是 if。

执行流程：先算小括号里关系表达式的值（一个判断，结果是 boolean）；为 true 就执行大括号里的语句体，为 false 就不执行；然后继续执行 if 下面的其他语句。

// 键盘录入女婿的酒量，大于 2 斤老丈人给出回应，反之不回应 Scanner sc = new Scanner(System.in); System.out.println("请输入女婿的酒量"); int wine = sc.nextInt(); if (wine > 2) { System.out.println("小伙子，不错嘛！"); }

输入 10，打印"小伙子，不错嘛！"；输入 0，什么都没有。在下面的追踪器里可以看到每次走了哪几行。

动手：代码追踪器

选一个例子，改输入值，看哪个判断是 true、哪个是 false，哪些行执行了（黄色）、哪些被跳过（变淡）。本页的例子都在这里。

三个注意事项

  1. 大括号的开头可以另起一行写，语法上没问题（有些其他语言习惯这么写），但建议按 Java 的习惯写在第一行的末尾。
  2. 语句体只有一句代码时，大括号可以省略，但建议不要省略。因为有时分不清什么才算"一句"：比如 int a = 100; 其实包含了"定义变量 a"和"给 a 赋值 100"两句，省略大括号就会报错。
  3. 对 boolean 类型的变量判断时，不要用 ==，直接把变量写在小括号里：if (flag)。因为 == 很容易少写一个，if (flag = true) 就从判断变成了赋值，不管 flag 原来是什么，赋值完都是 true，大括号里的代码一定会执行。

两个练习

考试奖励：班里小红对小明说，这次考试你要是全班第一，我就做你女朋友。其他同学很感动，决定集体交白卷。用代码实现小红的心理活动：定义变量记录小明的名次 ranking（其他人都交白卷，所以是 1），判断 ranking == 1 就打印"小红成为了小明的女朋友"。要是有个暗恋小红的男生没交白卷，还考得比小明好，名次变成 2，这句话就不打印了。

自动驾驶：车开到十字路口，绿灯亮就前进，黄灯亮就减速，红灯亮就停止。定义三个 boolean 变量记录三个灯的状态（true 亮，false 灭），然后写三个独立的 if，每个都直接把变量写在小括号里：if (isLightGreen) 打印 go go go，if (isLightYellow) 打印 slow，if (isLightRed) 打印 stop。三个 if 互相独立，程序会从上往下挨个判断。第 4 节会用第三种格式改进它。

第 3 节 · P41

if 的第二种格式：二选一

第二种格式就是在第一种的基础上加了个 else。先算关系表达式：true 执行 if 里的语句体1，false 执行 else 里的语句体2，最后执行 if 下面的其他语句。注意：执行了语句体1，就不会再执行语句体2，整个 if 结束；反过来也一样，不会回头。

练习一：吃饭。键盘录入身上的钱，大于等于 100 就吃网红餐厅，否则吃经济实惠的沙县小吃（也叫福建大酒店）。

int money = sc.nextInt(); if (money >= 100) { System.out.println("吃网红餐厅"); } else { System.out.println("吃经济实惠的沙县小吃"); }

视频里解释 else 时说"否则就表示钱小于等于 100"。朋友媳妇刚给了 200 零花钱，吃网红餐厅；月底只剩 30，就吃沙县小吃。什么时候用第二种格式？两种情况二选一的时候。

练习二：商品付款（斯坦福入门练习）：商品总价 600，键盘录入实际支付的钱，大于等于 600 打印"付款成功"，否则"付款失败"。写法和上面一样。

练习三：影院选座（斯坦福入门练习）：票号 1~100，奇数坐左边，偶数坐右边。键盘录入票号 ticket，用 ticket % 2 == 1 判断奇数。写完测一下：50 坐右边、11 坐左边都对，可输入 200 还提示"坐右边"，票号只到 100，这是张假票！所以显示座位之前，还要先判断票是不是真实有效的：

if (ticket >= 0 && ticket <= 100) { // 只有真实有效的票才判断坐哪边 if (ticket % 2 == 1) { System.out.println("坐左边"); } else { System.out.println("坐右边"); } }

输入 200，外面的判断为 false，里面的代码都不执行，程序直接结束。这叫对数据做合法性校验；if 里面还有 if，叫 if 的嵌套。

更正：票号的下限 题目说票号是 1~100，校验应该写 ticket >= 1 && ticket <= 100。视频写成了 >= 0，输入 0 会被当成有效的偶数票，提示"坐右边"。追踪器里输入 0 可以看到这个漏洞。测试时，边界值（0、1、100、101）一定要测。
第 4 节 · P42

if 的第三种格式：多选一

第一种格式判断一种情况，第二种在两种情况里选一种。情况更多怎么办？老师的朋友对儿子小明说：根据考试分数送不同的礼物，95~100 分送自行车一辆，90~94 分游乐场玩一天，80~89 分送变形金刚一个，80 分以下揍一顿。四种情况，就要用 if 的第三种格式：在第二种格式的中间加上对其他条件的判断。

执行流程：先判断关系表达式1，true 就执行语句体1，然后整个 if 结束；false 就继续判断关系表达式2，true 执行语句体2，结束……一句话：从上往下依次判断，只要有一个为真，就执行对应的语句体，然后结束；所有判断都为假，就执行 else 里的语句体。最后的 else 就像个"备胎"，上面都不满足才轮到它。

int score = sc.nextInt(); if (score > 0 && score <= 100) { // 对异常数据进行校验 if (score >= 95 && score <= 100) { System.out.println("送自行车一辆"); } else if (score >= 90 && score <= 94) { System.out.println("游乐场玩一天"); } else if (score >= 80 && score <= 89) { System.out.println("送变形金刚一个"); } else { System.out.println("揍一顿"); } } else { System.out.println("当前录入的成绩不合法"); }

一开始没有外层的校验：考 100 送自行车、考 60 揍一顿都对；可"超常发挥连附加题都做了"考了 110，也要挨揍，肯定不爽。所以加上外层判断，只有 0~100 之间的分数才去发奖励，否则提示"当前录入的成绩不合法"。

练习：商品的价格（斯坦福入门练习，原题是 1000 美元）：商品总价 1000，键盘录入会员级别，计算实际支付的钱。1 级会员打 9 折，2 级打 8 折，3 级打 7 折，其他数字是非会员，不打折（"要打也打骨折"）。

int price = 1000; int vip = sc.nextInt(); if (vip == 1) { System.out.println("实际支付的钱为" + (price * 0.9)); } else if (vip == 2) { System.out.println("实际支付的钱为" + (price * 0.8)); } else if (vip == 3) { System.out.println("实际支付的钱为" + (price * 0.7)); } else { System.out.println("实际支付的钱为" + price); }

price * 0.9 要用括号括起来，否则就是先和前面的字符串拼接了（上一篇讲过：从左到右，有字符串就拼接）。

改进自动驾驶：之前三个独立的 if，每次都要从上往下把三个判断全部执行一遍，效率低。用第三种格式把它们连成一个整体：

if (isLightGreen) { System.out.println("go go go"); } else if (isLightYellow) { System.out.println("slow"); } else if (isLightRed) { System.out.println("stop"); }

只有三种情况，最后的 else 可以省略不写。现在第一个判断为 true 就直接打印 go go go，下面的判断不再执行，提高了效率。

三个独立的 if

if … else if … else if

总结规律：一种情况的判断用第一种格式，两种情况用第二种格式，多种情况用第三种格式。

补充：更正、输出细节和一个小技巧 成绩校验的下限：视频写的是 score > 0，这样考 0 分会被当成"不合法"，应该写 score >= 0。追踪器里用的是改正后的写法。
VIP 的输出：1000 乘 0.9 有小数参与，结果是 double，打印出来是 900.0、800.0、700.0，不是 900；非会员那行打印的是 int，就是 1000。
else if 可以利用顺序省掉一半条件：能走到第二个判断，说明第一个已经是 false（分数不到 95），所以 score >= 90 && score <= 94 可以只写 score >= 90，后面同理。从上往下依次判断，正是 else if 的优势。
第 5 节

小结

流程控制顺序结构（默认，从上往下）、分支结构（if、switch）、循环结构
if 格式一一种情况：判断为 true 执行语句体，false 不执行
if 格式二二选一：true 执行 if 的语句体，false 执行 else 的语句体，执行完就结束
if 格式三多选一：从上往下依次判断，有一个为真就执行并结束；都为假执行 else
注意事项大括号写在行尾；大括号别省略；boolean 变量直接写 if (flag)，别写 ==
校验与嵌套先判断数据是否合法，再做业务判断；if 里还有 if 叫嵌套
一句话 几种情况就选几号格式：一种用 if，两种用 if-else，多种用 if-else if-else；先校验数据，再判断业务。

自测

1. boolean flag = false; if (flag = true) { System.out.println("执行了"); } 会打印吗？
会。flag = true 是赋值不是判断，赋值后小括号里的结果是 true，所以一定执行。判断 boolean 变量应该直接写 if (flag)。
2. if 第二种格式里，执行完语句体1之后还会执行语句体2吗？
不会。if 和 else 只会执行其中一个，执行完整个 if 就结束了，接着执行 if 下面的代码。
3. 影院选座里为什么要在外面再套一个 if？
对数据做合法性校验：只有 1~100 之间的票号才是真实有效的票，才去判断坐左边还是右边；200 这种假票直接不处理。if 里面套 if 叫嵌套。
4. 成绩是 92 时，第三种格式的 if 会判断几次？
外层合法性校验 1 次（true），然后内层：第一个"95~100"为 false，第二个"90~94"为 true，执行"游乐场玩一天"后结束。内层一共判断 2 次，后面的不再判断。
5. 自动驾驶用三个独立的 if 和用 else if 连起来，有什么区别？
三个独立的 if 每次都要把三个判断全部执行一遍，而且如果同时有两盏灯亮，会打印两句；else if 连成一个整体，从上往下只要有一个成立就执行并结束，效率更高，也只会打印一句。
