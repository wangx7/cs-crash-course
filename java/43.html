第 1 节 · P43

switch 的格式与执行流程

老师半夜饿醒，发现了一个人生真理：果然帅不能当饭吃。肚子饿了找妈妈煮面，妈妈会做四种：兰州拉面、武汉热干面、北京炸酱面、陕西油泼面。心里想吃哪种就做哪种。想吃一个不存在的面，比如海鲜龙虾面，妈妈不会做，那就只能吃备胎方便面。核心是：心里想一种面，存在就吃对应的面，不存在就吃方便面，在多种情况里选一个。这就可以用 switch。

switch (表达式) { case 值1: 语句体1; break; case 值2: 语句体2; break; … default: 语句体 n+1; break; }

执行流程：

  1. 先计算小括号里表达式的值。注意它不是一个判断，而是会得到一个具体的结果；
  2. 拿这个结果依次和每个 case 后面的值比较，有对应的值就执行相应的语句体，执行过程中遇到 break 就结束整个 switch；
  3. 所有 case 的值都不匹配，就执行 default 里的语句体，然后结束。

是不是和 if 的第三种格式很像？default 就相当于 if 里的 else，也是个备胎。两者的使用场景放到第 4 节说。

注意点：

  • 表达式：将要匹配的值，结果的类型可以是 byte、short、int、char（没有 long、float、double）；JDK 5 以后可以是枚举（后面学），JDK 7 以后可以是 String（字符串）。
  • case：后面跟的是要和表达式比较的值（被匹配的值）。case 和值之间要有空格，值的后面加冒号。
  • break：中断、结束，用来结束整个 switch。
  • default：所有情况都不匹配时执行，和 else 类似。
  • case 后面的值只能是字面量，不能写变量（非常重要）。
  • case 后面给出的值不能重复（IDEA 里 Ctrl+D 复制出两个一样的 case 会立刻报错）。
String noodles = "兰州拉面"; switch (noodles) { case "兰州拉面": System.out.println("吃兰州拉面"); break; case "武汉热干面": System.out.println("吃武汉热干面"); break; case "北京炸酱面": System.out.println("吃北京炸酱面"); break; case "陕西油泼面": System.out.println("吃陕西油泼面"); break; default: System.out.println("吃方便面"); break; }

想吃兰州拉面，和第一个 case 匹配上；改成陕西油泼面，匹配最后一个 case；改成海鲜龙虾面，都不匹配，打印"吃方便面"。

练习：运动计划。键盘录入星期数（1~7），显示今天的减肥活动：周一跑步、周二游泳、周三慢走、周四动感单车、周五拳击、周六爬山、周日好好吃一顿。键盘录入 week，switch (week) 里写 7 个 case，再加一个 default 打印"没有这个星期"。输入 8 显示"没有这个星期"，输入 3 显示"慢走"。

第 2 节 · P44

default 的位置和省略、case 穿透

default 可以省略：语法没问题，但不建议。省略之后就没有备胎了，所有 case 都不匹配时，没有任何代码执行，switch 直接结束。比如 number = 100，三个 case 是 1、10、20，什么都不打印。

default 的位置：不一定写在最下面，可以写在任意位置，比如挪到最上面，运行结果一样：先拿 number 和每个 case 匹配，都不匹配才执行 default。但这样看着难受，习惯写在最下面。

case 穿透：把所有 break 都注释掉，number 是 1，结果 1、10、20、default 里的四句全都打印了。所以break 千万不能随便省略，否则会导致 case 穿透：

  • 还是先拿表达式的值和每个 case 匹配，匹配上了就执行对应的语句体；
  • 遇到 break 就结束整个 switch；没有遇到 break，程序会继续执行下一个 case 的语句体（不再比较值），一直到遇到 break 或者右大括号为止。default 也是一个特殊的 case，照样会被穿过去。

检验一下：number 改成 10，只打开 case 1 和 case 20 的 break。结果打印哪几句？答案是两句："number 的值为 10""number 的值为 20"。匹配上 case 10，执行完没有 break，往下穿到 case 20，执行完遇到 break 结束。注意：只会往下穿，上面的不会执行。

第 3 节 · P44

新写法：箭头 ->

JDK 12 给 switch 加了新特性（只有装了 12 及以后的版本才能用，8、9、10、11 不行）。标准写法里语句体和 break 很多，看着有点乱。新写法用箭头：

int number = 1; switch (number) { case 1 -> { System.out.println("一"); } case 2 -> { System.out.println("二"); } case 3 -> { System.out.println("三"); } default -> { System.out.println("没有这种选项"); } }

箭头后面的大括号里写要执行的语句体，不用写 break，也不会触发 case 穿透：相当于用大括号把 break 简化掉了。而且大括号里只有一行代码时，大括号可以省略：

switch (number) { case 1 -> System.out.println("一"); case 2 -> System.out.println("二"); case 3 -> System.out.println("三"); default -> System.out.println("没有这种选项"); }

和标准格式比，代码少了很多，运行结果一模一样。switch 还能把结果赋值给一个变量，这个稍难，放到学完方法后再讲。

更正与补充：版本，以及 switch 表达式 箭头写法在 JDK 12、13 里还是"预览功能"，要开启预览选项才能用，JDK 14 起才正式可用。这门课用的 17 当然没问题。
视频说"留到后面讲"的 switch 表达式长这样，可以先认个脸： String type = switch (week) { case 1, 2, 3, 4, 5 -> "工作日"; case 6, 7 -> "休息日"; default -> "没有这个星期"; }; // 注意结尾的分号：整个 switch 是一个"值" 另外，"case 后面只能是字面量"严格说是"只能是编译时就确定的常量"：用 final 修饰并直接赋了值的变量也可以（final 后面会学）。
第 4 节 · P44

switch 和 if 第三种格式，各用在哪

  • if 的第三种格式：一般用于对范围的判断。比如小明的考试成绩 score >= 90 && score <= 100。这种要是用 switch，每个分数都得写一个 case，非常麻烦。
  • switch：把有限个数据一一列举出来，让我们任选其一。比如吃面、运动计划：星期只有 1~7 这七种，全部列出来。用 if 写七个 else if (week == 1) 也能实现，但读起来没有 switch 简洁。

练习一：休息日和工作日。键盘录入星期数，1~5 打印"工作日"，6、7 打印"休息日"。

小结

  

    
      
执行流程算出表达式的值 → 依次和 case 的值比较 → 匹配就执行，遇到 break 结束 → 都不匹配执行 default

      
表达式类型byte、short、int、char；JDK 5 起枚举；JDK 7 起 String。没有 long、float、double

      
case只能是字面量，不能是变量；不能重复

      
default可以省略（不建议）；位置任意，习惯写最下面

      
case 穿透没写 break，匹配后会一直往下执行，直到 break 或右大括号。语句体重复时可以利用它简化

      
新写法case 1 -> 语句;，不用 break、不会穿透；case 1, 2, 3 一个 case 写多个值

      
怎么选范围判断用 if 第三种格式；有限个选项任选其一用 switch

    
  


  

    一句话
    switch 拿一个值去对号入座：对上了就从那里往下执行，遇到 break 才停；箭头写法不用 break，也不会穿透。
  


  

    
自测

    

      
1. switch 小括号里能放 long 类型的变量吗？能放 String 吗？

      
      
long 不行（float、double 也不行）；String 可以，从 JDK 7 开始支持。支持的还有 byte、short、int、char 和枚举。

    

    

      
2. int a = 1; switch (x) { case a: … } 为什么报错？

      
      
case 后面只能写字面量（严格说是编译时常量），不能写普通变量。

    

    

      
3. number = 10，case 1、10、20 和 default 里只有 case 1 和 case 20 写了 break，会打印几句？

      
      
两句：case 10 和 case 20 的语句。匹配上 case 10，执行完没有 break，穿透到 case 20，执行完遇到 break 结束。上面的 case 1 不会执行。

    

    

      
4. 星期 1~5 打印"工作日"、6~7 打印"休息日"，用 case 穿透怎么写？

      
      
case 1: case 2: case 3: case 4: case 5: System.out.println("工作日"); break; case 6: case 7: System.out.println("休息日"); break;，或者 case 1, 2, 3, 4, 5 -> System.out.println("工作日");

    

    

      
5. 根据分数段打印 A/B/C/D 等级，用 switch 还是 if？

      
      
用 if 的第三种格式。这是范围判断，用 switch 得给每个分数写一个 case。
