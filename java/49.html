第 1 节 · P49

无限循环

学习就像闯关，难度是递增的：计算机基础、基础语法、运算符都闯过了，现在继续闯流程控制语句里循环的高级部分。第一个知识点是无限循环，字面意思：循环一直停不下来。它也有三种格式：

for (;;) { // 三条语句都可以不写，两个分号要留着 System.out.println("学习"); } while (true) { // 小括号里的 true 不能省略，否则报错 System.out.println("学习"); } do { System.out.println("学习"); } while (true); // 这里的 true 也不能省略
  • for 格式：初始化语句不写，表示循环前不做任何操作；条件判断语句不写，默认就是 true，循环一直进行；条件控制语句不写，表示每次循环结束后不做任何操作。所以小括号里只剩两个分号。
  • while 和 do…while 格式：小括号里的 true 一定要写。

三种里哪种最常用？先排除几乎不用的 do…while；剩下 for 和 while：知道次数或范围用 for，不知道用 while。无限循环恰恰不知道次数也不知道范围，所以一般用 while (true)。

在 IDEA 里运行，控制台会不停地打印"学习"。要手动停下来，点一下左边的红色小方块（程序运行指示灯，亮着表示程序在运行，按灭就停了）。

注意事项：无限循环的下面不能再写其他代码。循环永远停不下来，下面的代码永远执行不到：

while (true) { System.out.println("给女神表白"); } System.out.println("女神答应我了"); // 报错：无法访问的语句（unreachable statement）

程序都不用运行，这一行就会标红。

Mac 上怎么停 Mac 版 IDEA 一样是点运行窗口左侧（或顶部工具栏）的红色方块，快捷键是 ⌘F2。如果是在终端里用 java 命令运行的程序，按 Control + C 停止。
第 2 节 · P49

跳转控制语句：continue 和 break

实际开发中很少真的让循环一直运行，而是在合适的时候结束它。跳转控制语句就是在循环过程中，跳转到其他语句上执行。

场景一：小老虎吃 5 个包子，吃包子是循环体，吃 5 个就是循环 5 次。但第 3 个包子里有虫子，要跳过：吃第 1 个、第 2 个，第 3 个跳过，接着吃第 4 个、第 5 个。

for (int i = 1; i <= 5; i++) { if (i == 3) { continue; // 结束本次循环，继续下次循环 } System.out.println("小老虎在吃第" + i + "个包子"); }

continue：结束本次循环，继续下次循环。i 等于 3 时进入 if，执行 continue，本次循环里下面的打印就不执行了，直接跳到 i++ 开始第 4 次循环。

场景二：小老虎胃口不好，吃完第 3 个就饱了，第 4、5 个吃不下。这时不能用 continue（它只结束第 3 次，第 4、5 次还会执行），要用 break：结束整个循环，跳到循环外面执行下面的代码。

可如果照着上面的代码把 continue 换成 break，结果只吃了 2 个：i 等于 3 时一进 if 就 break，第 3 次循环里下面的打印走不到了。改法是把打印放到 if 上面：先吃，吃完再判断"已经是第 3 个了"，才跳出。

for (int i = 1; i <= 5; i++) { System.out.println("小老虎在吃第" + i + "个包子"); if (i == 3) { break; // 结束整个循环 } }

动手：小老虎吃包子

小结：continue 叫跳过本次循环（结束本次、继续下次），执行到它时直接跳到 i++；break 是结束整个循环，执行到它时非常粗暴地跳到循环外面，继续执行循环下面的代码。

在 while 里用 continue 要小心 for 循环里 continue 会跳到 i++；但 while 的条件控制语句写在循环体里，如果它在 continue 的下面，就会被一起跳过：int i = 1; while (i <= 5) { if (i == 3) { continue; } … i++; }，i 永远停在 3，变成无限循环。要把 i++ 放到 continue 之前。另外，break 在 switch 里也见过：它们是同一个关键字，作用都是"结束所在的这一层结构"。
第 3 节 · P50

练习：逢七过

接下来用学过的知识写练习，有力扣上的算法真题，有面试题，也有斯坦福大学的 Java 入门练习。第一个是朋友聚会时玩的逢七过：从任意一个数字开始报数，报的数字包含 7或者是 7 的倍数时，不能报这个数，要说"过"。需求：在控制台打印 1~100 之间满足逢七必过规则的数据。

先弄明白"包含 7"：在 1~100 里，个位是 7、十位是 7都算包含 7，再加上7 的倍数，一共三个条件，满足任意一个就说"过"。比如 1 2 3 4 5 6 过 8 9 10 11 12 13 过（14 是 7 的倍数） 15 16 过（17 包含 7） 18 19 20 过……要是大家都没犯错，数到 69 之后，70~79 全是"过"，一直到 80 才能正常报。

  1. 得到 1~100 之间的每一个数字：知道范围，用 for，100.fori 改成从 1 到 <= 100；
  2. 判断每一个数字：符合规则打印"过"，不符合打印数字本身。个位是 7：i % 10 == 7；十位是 7：i / 10 % 10 == 7；7 的倍数：i % 7 == 0。三个条件满足一个就行，用 || 连起来。
for (int i = 1; i <= 100; i++) { if (i % 10 == 7 || i / 10 % 10 == 7 || i % 7 == 0) { System.out.println("过"); continue; // 打印完"过"，下面的数字就不要再打印了 } System.out.println(i); }

i 是 1 时不满足，不进 if，打印 1；2~6 一样。第 7 次循环 i 等于 7，满足条件，打印"过"，然后 continue，下面的打印不再执行，直接跳到 i++，i 变成 8。

动手：1~100 哪些要说"过"

个位是 7十位是 77 的倍数（双色 = 同时满足两条）
超过 100 怎么办 i / 10 % 10 只取十位，数到 170、700 时百位上的 7 就漏掉了。想要任意范围都对，就像上一篇"把数字倒过来"那样，用 while 把每一位都拆出来检查：int t = i; while (t != 0) { if (t % 10 == 7) { 包含 7 } t /= 10; }。
第 4 节 · P51

练习：求平方根（力扣算法题）

需求：键盘录入一个大于等于 2 的整数 x，计算并返回 x 的平方根，结果只保留整数部分，小数部分舍去。

什么是平方根：就是数学里的开根号。16 的平方根是 4，4 的平方根是 2。

思路：求 10 的平方根，从 1 开始一个一个往上试：1 × 1 = 1，小于 10，继续；2 × 2 = 4，小于 10；3 × 3 = 9，还小于 10；4 × 4 = 16，大于 10 了。所以 10 的平方根在 3~4 之间，是三点几，整数部分就是 3（计算器算出来 3.162）。同样，20：4 × 4 = 16 < 20，5 × 5 = 25 > 20，所以是 4（计算器 4.472）。总结成代码的逻辑：从 1 开始循环，拿数字的平方和原来的数比较：

  • 小于：继续往后判断；
  • 相等：当前数字就是平方根；
  • 大于：前一个数字就是平方根的整数部分。
Scanner sc = new Scanner(System.in); System.out.println("请录入一个整数"); int number = sc.nextInt(); for (int i = 1; i <= number; i++) { if (i * i == number) { System.out.println(i + "就是" + number + "的平方根"); break; // 一旦找到，循环就可以停止，提高代码的运行效率 } else if (i * i > number) { System.out.println((i - 1) + "就是" + number + "平方根的整数部分"); break; } // 小于的情况两个分支都不走，直接 i++ 开始下一次循环 }

循环从 1 开始，结束条件写 number 本身就行。录入 10 输出 3，录入 20 输出 4，录入 16 输出 4。这段代码不难，难的是思路，课后先把思路捋顺再写。

第 5 节 · P52

练习：判断质数，标记思想

需求：键盘录入一个正整数 x，判断它是不是质数。

什么是质数：一个整数如果只能被 1 和它本身整除，就是质数，否则叫合数。7 只能被 1 和 7 整除，是质数；8 除了 1 和 8，还能被 2 和 4 整除，是合数。

思路一：写一个循环，从 2 开始，判断到 number − 1，看这个范围里有没有数字能整除 number。有一个，number 就是合数；全都不能，number 就是质数。结束条件写 i <= number - 1 或者 i < number 都行；循环里 i 依次表示范围内的每一个数字，只要看 number % i == 0。一旦能整除，就说明不是质数，后面的数字也没必要判断了，直接 break。

常见错误：在 if 后面加个 else，在 else 里打印"是质数"。比如录入 9：第一次循环 9 % 2 = 1，不等于 0，走 else，直接就说 9 是质数了？后面的 3、4、5…还没判断呢！只有循环结束、范围里所有数字都判断完了，才能断定 number 是质数，所以这句话得写在循环外面。

怎么写？这里介绍一个思想：标记思想。在循环上面定义一个变量做标记，标记 number 是否为质数。它只有两种状态，要么是要么不是，所以用 boolean：true 表示是质数，false 表示不是。

Scanner sc = new Scanner(System.in); System.out.println("请录入一个正整数"); int number = sc.nextInt(); boolean flag = true; // 标记：一开始就认为 number 是质数 for (int i = 2; i < number; i++) { // i 依次表示 2 ~ number-1 里的每一个数 if (number % i == 0) { flag = false; // 遇到能整除的，修改标记 break; // 后面的不用再判断了 } } // 循环结束，范围里的数字都判断完了，才能下结论 if (flag) { System.out.println(number + "是一个质数"); } else { System.out.println(number + "不是一个质数"); }

如果范围里所有数字都不能整除，flag 的值就不会变，还是一开始的 true。录入 7 输出"是一个质数"，录入 16 输出"不是一个质数"。

思路二：优化。要判断 100000 是不是质数，用思路一要从 2 判断到 99999，将近 10 万次循环。能不能少一点？先看一个数能被整除的特点。以 81 为例，它可以拆成 1 × 81、3 × 27、9 × 9。以 81 的平方根 9 为中心，如果 a × b = 81，那 a 和 b 里一定有一个小于等于 9，另一个大于等于 9。不信可以假设两个都大于 9：哪怕都是最靠近的 9.1，9.1 × 9.1 也已经大于 81 了；两个都小于 9，8.9 × 8.9 一定小于 81。

所以循环不必判断到 number − 1，判断到 number 的平方根就够了：如果 2 到平方根之间都没有数能整除 number，它就一定是质数。100000 的平方根约 316，循环次数从近 10 万次降到 316 次。现在还没法用一行代码直接求平方根（要用后面学的知识），所以先听懂思路，代码以后再写。

更正："质因子"应为"因数" 视频把 81 拆成 1 × 81 时说"1 和 81 叫做质因子"。准确地说，1、3、9、27、81 都是 81 的因数（约数）；质因数是因数里的质数，81 只有一个质因数 3。另外，"判断到平方根"现在也能写：不求平方根，把条件改成 i * i <= number 就行，效果一样。还有一个边界：1 不是质数，但上面的代码录入 1 时循环一次都不进，flag 还是 true，会说"1 是一个质数"，严谨的写法要单独判断 number < 2。

第 6 节 · P53

获取随机数：Random

下一个练习是猜数字：程序自动生成一个 1~100 之间的随机数，我们来猜它是多少。先要学怎么生成随机数。Java 已经写好了一个类 Random，使用步骤可以参考以前学的 Scanner，也是三步：

import java.util.Random; // ① 导包：找到 Random 这个类在哪，写在类定义的最上面 Random r = new Random(); // ② 创建对象：打个招呼，我要开始用 Random 了 int number = r.nextInt(范围); // ③ 生成随机数：真正干活的代码

第二步里只有变量名 r 可以变，其他都不能变，但建议 r 也别改，当成固定格式。用 IDEA 的话导包不用自己写，写完第二步它会自动生成 import java.util.Random;。

范围怎么写：小括号里只能写一个数，不是写"0 到 10"。写 10 表示从 0 开始到 9 之间生成随机数（包含 0、包含 9）；写 100 就是 0~99。判断技巧：范围一定从 0 开始，到这个数减 1 结束，口诀"包头不包尾，包左不包右"。视频里用 100.fori 循环生成 100 次 r.nextInt(10)，最大能看到 9、最小能看到 0，没有负数，也没有大于 9 的。

加大难度：生成 1~100。直接写 r.nextInt(101)？不对，那是 0~100。这里有个小秘诀，可以生成任意数到任意数之间的随机数，比如 7~15：

  1. 让这个范围头尾都减去一个值，让它从 0 开始：7~15 都减 7，变成 0~8；
  2. 尾巴 + 1：8 + 1 = 9，写进小括号；
  3. 最终结果再加上第一步减去的值：+ 7。
int number = r.nextInt(9) + 7; // nextInt(9) 是 0~8，统一加 7，就是 7~15 int number = r.nextInt(100) + 1; // nextInt(100) 是 0~99，统一加 1，就是 1~100

第 7 节 · P53

练习：猜数字小游戏

分析：① 生成一个 1~100 之间的随机数；② 键盘录入，猜这个数是多少；③ 判断两个数字，给出不同的提示：猜大了提示"大了"，猜小了提示"小了"，一样就提示"猜中了"。三种情况，所以不能只写 if…else（那是两种情况的），要用 if … else if … else。

写完运行，猜 50，提示"大了"。想接着继续猜，就要用循环改进。用哪种？do…while 先排除；用户猜几次才能中不知道，可能瞎猫碰上死耗子一次就中（1% 的几率），也可能第 100 次才中，次数和范围都不知道，所以用 while (true)，把猜的代码剪切进去，猜中了就 break。

Random r = new Random(); // 注意：生成随机数的代码不能写在循环里面，否则每次都会产生一个新的随机数 int number = r.nextInt(100) + 1; Scanner sc = new Scanner(System.in); while (true) { System.out.println("请输入你要猜的数字"); int guessNumber = sc.nextInt(); if (guessNumber > number) { System.out.println("大了"); } else if (guessNumber < number) { System.out.println("小了"); } else { System.out.println("恭喜你，猜中了"); break; } }

视频里每次猜一半：50 大了，说明在 50 以下；25 小了，在 25~50；35 大了；30 小了，范围压缩到 30~35，再一个个试，32 猜中。

扩展一：随机数写在循环里会怎样？把生成随机数的代码也挪进循环，打印出来看：第一次是 55，猜一次 50 之后，随机数变了！所以生成随机数的代码不能写在循环里面，否则每一次都会产生一个新的随机数。这是一个非常重要的点。

扩展二：保底机制。有些游戏抽奖有保底，比如抽了多少次没中，自动送你一个。猜数字也能加：3 次猜不中，直接提示猜中。在循环外面加一个计数器 count，统计已经猜了多少次；循环里每猜一次 count++，然后判断 count == 3 就提示"猜中了"并 break。视频里打印出随机数是 65，猜 1、2、3，第三次直接"猜中了"，触发了保底。互联网里的这些逻辑其实不难，想明白就很简单。

int count = 0; while (true) { System.out.println("请输入你要猜的数字"); int guessNumber = sc.nextInt(); count++; if (count == 3) { System.out.println("猜中了"); break; } // 下面是原来的大了 / 小了 / 猜中了 … }

小结

无限循环for (;;)、while (true)（最常用）、do {} while (true)；下面不能再写代码
continue结束本次循环，继续下次循环（跳到 i++）
break结束整个循环，跳到循环外面
逢七过i % 10 == 7 || i / 10 % 10 == 7 || i % 7 == 0 → 过，continue
平方根从 1 往上试 i * i：相等就是 i，大于就是 i − 1，找到就 break
标记思想先 boolean flag = true，循环里发现反例改成 false，循环结束后再看 flag 下结论
质数优化只需判断到平方根：因数总是一个 ≤ 平方根、一个 ≥ 平方根
Randomr.nextInt(n) 是 0 ~ n−1；a~b 写 r.nextInt(b - a + 1) + a
猜数字随机数在循环外生成；while (true) 里猜，猜中 break
一句话 不知道要转几圈就写 while (true)，到点了用 break 跳出；continue 只跳过这一圈。

自测

1. for (int i = 1; i <= 5; i++) { if (i % 2 == 0) { continue; } System.out.println(i); } 打印什么？把 continue 换成 break 呢？
continue：1 3 5（偶数被跳过）。break：只打印 1，i 为 2 时整个循环结束。
2. while (true) { … } 里没有 break，后面再写一句打印，会怎样？
编译报错"无法访问的语句"：循环永远停不下来，下面的代码永远执行不到。
3. 判断质数时，为什么不能在 if 的 else 里打印"是质数"？
else 只说明当前这个 i 不能整除，后面的数还没判断。比如 9 % 2 不为 0 就说 9 是质数，但 9 能被 3 整除。要等循环结束再根据标记 flag 下结论。
4. 生成 10~20（包含两头）的随机数，nextInt 的括号里写几？后面加几？
头尾都减 10 变成 0~10，尾巴加 1 得 11，所以 r.nextInt(11) + 10。
5. 求 50 的平方根整数部分，循环会执行到 i 等于几？输出什么？
i = 8 时 64 > 50，输出 7（7 × 7 = 49 < 50），然后 break。
