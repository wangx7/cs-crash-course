第 1 节 · P80

什么是二维数组

很简单：数组里面存的还是数组，最外层的大数组就叫二维数组。之前学的数组叫一维数组，把多个一维数组放到一个大数组里方便管理，这个大数组就是二维数组。有没有三维、四维、五六七八九维数组？有，但几乎用不到，只考虑到二维就可以了。

什么时候用？当我们需要把数据分组管理的时候。

  • 某商场每个季度的营业额（每季度三个月），要计算每个季度的总营业额和全年的总营业额。可以定义四个一维数组，单独存每个季度的营业额，再把四个一维数组放进一个二维数组里统一管理（本篇最后的练习）；
  • 学完面向对象后要做的拼图小游戏：先把大图分成 15 张小图，每张小图对应一个数字；每一行的数字放进一个一维数组，再把四个一维数组放进二维数组统一管理。

第 2 节 · P80

静态初始化

二维数组和一维数组一样，有静态初始化和动态初始化两种方式。先看静态的：

// 完整格式：数据类型[][] 数组名 = new 数据类型[][]{ {元素1, 元素2}, {元素1, 元素2} }; int[][] arr = new int[][]{{11, 22}, {33, 44}}; // 简化格式：省略 new 数据类型[][]，直接写大括号（一般用这个） int[][] arr = {{11, 22}, {33, 44}};

上面的二维数组里存了两个一维数组：第一个装着 11、22，第二个装着 33、44。写一个方括号是一维数组，写两个方括号才是二维数组。最外面的大括号表示二维数组，它里面装的是一维数组，所以每个一维数组也要用大括号括起来，里面才是真正存储的元素；一维数组之间用逗号隔开。

方括号的位置：和一维数组一样，方括号和数组名可以前后对调，int[][] arr 和 int arr[][] 都行，但习惯用前一种。为什么？看《阿里巴巴 Java 开发手册》编程规约里的一条【强制】：中括号是数组类型的一部分，数组定义应该是"数据类型[] 数组名"；"数据类型 数组名[]"是反例。以后自己定义数组，建议按这个约定来。

到 IDEA 里写（类名 TwoDimensionDemo1）。一维数组的长度可以不一样：

int[][] arr1 = new int[][]{{1, 2, 3}, {4, 5, 6, 7, 8}}; int[][] arr2 = {{1, 2, 3}, {4, 5, 6, 7, 8}}; // 以后建议这样定义：把每一个一维数组单独写成一行 int[][] arr3 = { {1, 2, 3}, {4, 5, 6, 7, 8} };

这个二维数组里有两个一维数组，第一个长度是 3，第二个长度是 5。全写在一行不利于阅读，所以一般把每个一维数组单独写一行。注意：每个一维数组其实是二维数组中的元素，所以它们之间要用逗号隔开，而最后一个一维数组后面不加逗号，就像一维数组里最后一个元素后面没有逗号一样。

第 3 节 · P80

获取元素

先猜：对上面的 arr3，System.out.println(arr3[0]); 打印出来是什么？运行一看，是 [I@… 这样一串眼熟的东西：地址值。左边的 [ 表示它是一个数组，I 表示类型是 int，@ 是固定格式，后面是真正的地址值。也就是说，arr3[0] 获取的是二维数组中的第一个一维数组。

想拿里面的元素，后面还要再加一个方括号：arr3[0][0]。可以把 arr3[0] 这个整体看作第一个一维数组，既然是数组，再获取它的 0 索引就行了，结果是 1。

再考一个：arr3[i][j] 要打印出 8，i 和 j 分别写几？8 在第二个一维数组的最后一个位置。二维数组的 0 索引是第一个一维数组，1 索引是第二个，所以 i 写 1；在这个一维数组里，8 在 4 索引，所以 j 写 4。

那 arr3[2][0] 呢？运行报错：ArrayIndexOutOfBoundsException，错误信息是 Index 2 out of bounds for length 2。二维数组里只有两个一维数组，长度是 2，只有 0 索引和 1 索引，没有 2 索引。

公式 arr[i][j]：arr 是二维数组；i 是二维数组的索引，获取出来的是里面的一维数组；j 是一维数组中的索引，获取出来的才是真正的元素。

第 4 节 · P80

遍历二维数组

遍历就是把二维数组里所有的元素都打印出来。思想是：先获取到一维数组，再遍历一维数组，获取到里面的每一个元素。

  • arr3.fori：i 依次表示二维数组中的每一个索引，arr3[i] 就是二维数组中的每一个元素，也就是一维数组；
  • 拿到一维数组还要再遍历它：arr3[i].fori，变量名改成 j，j 表示一维数组中的每一个索引；
  • 打印 arr3[i][j]。

提升难度：希望每个一维数组打印一行，元素之间用空格隔开。把 ln 删掉、拼一个空格，所有元素都跑到同一行了；再在内循环结束之后单独换行，就是想要的效果。

for (int i = 0; i < arr3.length; i++) { // 外循环：遍历二维数组，得到里面的每一个一维数组 for (int j = 0; j < arr3[i].length; j++) { // 内循环：遍历一维数组，得到里面的每一个元素 System.out.print(arr3[i][j] + " "); } System.out.println(); // 内循环结束 = 一个一维数组遍历完毕，换行 }

还是那句话：写循环嵌套要清楚外循环是什么、内循环是什么。

动手：三版打印

两个 length 不是一回事 arr3.length 是二维数组的长度，也就是里面有几个一维数组（2）；arr3[i].length 是第 i 个一维数组的长度（3 和 5）。内循环的条件必须写 arr3[i].length：这个例子里两行不一样长，如果写死成 3，第二行的 7、8 就漏掉了；写死成 5，第一行就会越界。另外，想快速看一眼二维数组的内容，可以用 System.out.println(Arrays.deepToString(arr3));，输出 [[1, 2, 3], [4, 5, 6, 7, 8]]。
第 5 节 · P80

动态初始化

// 数据类型[][] 数组名 = new 数据类型[m][n]; // m：这个二维数组可以存放多少个一维数组（二维数组的长度） // n：每一个一维数组可以存放多少个元素（一维数组的长度） int[][] arr = new int[3][5]; arr[0][0] = 10; // 给二维数组赋值一个元素：把 10 赋给第一个一维数组的 0 索引

这里的 3 表示二维数组长度为 3，可以装三个一维数组；5 表示每个一维数组的长度都是 5，可以装 5 个 int 类型的元素。用上一节的循环嵌套遍历（为什么要有内循环？因为外循环拿不到元素，拿到的只是一维数组），打印结果：没有赋值的位置是默认初始化值 0，赋过值的位置是 10。

第 6 节 · P80

二维数组的内存图

学难一点的：二维数组在内存里到底长什么样。以 int[][] arr = new int[2][3]; 为例：

  • main 方法先进栈，执行第一行。等号左边只是在内存里定义了一个变量：arr 是变量名，int[][] 是数据类型，表示 arr 可以记录 int 类型二维数组的地址值；
  • 等号右边有 new，在堆里给二维数组开辟一块小空间，假设地址值是 0x0011。它有 0、1 两个索引，此时装的是两个默认初始化值 null；
  • 还没完：代码里还指定了一维数组的长度 3，所以内存里还会创建两个长度为 3 的一维数组（假设地址是 0x0022 和 0x0033），再把这两个地址值赋给二维数组的 0 索引和 1 索引；
  • 最后把二维数组的地址值 0x0011 赋给左边的变量 arr，整个二维数组才创建完毕。

所以整体结构可以这么理解：arr 记录的是二维数组，而二维数组的下面又拖了两个一维数组。

  • arr[0]：获取二维数组 0 索引的元素，它记录的是 0x0022，也就是第一个一维数组。所以打印 arr[0] 看到的是数组的地址值；
  • arr[0][1]：先通过 arr[0] 拿到地址值 0x0022，找到第一个一维数组，再通过后面的 1 拿到它 1 索引上的元素：0。

第 7 节 · P80

两种特殊情况的写法

这两种写法知道就可以，不需要掌握。上面演示里的后两段程序就是它们。

特殊情况一：后面的方括号空着不写。

int[][] arr = new int[2][]; // 只创建二维数组，没有创建一维数组，里面是两个 null int[] arr1 = {11, 22}; int[] arr2 = {44, 55, 66}; arr[0] = arr1; // 手动把一维数组的地址值添加给二维数组 arr[1] = arr2;

前面的方括号写 2，表示二维数组的长度；后面的方括号空着，表示此时内存里只创建了二维数组，没有创建一维数组，二维数组里存的是 null。一维数组需要我们手动创建：假设 arr1、arr2 的地址值分别是 0x00aa、0x00bb，arr[0] = arr1 就是把 0x00aa 添加到 0 索引，arr[1] = arr2 把 0x00bb 添加到 1 索引。这样写比较麻烦，但也有好处：自己创建一维数组非常灵活，想要多长就多长，第一个长度是 2、第二个长度是 3 都行。而在第二个方括号里写了固定的数字时，Java 会自动创建一维数组，所有一维数组的长度都一样。

特殊情况二：标准方式创建之后，又换成新的一维数组。

int[][] arr = new int[2][3]; // 标准方式：自动创建了两个长度为 3 的一维数组 int[] arr1 = {11, 22}; int[] arr2 = {44, 55, 66}; arr[0] = arr1; // 0 索引原来记录的 0x0022 被覆盖 arr[1] = arr2; // 1 索引原来记录的 0x0033 被覆盖

把 arr1 记录的 0x00aa 赋给 arr 的 0 索引，原来的 0x0022 就被覆盖了；再把 0x00bb 赋给 1 索引，原来的 0x0033 也被覆盖。二维数组的 0 索引和 1 索引指向了两个新的数组，原来那两个一维数组没人用了，会变成垃圾，从内存中消失。

二维数组学的内容不少，需要掌握的只有四点：① 什么时候用（数据要分组管理时）；② 两种初始化方式；③ 怎么给元素赋值；④ 怎么遍历。

null 是什么，碰到它会怎样 null 是引用数据类型的默认初始化值，意思是"还没有记录任何地址"。二维数组的每个格子装的是一维数组的地址值，属于引用类型，所以默认是 null（一维 int 数组的格子装的是整数，默认才是 0）。在特殊情况一里，如果还没执行 arr[0] = arr1; 就去访问 arr[0][0]，Java 顺着 arr[0] 去找一维数组，却发现里面是 null，没有数组可找，程序会抛出 NullPointerException（空指针异常）。这是 Java 里最常见的异常之一，学了面向对象之后会经常遇到。
第 8 节 · P80

练习：季度营业额

需求：某商场每个季度的营业额如下（单位：万元）。第一季度：22、66、44；第二季度：77、33、88；第三季度：25、45、65；第四季度：11、66、99。要求计算出每个季度的总营业额和全年的总营业额。

分析：要算每个季度的总营业额，得先把四个季度的数据存起来：四个一维数组；为了方便管理，再把它们放到一个二维数组里。

  • 创建二维数组：动态还是静态？不知道要添加的数据用动态，现在数据都知道了，用静态。名字叫 yearArrArr（二维数组用两个 Arr），每个一维数组单独写一行；
  • 定义方法求一个季度的营业额：一个季度就是一个一维数组，所以形参是 int[]，返回求出来的总和；
  • 遍历二维数组，得到每个一维数组（yearArrArr[i]，起名 quarterArr），交给方法求和并打印。提示语里的季度是 i + 1；
  • 全年：在循环外面定义 yearSum，每得到一个季度的营业额，先打印，再累加进去；循环结束后打印。
public static void main(String[] args) { // 1. 创建二维数组并存储数据 int[][] yearArrArr = { {22, 66, 44}, {77, 33, 88}, {25, 45, 65}, {11, 66, 99} }; int yearSum = 0; // 全年的营业额 // 2. 遍历二维数组，得到每一个一维数组并求和 for (int i = 0; i < yearArrArr.length; i++) { int[] quarterArr = yearArrArr[i]; // 二维数组的每一个元素，就是一维数组 int sum = getSum(quarterArr); System.out.println("第" + (i + 1) + "个季度的总营业额为：" + sum); yearSum = yearSum + sum; } System.out.println("全年的总营业额为：" + yearSum); // 641 } // 求一个季度（一个一维数组）的总营业额 public static int getSum(int[] arr) { int sum = 0; for (int i = 0; i < arr.length; i++) { sum = sum + arr[i]; } return sum; }

字幕里只念出了第二季度的 77、33、88 和最后的结果 641 万元；其余三个季度的数字取自这道题通行的版本，四个季度加起来正好是 641。

动手：改改数字

这里的 getSum 和 P66 的 getSum 学带返回值的方法时也算过季度营业额，那时的方法是 getSum(int num1, int num2, int num3)，三个月写成三个形参，main 里要手写四次调用、四个变量。现在数据装进了二维数组，方法收一个一维数组，main 里一个循环就把四个季度都处理了；哪天一个季度变成四个月，或者要算八个季度，只改数据，代码一行不用动。这就是"把数据分组管理"带来的好处。
第 9 节

小结

二维数组数组里存的还是数组；需要把数据分组管理时用
静态初始化int[][] arr = {{1, 2, 3}, {4, 5, 6, 7, 8}};，每个一维数组建议单独写一行，长度可以不同
动态初始化new int[m][n]：m 个一维数组，每个长度 n，默认值 0
取元素arr[i] 是第 i 个一维数组（打印是地址值）；arr[i][j] 才是元素
遍历外循环 i < arr.length 得到一维数组，内循环 j < arr[i].length 得到元素
内存变量记录二维数组的地址；二维数组的格子里记录各个一维数组的地址
特殊写法new int[2][] 只建二维数组（格子是 null），一维数组自己建、自己放；放进新数组后旧的没人用就成了垃圾
一句话 二维数组就是"装着数组的数组"：第一个方括号挑出一个一维数组，第二个方括号才挑出元素。

自测

1. int[][] arr = {{1, 2, 3}, {4, 5, 6, 7, 8}};，arr.length、arr[1].length、arr[1][2] 分别是多少？
2（有两个一维数组）、5（第二个一维数组的长度）、6（第二个一维数组的 2 索引）。
2. 对上面的数组，System.out.println(arr[0]); 打印的是什么？arr[2][0] 呢？
arr[0] 是第一个一维数组，打印的是它的地址值（[I@ 加一串十六进制数）。arr[2][0] 报 ArrayIndexOutOfBoundsException：二维数组长度是 2，没有 2 索引。
3. 遍历二维数组时想让每个一维数组占一行，换行的 System.out.println(); 写在哪？
写在内循环结束之后、外循环的循环体里。内循环结束表示一个一维数组遍历完了，这时换行。
4. int[][] arr = new int[3][5]; 一共在堆里创建了几个数组？
4 个：1 个长度为 3 的二维数组，加上 3 个长度为 5 的一维数组。二维数组的三个格子里分别记录三个一维数组的地址值。
5. new int[2][] 和 new int[2][3] 有什么区别？
前者只创建二维数组，两个格子都是 null，一维数组要自己创建再赋进去（长度可以各不相同）；后者由 Java 自动创建两个长度都是 3 的一维数组。
