练习一：卖飞机票

今天是专题课：不学新内容，写很多比较有难度的练习，目的是复习前面的 Java 知识、学会用它们解决问题，同时提高编程能力。九道练习有的来自斯坦福大学的 Java 入门练习，有的是力扣上的算法题，还有一些是大厂的面试真题。很多同学觉得自己编程没有思路，是因为编程思维和编程能力还没建立，这不是一朝一夕的事，需要时间沉淀和大量练习。记住一句话：先模仿，再创新。

需求：机票价格按照淡季旺季、头等舱和经济舱收费。键盘录入机票原价、月份、头等舱或经济舱，按下面的规则计算机票价格：

头等舱
经济舱
旺季（5 ~ 10 月）
9 折
8.5 折
淡季（11 月 ~ 来年 4 月）
7 折
6.5 折

分析：没有思路就读题。

  1. 键盘录入三样东西：机票原价、月份、头等舱或经济舱；
  2. 先判断月份是旺季还是淡季；
  3. 继续判断当前机票是经济舱还是头等舱；
  4. 根据实际情况计算出对应的价格。

几个细节：

  • 原价用整数：可以认为是小数，也可以认为是整数。坐飞机时很少见到几毛钱的机票，至少以元为单位，所以用 nextInt。
  • 舱位用 0 和 1 表示：0 头等舱，1 经济舱。用 true / false 行不行？行，但它只有两种情况，万一以后需求变更要加一个商务舱就搞不定了。用数字，以后再加 2、3、4、5 都能表示，扩展性更好。
  • 淡季是两段：1~4 月，以及 11~12 月。两个条件满足一个就行，中间用"或者"。先看中间的 ||，左边看作第一个条件，右边看作第二个条件。
  • 要强转：ticket * 0.9 是小数，不能直接赋给 int 变量，要写 (int) (ticket * 0.9)。后面的小括号千万不能省，省了强转的就只是 ticket。
Scanner sc = new Scanner(System.in); System.out.println("请输入机票的原价"); int ticket = sc.nextInt(); System.out.println("请输入当前的月份"); int month = sc.nextInt(); System.out.println("请输入当前购买的舱位 0 头等舱 1 经济舱"); int seat = sc.nextInt(); if (month >= 5 && month <= 10) { // 旺季 if (seat == 0) { ticket = (int) (ticket * 0.9); } else if (seat == 1) { ticket = (int) (ticket * 0.85); } else { System.out.println("没有这个舱位"); } } else if ((month >= 1 && month <= 4) || (month >= 11 && month <= 12)) { // 淡季 if (seat == 0) { ticket = (int) (ticket * 0.7); } else if (seat == 1) { ticket = (int) (ticket * 0.65); } else { System.out.println("没有这个舱位"); } } else { System.out.println("键盘录入的月份不合法"); } System.out.println(ticket);

运行两次：原价 1000、3 月、经济舱（像我们这种身份，一定是坐经济舱的），3 月是淡季，打 6.5 折，650；原价 2000、10 月、头等舱，旺季头等舱 9 折，1800。

动手：算一张机票

试试：2000 元、10 月、头等舱 · 700 元、12 月、头等舱 · 13 月
小数乘法加强转的坑：700 元打 7 折是 489？ 上面演示里点"700 元、12 月、头等舱"，结果是 489，不是 490。原因是 0.7 这样的小数在计算机里没法用二进制精确表示，700 * 0.7 算出来是 489.99999999999994，而 (int) 强转是直接砍掉小数部分，不是四舍五入。原价是 10 的倍数时，100 到 5000 之间有 69 个这样的价格（170、180、330、650、700……）。两种修法：四舍五入 (int) Math.round(ticket * 0.7)；或者全程用整数算，把折扣写成"百分之几"：ticket * 70 / 100。算钱尽量不要用 double，课程后面会学专门的 BigDecimal。
另外两个小地方 ① 淡季的条件里，两对小括号可以不写：&& 的优先级比 || 高，会先算两边的"并且"。但像视频这样写上更好读。② 月份或舱位不合法时，程序打印完提示还会接着执行最后一行，把原价打印出来，容易让人误以为那是算好的票价。更稳妥的做法是录入不合法就不再打印价格（比如用后面"评委打分"里学的办法让用户重输）。

优化：把重复的判断抽取成方法

代码还有优化之处：旺季里判断舱位的那一段，和淡季里的那一段，非常类似。为了提高代码的复用性，把它们抽取成一个方法，main 里直接调用。方法怎么写？还是问自己三个问题：

① 我要干嘛？看要抽取的那段代码在干嘛：根据舱位和折扣，计算最终的票价决定方法体
② 需要什么才能完成？原价（原价都不告诉我，我算个毛）、舱位、头等舱的折扣、经济舱的折扣四个形参
③ 调用处是否要用结果？要：调用处要把最终价格交给变量再打印必须有返回值，int
if (month >= 5 && month <= 10) { ticket = getPrice(ticket, seat, 0.9, 0.85); // 旺季 } else if ((month >= 1 && month <= 4) || (month >= 11 && month <= 12)) { ticket = getPrice(ticket, seat, 0.7, 0.65); // 淡季 } else { System.out.println("键盘录入的月份不合法"); } System.out.println(ticket); // v0：头等舱的折扣，v1：经济舱的折扣 public static int getPrice(int ticket, int seat, double v0, double v1) { if (seat == 0) { ticket = (int) (ticket * v0); } else if (seat == 1) { ticket = (int) (ticket * v1); } else { System.out.println("没有这个舱位"); } return ticket; }

以后题目变了，比如把 11、12 月单独叫"过渡季"，折扣又不一样，只要再加一个 else if，里面还是调用 getPrice，不用再写那一串判断。

两个 IDEA 快捷键：

  • Ctrl + P：光标放在调用方法的小括号里按一下，可以看到形参的顺序（忘了四个参数谁先谁后时用）；
  • Ctrl + Alt + M：自动抽取方法。选中要抽取的代码按快捷键，IDEA 会提示"方法里还有其他地方有重复的代码，要不要一起抽取"、"要不要用调用方法的形式去替换"，都选是。它抽出来的方法前面写的是 private（面向对象时会学），先改成 public 就行，其余和手写的几乎一模一样。

课后两种都要练：先手动抽取，自己分析形参、方法体、返回值；等熟了，再用快捷键。

Mac 上的快捷键 查看形参 Ctrl+P → ⌘P；抽取方法 Ctrl+Alt+M → ⌥⌘M；本篇后面还会用到：批量改名 Shift+F6 → ⇧F6（MacBook 上可能要同时按 fn）。

练习二：找质数

需求：判断 101 ~ 200 之间有多少个素数，并输出所有素数。（素数和质数是一回事，只是两个称呼。）

这题之前做过类似的：给定一个数，判断它是不是质数。当时有两个思路：思路一，循环判断 2 到"这个数减 1"之间有没有数字能把它整除；思路二，因为思路一在数字很大时循环次数太多，只判断到平方根就够了，但那时还没学怎么取平方根，只要求了解。这里还是用思路一。

一下子写成最终代码会有点懵，所以先把题目改简单：写出判断单个数字的代码，再加上范围。

// 第一步：判断一个数 i 是否为质数 int i = 100; boolean flag = true; // 标记：一开始认为 i 是质数 for (int j = 2; j < i; j++) { // 变量名不能再叫 i 了；j 依次表示 2 ~ 99 if (i % j == 0) { flag = false; // 遇到能整除的，就不是质数 break; } } if (flag) { System.out.println("当前数字是质数"); } else { System.out.println("当前数字不是质数"); }

100 运行出来不是质数，改成 7 是质数，说明判断单个数字的代码没问题。再加范围：外面套一个循环，i 从 101 到 200（不放心可以先只打印 i，看看是不是 101、102、103……一直到 200）。i 依次表示范围里的每一个数字，那么在循环里判断 i 是不是质数就行了，直接把刚才的代码粘进来（注意别把上面的 int i = 100; 也粘进来）。不是质数就不用打印了。题目还问"有多少个"，再加一个统计变量。

int count = 0; // 统计有多少个质数 for (int i = 101; i <= 200; i++) { // 外循环：得到范围里的每一个数字 boolean flag = true; for (int j = 2; j < i; j++) { // 内循环：判断当前数字是否为质数 if (i % j == 0) { flag = false; break; // 跳出单层循环，也就是内循环 } } if (flag) { System.out.println("当前数字" + i + "是质数"); count++; } } System.out.println("一共有" + count + "个质数"); // 21

结果：101、103、107、109、113、127、131……一共 21 个。这题有两个难点：

  • break 跳出的是哪个循环？break 跳出单层循环，这里跳的是内循环。内循环结束后判断 flag，外循环的这一轮循环体就执行完了，i++，接着判断下一个数字。
  • 循环的嵌套。以后每次写循环嵌套，都要能清楚地说出哪一层循环干了什么事。这题里：外循环遍历 101 ~ 200，依次得到范围内的每一个数字；内循环判断当前数字是否为质数，为此要从 2 开始、到这个数减 1 结束再循环一遍。

动手：点一个数，看内循环怎么判断它

~
两层循环一共转了多少圈 演示最下面会数出内循环体总共执行的次数。101 ~ 200 用思路一是 3291 次：合数很快就 break（偶数第一圈就走了），而 21 个质数每个都要从 2 一直试到自己减 1，占了其中的绝大部分。这就是"思路二"值得学的原因：只试到平方根，质数也只要试十来次，总数能降到 392 次。等学了 Math.sqrt 之后，把内循环的条件改成 j <= Math.sqrt(i) 即可；现在不用库函数的写法是 j * j <= i。

练习三：开发验证码

需求：定义方法实现随机产生一个 5 位的验证码。格式：长度为 5；前四位是大写字母或者小写字母；最后一位是数字。

核心是随机。可大写字母、小写字母没有什么规律，怎么随机？分享一个技巧：

编程技巧 要在一堆没有什么规律的数据中随机抽取，可以先把这些数据放到数组里，再随机抽取一个索引。数组的索引是有规律的：从 0 开始，连续、逐个加一、中间不间断。
  1. 把大写字母和小写字母都放到数组当中（数字不放进去，前四位没有数字）；
  2. 随机抽取 4 次：随机的是数组的索引，再用索引拿到对应的元素；
  3. 随机抽取一个 0 ~ 9 的数字，拼在最后。

第一步是难点。直接写 char[] chs = {'a', 'b', 'c', …} 一路排下去可以，但要敲好久，不推荐。换个办法：先创建长度 52 的数组 new char[52]，再用循环往里放。回忆 ASCII 码表：数字和字母是一一对应的，把 97 强转成 char 就是 'a'，98 是 'b'。所以写 chs[i] = (char) (97 + i);：i 是 0 时 97 + 0 强转是 a，放在 0 索引；i 是 1 时 98 是 b……

这样跑完，0 ~ 25 索引是 a ~ z，可后面跟着一堆乱七八糟的东西。所以加个判断：i ≤ 25 时添加小写字母；否则添加大写字母。大写 A 对应 65，但不能写 65 + i：i 到 26 才开始放大写字母，65 + 26 转出来就不是 A 了。所以要再减 26：i = 26 时 65 + 26 − 26 = 65，是 A；i = 27 时是 66，B。

// 1. 大写字母和小写字母都放到数组当中 char[] chs = new char[52]; for (int i = 0; i < chs.length; i++) { if (i <= 25) { chs[i] = (char) (97 + i); // 添加小写字母，a 是 97 } else { chs[i] = (char) (65 + i - 26); // 添加大写字母，A 是 65 } } // 2. 随机抽取 4 次 String result = ""; // 记录最终的结果，一开始是长度为 0 的字符串 Random r = new Random(); for (int i = 0; i < 4; i++) { int randomIndex = r.nextInt(chs.length); // 随机索引 0 ~ 51 result = result + chs[randomIndex]; // 利用随机索引获取元素，拼接上去 } // 3. 随机抽取一个数字 0 ~ 9 int number = r.nextInt(10); result = result + number; System.out.println(result);

第二步也是先做简单的：先随机一次并打印（o、c、q……每次都不一样），再套上循环 4 次。四个字母要拼在一起，所以定义字符串变量 result，初始值是 ""（长度为 0、什么都没有的字符串）。result = result + 字符 的过程：一开始 result 是空的，随机到 a，拼出新的字符串 "a"，再赋回给 result，原来的被覆盖；下一次在 "a" 的后面再拼一个。

想让数字的位置也随机？等后面学完字符串那一章再回来改写，现在先完成当前的需求。

动手：52 个格子，随机 4 个索引

不用背 97 和 65 char 参与运算时本来就会变成它在码表里的数字，所以可以直接拿字符来算：(char) ('a' + i)、(char) ('A' + i - 26)，意思一目了然。另外演示里"只写 (char)(97 + i)"时后 26 格显示的 { | } ~ 等就是视频里说的"乱七八糟的东西"：码表上 z（122）后面紧挨着的符号，再往后是不可见的控制字符。

练习四：数组元素的复制

需求：把一个数组中的元素复制到另一个新数组中去。比如老数组是 1、2、3、4、5，复制到新数组里也应该是 1、2、3、4、5。

  1. 定义一个老数组并存储一些元素；
  2. 定义一个新数组，长度跟老数组一致；
  3. 遍历老数组，得到每一个元素，依次存入新数组。
int[] arr = {1, 2, 3, 4, 5}; int[] newArr = new int[arr.length]; // 长度和老数组一致 for (int i = 0; i < arr.length; i++) { // i 表示老数组中的索引，同时也是新数组中的索引；arr[i] 表示老数组中的元素 newArr[i] = arr[i]; } for (int i = 0; i < newArr.length; i++) { System.out.println(newArr[i]); }

这题的难点就是循环里的 i：因为老数组和新数组等长，所以 i 同时表示老数组的索引和新数组的索引。把老数组 0 索引的值存到新数组的 0 索引，i++，再把 1 索引的存到 1 索引，一个一个挨着存。

为什么不直接写 int[] newArr = arr; 那样并没有复制任何元素。上一篇讲过：数组变量里存的是地址值，newArr = arr 只是让两个变量指向堆里的同一个数组，改 newArr[0]，arr[0] 也跟着变。这道题用 new 开辟了第二块空间，再把数据一个个搬过去，两个数组才互不影响。对比上上篇的 copyOfRange：那里只拷贝一段，新老数组不等长，所以才需要另外伪造一个 index。

练习五：评委打分

需求：在唱歌比赛中，有 6 名评委给选手打分，分数范围是 [0, 100] 之间的整数。选手的最后得分为：去掉最高分、最低分后的 4 个评委的平均分。请完成上述过程并计算出选手的得分。

  1. 定义一个数组，用来存储 6 名评委的打分（键盘录入，0 ~ 100）；
  2. 求出数组中的最大值；
  3. 求出数组中的最小值；
  4. 求出数组中 6 个分数的总和；
  5. （总和 − 最大值 − 最小值）÷ 4；
  6. 打印结果。

步骤比较多，用方法一个一个做。最难的是第一步。先用三个问题设计它：要干嘛？定义数组存 6 名评委的打分。需要什么？什么都不需要，数组可以在方法里创建，键盘录入也写在方法里，所以无参。要不要返回？下面还要用这个存满分数的数组，必须返回，返回值类型写 int[]（只写 int 表示返回一个整数）。

核心代码很快就能写出来：动态初始化 new int[6]，循环里 nextInt 录入、存到 i 索引。测试 100、100、100、50、100、60，没问题。但录一个 120 呢？它也被存进了数组，这不是我想要的。于是加判断：分数在 0 ~ 100 之间才存。再测：连录六个 120，数组里是六个 0，而且程序也没让我重新输。为什么？

i 是 0 时录了 120，不满足 if 的条件，没存；然后循环照常 i++，i 变成 1，相当于把 0 索引跳过去了。改法很简单：把 i++ 从 for 的小括号里拿走，放到 if 的里面。条件控制语句空着不写，表示 i 不会自己变化；只有录了合法的数据、成功存进去，i 才 ++。录入不合法，i 还是原来的值，下一圈让你对着同一个索引再录一次。

public static int[] getScores() { int[] scores = new int[6]; Scanner sc = new Scanner(System.in); for (int i = 0; i < scores.length; ) { // 小括号里没有 i++ System.out.println("请输入评委的打分"); int score = sc.nextInt(); if (score >= 0 && score <= 100) { scores[i] = score; i++; // 成功存进去了，索引才移动 } else { System.out.println("成绩超出了范围，继续录入，当前的i为：" + i); } } return scores; }

动手：当一回评委

一键录入：100 50 80 80 80 80 · 六个 120

后面几步难度不大。求最大值、最小值、总和各写一个方法，都需要你把数组给我，都要返回结果：

public static void main(String[] args) { int[] scoresArr = getScores(); // 1. 录入 6 个分数 int max = getMax(scoresArr); // 2. 最大值 int min = getMin(scoresArr); // 3. 最小值 int sum = getSum(scoresArr); // 4. 总和 int avg = (sum - max - min) / (scoresArr.length - 2); // 5. 平均分 System.out.println("选手的最终得分为：" + avg); // 6. 打印 } public static int getMax(int[] scoresArr) { // 求数组的最大值 int max = scoresArr[0]; // 初始值一定要是数组里的元素 for (int i = 1; i < scoresArr.length; i++) { if (scoresArr[i] > max) { max = scoresArr[i]; } } return max; } public static int getMin(int[] scoresArr) { // 复制 getMax，改名字，> 改成 < int min = scoresArr[0]; for (int i = 1; i < scoresArr.length; i++) { if (scoresArr[i] < min) { min = scoresArr[i]; } } return min; } public static int getSum(int[] scoresArr) { // 求总和 int sum = 0; for (int i = 0; i < scoresArr.length; i++) { sum = sum + scoresArr[i]; } return sum; }

两个小技巧：

  • 批量改名 Shift + F6：getMin 是复制 getMax 来的，把变量 max 改成 min 时不用一个个改。选中 max 按 Shift + F6，再改成 min，下面凡是用到这个变量的地方都跟着一起改。
  • 值能不写死，尽量不写死：第五步除以 4 就是写死了。建议写 scoresArr.length - 2（减去一个最大的、一个最小的），以后数组长度变了，这行不用改。

测试：最高分 100、最低分 50，其余四个 80，最终得分 80。这道题不算很难，注意两处：一是录入时的判断，不合法就不存，而且索引不动；二是步骤多，写之前一定把思路捋顺。

平均分是整数除法 avg 是 int，(sum - max - min) / 4 会直接丢掉小数部分。比如打分 90、91、92、93、94、95，去掉 95 和 90 剩 370，370 / 4 得 92，真实的平均分是 92.5。演示里录完六个分数后会同时显示两种结果。想保留小数，把其中一边变成小数即可：double avg = (sum - max - min) * 1.0 / (scoresArr.length - 2);。另外，如果有两位评委都打了最高分，按规则也只去掉其中一个，上面的代码正好就是这个效果。

自测

1. 舱位为什么用 0、1 表示，而不用 boolean？
boolean 只有 true、false 两种情况；以后要加商务舱等其他舱位，数字可以接着用 2、3、4……扩展性更好。
2. ticket = (int) ticket * 0.9; 为什么不行？
少了后面的小括号，强转的只是 ticket，乘 0.9 之后结果还是小数，不能赋给 int 变量，编译报错。要写 (int) (ticket * 0.9)。
3. 找质数的代码里，外循环和内循环各干了什么事？内循环里的 break 跳出的是谁？
外循环遍历 101 ~ 200，依次得到每一个数字；内循环从 2 到这个数减 1，判断当前数字是否为质数。break 只跳出内循环，然后外循环继续判断下一个数字。
4. 往 chs 数组里放大写字母时，为什么是 (char) (65 + i - 26)？
前 26 个位置（i 为 0 ~ 25）放了小写字母，i 从 26 才开始放大写。i = 26 时要得到 A（65），所以要把多出来的 26 减掉：65 + 26 − 26 = 65。
5. 录入评委打分时，for (int i = 0; i < scores.length; i++) 配上"合法才存"的 if，连续录入 120、90 会怎样？怎么改？
120 不合法没存，但 i 照样 ++，0 索引被跳过（留着默认值 0），90 存进了 1 索引。改法：把 i++ 从小括号里拿走，放进 if 里，只有成功存入时索引才移动。
