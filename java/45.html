第 1 节 · P45

什么是循环，for 循环的格式和执行流程

循环，顾名思义就是重复地做某件事，而且有明确的开始和停止标记。比如电风扇：按下 Open，叶子开始一直重复地转；按下 Stop，就停了。Open 是循环的开始标记，Stop 是停止标记。

Java 里的循环一共三种：for、while、do…while。前两个要重点掌握；do…while 简单了解就行，以后几乎不会用。先学 for：

for (初始化语句; 条件判断语句; 条件控制语句) { 循环体语句; // 要重复执行的代码 }

小括号里有三条语句，用分号隔开；大括号里是循环体。比如重复打印 10 次 HelloWorld：

for (int i = 1; i <= 10; i++) { System.out.println("HelloWorld"); }

简单理解：用变量 i 控制循环的次数，从 1 开始、到 10 结束，每次循环 i 自增一次，一共 10 次。详细的执行流程是：

  1. 执行初始化语句（int i = 1）；
  2. 执行条件判断语句（i <= 10），看结果是 true 还是 false：false 就结束循环，去执行循环后面的代码；true 就进入大括号，
  3. 执行循环体（打印 HelloWorld）；
  4. 执行条件控制语句（i++）。到这里第一轮结束，回到第 2 步，从条件判断开始下一轮。

一轮一轮这么执行下去，直到判断结果是 false，循环才结束。要记住两个核心：

  • 初始化语句只执行一次，它是循环的开始；
  • 判断为 true，说明还没到循环的末尾，循环继续；判断为 false，说明到末尾了，循环结束。

动手：for 循环单步执行

选一个练习，一步一步点"下一步"，看程序此刻执行的是哪条语句、变量怎么变。本页后面的练习都在这里，可以学到哪一节就回来跑哪一个；开始、结束的数字也能改。

开始 结束

练习：打印 5 次 HelloWorld。打印 5 次，就用变量 i 从 1 数到 5。写 for 的时候如果忘了三条语句，可以先在小括号里打两个分号，再一个一个补：第一个是初始化语句（循环的开始），中间是条件判断语句（判断变量有没有到循环的结束），第三个是条件控制语句（每次循环结束后变量怎么变，大多数时候 i++ 就行）。写成 int i = 1; i <= 5; i++。中间写成 i < 6 也可以，同样是 1 到 5，只是 <= 5 更好理解。

想打印 10 次、20 次、50 次？只要改结束条件。改成 10，循环就从 1 到 10，打印 10 次。

第 2 节 · P45

正着、倒着打印数字，断线重连

练习：输出数字。打印 1 2 3 4 5，再倒着打印 5 4 3 2 1。

写循环先想清楚：从几开始，到几结束。正着打印从 1 开始、到 5 结束，所以是 int i = 1; i <= 5; i++。循环体打印谁？第一次循环 i 是 1（初始化时赋的值），第二次 i 已经 ++ 过一次，变成 2……i 在循环里的变化正好是 1、2、3、4、5，所以直接打印 i 就行。

倒着打印，开始条件变成 5、结束条件变成 1，由大变小，所以判断要写 >=，条件控制也不能写 i++，要写 i--：

for (int i = 1; i <= 5; i++) { // 正着：1 2 3 4 5 System.out.println(i); } for (int i = 5; i >= 1; i--) { // 倒着：5 4 3 2 1 System.out.println(i); }

练习：断线重连。实际开发中，需要重复执行的代码一般都用循环实现。比如玩游戏网不好时会断线重连，断线重连就是重复执行的；公司要求重连次数不能太多，最多 5 次。游戏和服务器还没学，重连的业务逻辑先用一句输出代替：

for (int i = 1; i <= 5; i++) { System.out.println("第" + i + "次执行断线重连的业务逻辑"); }

本来只打印"执行断线重连的业务逻辑"，想看到当前是第几次，就把 i 拼进字符串：第一次循环 i 是 1，打印"第1次执行……"，然后 i++ 变成 2，打印"第2次执行……"，一共 5 次。以后写开发或综合练习时，需要重复执行某段代码，就用循环。

IDEA 快速生成 for 视频在第 5 节用了一个快捷方式：写循环次数再加 .fori，比如 100.fori 回车，生成 for (int i = 0; i < 100; i++)，再把开始、结束条件改成需要的样子。同理 100.forr 生成倒着数的 for (int i = 100; i > 0; i--)。直接打 fori 回车也能出一个空架子。
第 3 节 · P46

累加思想：求 1~5 的和

前面的练习说白了只是打印语句，从这里开始加大难度。实际开发中，要获取一个范围里的数据时也会用到循环。求 1~5 之间的和，怎么做？

思路：先要能拿到 1、2、3、4、5 这五个数；再定义一个初始值为 0 的变量，把每个数依次累加进去：加 1 变成 1，加 2 变成 3，加 3 变成 6，加 4 变成 10，加 5 变成 15。15 正好是五个数的总和。这是 Java 程序里第一个比较重要的思想：累加思想。

  1. 循环 1 到 5，得到里面的每一个数字（先在循环体里打印 i 看看，确实都拿到了）；
  2. 在循环外面定义变量 sum，专门用来累加；
  3. 循环里把拿到的数字累加进 sum：拿 sum 原来的值和当前数字相加，结果再赋值给 sum；
  4. 循环结束，就表示 1~5 都已经累加到 sum 里了，在循环下面打印 sum。
int sum = 0; for (int i = 1; i <= 5; i++) { sum = sum + i; // 也可以简写成 sum += i; } System.out.println(sum); // 15

第一次循环 i 是 1、sum 是 0，0 + 1 = 1 赋给 sum；第二次 i 是 2、sum 是 1，1 + 2 = 3 赋给 sum……就这样一个一个累加。sum = sum + i 可以用之前学的加等运算符简写成 sum += i。

要算 1~100 的和，只要把结束条件改成 i <= 100，结果 5050。这个数是对的，很久以前数学家高斯就已经帮我们算过了。（在上面的单步执行里选"求和"，结束改成 100，点"直接跑完"试试。）

高斯的算法 1 + 100、2 + 99、3 + 98……每一对都是 101，一共 50 对，所以和是 101 × 50 = 5050，也就是公式 n(n+1)/2。循环的好处是不用想公式，换成"1~100 里 3 的倍数之和"这种不好套公式的题也照样能算。
第 4 节 · P46

扩展：sum 为什么不能定义在循环里面

如果把累加的变量 sum 定义在循环的里面，代码还能正常运行吗？这就说到了学变量时留的一个坑：变量的作用范围。

变量只在所属的大括号中有效。sum 定义在循环外面，它属于 main 方法的大括号，在整个 main 里都能用；定义在循环里面，就只在循环的大括号里有效，循环下面打印 sum 已经出了大括号，超出作用范围，直接报错。

那把输出语句也挪进循环里呢？能运行，但结果不对：打印出来的是 1、2、3、4、5，不是累加的结果。因为：定义在循环里的变量只在本次循环中有效，本次循环结束（碰到循环的右大括号），变量就从内存中消失；下一轮循环开始时，又会重新定义一个新的 sum，又是 0。第一轮 0 + 1 = 1，打印 1；第二轮重新定义 sum = 0，0 + 2 = 2，打印 2……

动手：sum 放在哪


  


  
这个过程有点绕，记结论就行：累加求和的变量，定义在循环的外面。这样不管循环 100 次还是多少次，用的都是同一个 sum，它不会在内存里反复消失又创建。

  

    循环变量 i 也一样
    for (int i = 1; …) 里定义的 i，作用范围也只是这个 for 循环，循环结束后在下面写 System.out.println(i); 同样会报错。所以两个 for 循环可以各自定义一个 i，互不冲突（第 2 节正着、倒着打印就是这么写的）。

求 1~100 的偶数和：循环和其他语句结合

  
难度再加一丢丢。获取一个范围里的数据时，大多数情况不是要全部数据，而是要符合要求的数据，这就需要循环和其他语句结合使用。比如求 1~100 之间的偶数和。

  
    
    
  1. 获取 1~100 之间的每一个数（用 100.fori 生成循环，开始改成 1、结束改成 <= 100）；
    2. 
    
  2. 累加求和，但不是直接加，要先判断，再求和：符合要求（偶数）的才加，奇数就不要了，直接 i++ 找下一个数。
    3. 
  

  int sum = 0;
for (int i = 1; i <= 100; i++) {
    if (i % 2 == 0) {     // 对 2 取余为 0，就是偶数
        sum = sum + i;
    }
}
System.out.println(sum);   // 2550
  
结果 2550。这个练习的核心是：循环里还可以写其他的语句，比如 if。

  

    另一种写法
    偶数本来就是隔一个一个，也可以让 i 从 2 开始、每次加 2，不用判断：for (int i = 2; i <= 100; i += 2) { sum += i; }。条件控制语句不一定是 i++，写成什么都可以，只要最后能让判断变成 false。
  







  
第 6 节 · P46

  
统计思想：既能被 3 整除又能被 5 整除的数有几个

  
需求：键盘录入两个数字，表示一个范围（比如 1 和 100）。统计这个范围中既能被 3 整除、又能被 5 整除的数字有多少个。还记得学自增运算符时说过的吗：以后要统计某样东西有多少个，就会用到自增。

  
分析：

  
    
    
  1. 键盘录入两个数字 start、end；
    2. 
    
  2. 利用循环获取这个范围中的每一个数字：开始条件是 start，结束条件是 end（可以写 end.fori 再改）；先打印 i 看看，录入 10 和 15 时确实拿到了 10~15；
    3. 
    
  3. 对每一个数字进行判断，统计有多少个满足要求。"能被 3 整除"就是 i % 3 == 0（余数为 0），"能被 5 整除"是 i % 5 == 0。题目说"既能……又能……"，两个条件要同时满足，用 &&；如果是只要满足其中一个，就用 ||。写代码前一定要读懂题目。
    4. 
  

  Scanner sc = new Scanner(System.in);
System.out.println("请录入一个数字表示范围的开始");
int start = sc.nextInt();
System.out.println("请录入一个数字表示范围的结束");
int end = sc.nextInt();

int count = 0;            // 统计变量
for (int i = start; i <= end; i++) {
    if (i % 3 == 0 && i % 5 == 0) {
        count++;          // 有一个满足，就数一个
    }
}
System.out.println(count);
  
先在 if 里打印 i 验证：10~15 只有 15 满足（10、11、12、13、14 都不满足）；1~100 满足的是 15、30、45、60、75、90。但题目要的是个数，所以不打印了，在循环外面定义一个统计变量 count，在合适的时候让它 ++。合适的位置就是判断的里面：有一个数字满足，count 就加一。循环结束时，范围里的数字都判断过了，再打印 count：10~15 是 1，1~100 是 6。

  
这就是统计思想：定义一个变量用来数数，在合适的时候让它自增一次。

小结

  

    
      
格式for (初始化语句; 条件判断语句; 条件控制语句) { 循环体 }

      
流程① 初始化（只执行一次）→ ② 判断：false 结束，true 往下 → ③ 循环体 → ④ 条件控制 → 回到 ②

      
写循环先想从几开始、到几结束；倒着数用 >= 和 i--

      
累加思想循环外定义 sum = 0，循环里 sum += i，循环后打印

      
统计思想循环外定义 count = 0，满足条件时 count++，循环后打印

      
作用范围变量只在所属的大括号中有效；循环里定义的变量每一轮都会重新创建

      
筛选循环里可以写 if，只处理符合要求的数据；"既…又…"用 &&，"满足一个"用 ||

    
  


  

    一句话
    for 循环先初始化一次，然后"判断 → 循环体 → 条件控制"一轮一轮转，判断为 false 才停；求和、计数的变量都要定义在循环外面。
  


  

    
自测

    

      
1. for (int i = 1; i <= 3; i++) 里，初始化语句、条件判断语句、条件控制语句分别执行几次？

      
      
初始化 1 次；判断 4 次（i 为 1、2、3 时 true，为 4 时 false 结束）；条件控制 3 次。循环体也是 3 次。

    

    

      
2. 倒着打印 10 到 1，for 的小括号怎么写？

      
      
int i = 10; i >= 1; i--

    

    

      
3. 把 int sum = 0; 写进循环里，同时在循环里打印 sum，求 1~5 的和会输出什么？为什么？

      
      
输出 1 2 3 4 5。循环里定义的变量只在本次循环有效，每一轮都会重新定义一个 sum = 0，所以每次打印的都是 0 + i。

    

    

      
4. 统计 1~100 里能被 3 整除或能被 5 整除的数，条件怎么写？结果是多少？

      
      
i % 3 == 0 || i % 5 == 0，结果 47（3 的倍数 33 个 + 5 的倍数 20 个 − 两者都是的 6 个）。可以在第 6 节的演示里切到 || 验证。

    

    

      
5. 求 1~100 的偶数和，除了循环里用 if 判断，还有什么写法？

      
      
让 i 从 2 开始、每次 i += 2，循环体直接 sum += i。结果都是 2550。
