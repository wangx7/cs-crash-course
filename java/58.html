第 1 节 · P58

求最值：比武擂台

数组的基本知识就四点：怎么定义、怎么获取元素、怎么遍历、怎么修改元素。接下来用它们做几个常见操作：求最值、求和、交换数据、打乱数据。

需求：数组里有 33、5、22、44、55，找到最大值并打印。光讲代码太枯燥，给这五个数赋予意义：它们是五个人的战斗力。求最大值就是看谁最能打，那就准备一个比武擂台：

  • 定义变量 max，记录擂台上站着的人。一开始认为第一个人（小白人，战斗力 33）最能打，让他先站上擂台：max = arr[0]；
  • 循环遍历数组，相当于让每个选手上台打一下：新上台的战斗力更高，max 就记录他；否则 max 不变。战斗力 5 的渣渣一下被打下台；紫衣服的 22 没几个回合也趴下了；小红人 44 一招佛山无影脚把小白人踢下去；最后上来的春丽（55）放了个大招把小红人也打下去；
  • 循环结束，擂台上站着的就是最大值：55。
int[] arr = {33, 5, 22, 44, 55}; // 数据都知道，用静态初始化 int max = arr[0]; // 临时认为 0 索引的数据是最大的 for (int i = 1; i < arr.length; i++) { if (arr[i] > max) { max = arr[i]; // 找到更大的，max 记录最新的较大值 } } System.out.println(max); // 55

视频最后讲了三个扩展问题：

  1. 求最小值：变量名改成 min，判断从 > 改成 <，就这两处。
  2. max 的初始值为什么不能是 0？如果数组里全是负数，比如 -33、-5、-22，max 从 0 开始，没有一个元素比 0 大，最后打印的最大值是 0，可数组里根本没有 0！所以 max 的初始值一定要是数组中的值。写 arr[1]、arr[2] 也行，只是习惯写 arr[0]，而且这样下面的循环还能优化：
  3. 循环一定从 0 开始吗？不一定。i 为 0 时是拿 arr[0] 和 max 比，而 max 本来就是 arr[0]，等于自己跟自己比一下，对结果没影响，但多循环了一次。所以开始条件可以写 1，提高效率。

第 2 节 · P59

求和、平均数、统计比平均数小的个数

需求：生成 10 个 1~100 之间的随机数存入数组，① 求出所有数据的和；② 求所有数据的平均数；③ 统计有多少个数据比平均数小。

先准备数据：定义数组用静态还是动态？定义时随机数还不知道，所以用动态初始化 new int[10]。然后用 Random 生成 1~100 的随机数：r.nextInt(100) + 1（写 100 是 0~99，所以要再加 1）。要 10 个，就放进 arr.fori 循环，每循环一次生成一个新的随机数，用 arr[i] = number 存进去（i 就是索引）。存完想验证，再写一个循环遍历打印：一个循环只干一件事。每次运行结果都不一样。

int[] arr = new int[10]; Random r = new Random(); for (int i = 0; i < arr.length; i++) { int number = r.nextInt(100) + 1; // 每循环一次，生成一个新的随机数 arr[i] = number; // 添加到数组中 } // ① 求和 int sum = 0; for (int i = 0; i < arr.length; i++) { sum = sum + arr[i]; } System.out.println("数组中所有数据的和为：" + sum); // ② 平均数 = 和 / 长度 int avg = sum / arr.length; System.out.println("数组中平均数为：" + avg); // ③ 统计比平均数小的个数 int count = 0; for (int i = 0; i < arr.length; i++) { if (arr[i] < avg) { count++; } } System.out.println("在数组中，一共有" + count + "个数据，比平均数小"); // 遍历数组，验证答案 for (int i = 0; i < arr.length; i++) { System.out.print(arr[i] + " "); // print 不换行，所有数据显示在同一行 }

平均数视频直接用整数（avg 是 Average 的缩写），用小数也没问题。最后验证时打印一个数据占一整行，看着累，这里有个小扩展：把 println 的 ln 删掉，打印时就不换行，后面拼一个空格隔开。视频里一次运行：和 505、平均数 50，数一数确实有 6 个比 50 小。

这道题的原题来自斯坦福大学，原题只有一句：生成 10 个 1~100 的随机数存入数组，统计有多少个数据比平均数小。一上来这么写很多同学思路会乱，所以老师把中间步骤拆成了问答的形式。思路捋清了，代码就简单了。

第 3 节 · P60

交换数据：头尾对调

需求：数组 {1, 2, 3, 4, 5}，交换后变成 {5, 4, 3, 2, 1}，相当于把元素首尾对调。这题比较难，拆成三个小问题，由浅入深。

小问题一：交换两个变量的值。int a = 10; int b = 20; 有人写 a = b; b = a;，结果打印两个 20。为什么？a = b 把 b 的值赋给 a，a 原来的 10 被覆盖了，a、b 都是 20；接着 b = a 把 20 赋给 b，还是 20。

换个问题：A 杯装可乐，B 杯装雪碧，怎么对调？找一个第三方的 C 杯：可乐先倒进 C，雪碧倒进 A，再把 C 里的可乐倒进 B。变量也一样，用第三方临时变量：

int temp = a; // 把 a 的值赋给 temp，做个临时记录 a = b; // 把 b 的值赋给 a，a 原来的值被覆盖 b = temp; // temp 里是 a 原来的值，赋给 b

动手：倒饮料

小问题二：交换数组的 0 索引和最大索引。也是用第三方变量：int temp = arr[0]; arr[0] = arr[4]; arr[4] = temp;，遍历打印（删掉 ln、空格隔开）：5 2 3 4 1。

正式题目：把刚才的交换反复循环。定义两个变量记录两个索引：i 记录最小索引 0，j 记录最大索引 4，交换它们指向的数据（1 和 5）；然后 i++、j--，再交换（2 和 4）……一直到 i 等于 j，或者 i 跑到 j 的右边，循环结束。

int[] arr = {1, 2, 3, 4, 5}; // 初始化语句里可以定义两个变量，用逗号隔开 for (int i = 0, j = arr.length - 1; i < j; i++, j--) { int temp = arr[i]; // 交换变量 i 和变量 j 指向的元素 arr[i] = arr[j]; arr[j] = temp; }

循环条件：i 在 j 左边时才继续，所以写 i < j。课后自己写时不要直接写最后一题，按顺序先写交换两个变量，再写交换首尾两个元素，最后写全部交换。

动手：i 和 j 往中间走

第 4 节 · P61

打乱数据：和随机索引交换

需求：数组 {1, 2, 3, 4, 5}，随机打乱所有数据的顺序。刚开始很难入手，思路是：从 0 索引开始遍历，拿当前元素和一个随机索引上的元素交换。比如 0 索引的 1，随机索引是 2，就把 1 和 3 交换；然后 i++，拿 1 索引的元素和下一个随机索引交换……循环结束，数据就打乱了。

难点：怎么获取随机索引？索引范围是 0~4，用 Random：r.nextInt(5)，包头不包尾，正好 0~4。多运行几次：0、3、0、1……每次都不一样。再改进一下，5 没有通用性，改成 arr.length，随便给一个数组都能拿到随机索引。

int[] arr = {1, 2, 3, 4, 5}; Random r = new Random(); for (int i = 0; i < arr.length; i++) { int randomIndex = r.nextInt(arr.length); // 生成一个随机索引 int temp = arr[i]; // 和 i 指向的元素交换 arr[i] = arr[randomIndex]; arr[randomIndex] = temp; } for (int i = 0; i < arr.length; i++) { System.out.print(arr[i] + " "); }

打乱了三次：4 5 3 2 1、2 1 4 3 5、5 3 1 4 2，每次都不一样。写完按 Ctrl+Alt+L 格式化代码。

动手：一步步打乱

这样打乱其实不太"公平" 每一轮都从全部索引里随机挑，n 个数一共有 nn 种随机过程，而排列只有 n! 种。n = 3 时是 27 种过程对 6 种排列，27 不能被 6 整除，所以有的排列注定比别的更容易出现。正确的做法叫 Fisher–Yates 洗牌：第 i 轮只在 i 和它后面的索引里挑，int randomIndex = i + r.nextInt(arr.length - i);，这样每种排列的概率都一样。用 {1, 2, 3} 各洗 60000 次比一比（虚线是"完全公平"的位置）：

Java 的内存分配

数组的基本使用学完了。为了更好地理解数组到底怎么工作，扩展讲一讲数组的内存图。先看 Java 的内存分配：每款软件运行时都要占用一块内存，Java 也一样，虚拟机为了更好地利用这块空间，把它分成了五个部分：

栈方法运行时使用的内存。程序的主入口 main 也是方法，开始执行时进栈，代码全部执行完就出栈
堆存储对象或数组，new 出来的都在堆里，开辟的空间有地址值
方法区存储可以运行的 class 文件：类要运行时，字节码文件会加载到这里
本地方法栈虚拟机使用操作系统功能时用，和开发无关
寄存器视频说交给 CPU 使用，和开发无关

其中方法区要单独说一下：JDK 7 以前方法区和堆是连在一起的，物理内存中也是连续的一块，这种设计不太好（后面讲虚拟机内存时详细说）；到了 JDK 8，取消了方法区，新增了元空间，和堆分开了，原来方法区的功能有的放进堆、有的放进元空间。为了方便理解，暂时还叫它方法区。现在只需要掌握前两个：栈和堆。

更正：两处说法更准确的版本 ① 方法区是 Java 虚拟机规范里的一个概念，并没有被"取消"。JDK 7 及以前，HotSpot 虚拟机用永久代（放在堆旁边，归垃圾回收器管）来实现它；JDK 8 删掉的是永久代，改用放在本地内存里的元空间来实现方法区，原来存在永久代里的字符串常量池、静态变量在 JDK 7 就已经挪进了堆。② 第五块在规范里叫程序计数器（PC Register），作用是记录当前线程执行到了哪一条字节码，不是 CPU 自己的寄存器。这两块入门阶段确实不用管，知道名字就行。

先看最简单的代码：int a = 10; int b = 10; int c = a + b; System.out.println(c);。没有 new，不需要堆，只看栈：main 方法进栈，从第一行往下执行。int a = 10 就是在栈里开辟一块小空间，起名叫 a，限定只能存 int 整数，再把 10 放进去；b 同理；int c = a + b 先算出 20，再赋值给 c；打印时先找到 c 记录的值，再把 20 打印到控制台。下面的演示里第一段程序就是它。

第 6 节 · P62

数组的内存图

一个数组：int[] arr = new int[2]; 有 new 了，栈和堆都要看。这行代码由左右两部分组成：

  • 等号左边：在栈里定义一个变量 arr，类型 int[]，表示它可以记录 int 类型数组的地址值；
  • 等号右边：有 new，在堆里开辟一块空间，长度为 2，有 0、1 两个索引，元素是默认值 0。这块空间有地址值，通过中间的赋值运算符，把地址值赋给左边的 arr，arr 通过地址值就能找到堆里的这块空间。

这就是数组和变量的区别：变量 a、b、c 里存的是真实的数据；而数组要存的数据可能很多很多，没法都放在 arr 这个变量里，所以 Java 把数据放在另一块空间，arr 只记录那块空间的地址值。所以打印 arr 看到的是地址值；arr[0] 是先通过 arr 找到堆里的空间，再通过 0 索引找到里面的数据。赋值 arr[0] = 11 也是先找到空间，再把 11 赋给 0 索引，原来的元素被覆盖。

两个数组：再写 int[] arr2 = {33, 44, 55};。虽然没写 new，但这是简写，完整格式里还是有 new，所以同样在堆里开辟一块新空间，arr2 记录它的地址值。堆里有了两块空间，互相独立，没有任何影响。

两条重要规律：① 只要是 new 出来的，一定是在堆里开辟了一块小空间，而且这块空间有地址值；② new 了多次，堆里就有多块小空间，每块空间都有各自的数据。

特殊情况：两个数组指向同一个空间。先讲个小故事：老师有个朋友，小时候逢年过节喜欢和好基友把炮扔进厕所里，俗称"炸屎"。他爹再去上厕所，看到的是干净的厕所还是满地翔的厕所？当然是满地翔的，因为他们共享同一个厕所。来看代码：

int[] arr1 = {11, 22}; int[] arr2 = arr1; // 没有 new！把 arr1 记录的地址值赋给 arr2 System.out.println(arr1[0]); // 11 System.out.println(arr2[0]); // 11 arr2[0] = 33; System.out.println(arr1[0]); // 33 System.out.println(arr2[0]); // 33

第二行等号右边没有 new，而是 arr1，表示把 arr1 记录的内容（地址值，比如 0x0011）赋值给 arr2。于是 arr1 和 arr2 指向同一块空间：arr1 是朋友，arr2 是朋友他爹，找的是同一个厕所。通过 arr2 把 0 索引改成 33，再通过 arr1 访问，看到的也是 33。结论：当两个数组指向同一个小空间时，其中一个数组对小空间中的值发生了改变，其他数组再次访问的时候都是修改之后的结果。

小结

求最值max = arr[0]（初始值必须是数组里的值），从 1 开始遍历，更大就替换
随机数存入数组动态初始化 + 循环 arr[i] = r.nextInt(100) + 1；一个循环只干一件事
print去掉 ln 不换行，配合 + " " 让数据显示在同一行
交换两个变量temp = a; a = b; b = temp;
头尾对调for (int i = 0, j = arr.length - 1; i < j; i++, j--) 里交换 arr[i]、arr[j]
打乱遍历时和 r.nextInt(arr.length) 得到的随机索引交换
栈 / 堆方法运行在栈里；new 出来的在堆里，有地址值；new 几次就有几块空间
共享空间arr2 = arr1 传的是地址值，两个变量改的是同一个数组
一句话 数组变量里存的不是数据，是堆里那块空间的地址；复制变量只是多了一个能找到同一块空间的人。

自测

1. 求最小值时 int min = 0;，数组是 {3, 8, 5}，结果是多少？错在哪？
结果是 0，但数组里没有 0。初始值必须是数组中的值，写 min = arr[0]。
2. int a = 1, b = 2; a = b; b = a; 之后 a、b 各是多少？
都是 2。第一句已经把 a 原来的 1 覆盖了，要用第三方变量 temp 先记下来。
3. 头尾对调时，数组长度是 6，循环会交换几次？长度是 5 呢？
长度 6：3 次（0↔5、1↔4、2↔3）；长度 5：2 次，中间的 2 索引不用动，i 和 j 相遇就停。
4. int[] a = {1, 2}; int[] b = {1, 2}; b[0] = 9; 之后 a[0] 是多少？换成 int[] b = a; 呢？
第一种 a[0] 还是 1：两次 new（简写也是 new），堆里两块独立空间。第二种 a[0] 变成 9：a、b 指向同一块空间。
5. 生成随机索引时，为什么写 r.nextInt(arr.length) 而不写 r.nextInt(5)？
arr.length 有通用性：数组长度变了也不用改，范围永远是 0 ~ length − 1，正好是所有合法索引。
