第 1 节 · P23

基本数据类型：四类八种

接下来难度升一级，学三个比较难、又都和变量有关的知识点：

  • 数据类型（对应格式里的"数据类型"）：之前只介绍了两种，其实还有别的；
  • 标识符（对应"变量名"）：用 a、b、c、d 起名规范吗？学一学现在大多数程序员都在遵守的阿里巴巴编码规范，从一开始就养成好习惯；
  • 键盘录入（对应"数据值"）：之前的数据值都是写死的，能不能键盘敲 1 变量就记 1，敲 2 就记 2？下一篇讲。

Java 的数据类型分两种：基本数据类型和引用数据类型。引用数据类型学数组和面向对象时再讲，先学基本数据类型。它分四类八种：

类关键字取值范围内存占用（字节）
整数byte−128 ~ 127（要记）1
short−32768 ~ 327672
int约 −21 亿 ~ 21 亿（10 位数）4
long更大，19 位数8
浮点数
（小数）		float约 ±3.4×10³⁸4
double约 ±1.8×10³⁰⁸8
字符char0 ~ 655352
布尔booleantrue、false1

一个整数搞出四种、一个小数搞出两种，有什么不一样？最本质的区别是取值范围不一样。最小的 byte 只能存 −128 到 127，所以把 200 赋值给 byte 变量是错的，一定要在范围内。常用的 int 大约是正负 21 亿，最大的 long 是一个 19 位数。范围不同，占用的内存空间也不同（1、2、4、8、4、8、2、1 个字节），这涉及计算机底层的存储原理，第二阶段再深入，现在了解一下就行。

实际使用时：整数一般用 int，小数一般用 double。

要记住的有三点：

  1. 四类八种的名字；
  2. byte 的取值范围 −128 ~ 127（其他的不用记）；
  3. 整数和小数取值范围的大小关系：double > float > long > int > short > byte。
float 只有 4 个字节，范围却比 8 字节的 long 大？ 是的。整数类型每个二进制位都用来表示数值，所以 long 能精确表示 19 位以内的每一个整数。浮点数用一部分位记"有效数字"、一部分位记"小数点挪几位"（类似科学计数法 1.23×10³⁸），所以能表示特别大或特别小的数，代价是精度有限：float 大约只有 7 位有效数字，double 大约 15~16 位。上面的范围是"能表示多大"，不是"每个数都精确"。
另外，boolean 占几个字节，Java 规范其实没有规定，视频说的 1 个字节是常见的实现方式。
第 2 节 · P23

八种类型的变量写一遍

复制 VariableDemo2 成 VariableDemo3.java（类名跟着改），把八种基本数据类型的变量都定义一遍：

public class VariableDemo3 { public static void main(String[] args) { byte b = 10; // 写成 200 会报错：超出 byte 的范围 short s = 20; int i = 30; long n = 9999999999L; // long 的数据值要加 L 后缀 float f = 10.1F; // float 的数据值要加 F 后缀 double d = 20.2; char c = '中'; boolean o = true; // 只有 true 和 false 两个值 System.out.println(b); // 每个变量都打印一下（这里省略后面几行） } }
  • long 要加 L：一开始按老写法 long n = 12345678910;（10 位数），编译报错 整数太大。定义 long 类型变量时，数据值后面要加 L 作为后缀。大小写都行，但建议大写：小写的 l 和数字 1 长得太像了。
  • float 要加 F：同理，大小写都行，为了和 L 统一，建议大写。
  • double 不用加后缀，和之前一样。

"整数太大"为什么写在 long 前面也会报 代码里直接写的整数（字面量），Java 默认把它当成 int。12345678910 超出了 int 的范围，所以还没轮到"存进 long"这一步，光是"这个 int 字面量"本身就不合法了，报"整数太大"。加上 L，等于告诉 Java"这是个 long 字面量"，就没问题了。同理，代码里直接写的小数默认是 double，存进 float 时会报"从double转换到float可能会有损失"，所以要加 F 说明"这是个 float"。
把 200 存进 byte 的报错是 不兼容的类型: 从int转换到byte可能会有损失。在实验台里都能看到。
第 3 节 · P24

三个练习：根据数据选类型

这一章的重点是：根据不同的数据，选择不同的数据类型。三个练习：

  1. 输出老师的信息：姓名"黑马谢广坤"、年龄 18、性别男、身高 180.1、是否单身。
  2. 输出电影的信息：电影名"送初恋回家"、三位主演的名字、年份 2020、评分 9.0。
  3. 输出商品的信息：从几部手机里选一部，记录价格（5299.00、1699.00……）和品牌（华为、荣耀……）。

分析老师的信息时，先挑简单的：年龄 18 是整数，整数默认用 int；性别"男"只有一个字，用 char；身高 180.1 是小数，默认用 double；是否单身只有"是"和"否"两种状态，不可能又是又否，用布尔 true / false。最后剩下"黑马谢广坤"：五个汉字，整数、小数、布尔、字符都不像，在代码里用字符串表示最合适。字符串的类型叫 String（后面会专门学）。

第 4 节 · P25

标识符：给类、方法、变量起名字

之前起变量名用 a、b、c、d，不符合规范，名字没有意义，时间一长也忘了它们是什么意思。标识符就是我们自己给类、方法、变量起的名字，是个统称：类名、方法名、变量名都是标识符（方法马上就会学）。

现实里起名字也有讲究：给家里的二哈起名"刘建国""王翠花"也行，但太土；"亚托克斯""阿里斯塔"也行，但难记；要是起个更离谱的，怕是要被二哈嘲讽。现实中起名要讲规矩，代码里也一样。业内大多数程序员遵守的是阿里巴巴 Java 开发手册里的命名规范（课程资料里有）。规矩分两类：

硬性要求：必须遵守，否则报错

  1. 由数字、字母、下划线 _、美元符 $ 组成，括号、感叹号这些都不行；
  2. 不能以数字开头；
  3. 不能是关键字：关键字已经被 Java 赋予了特定含义，比如 class；
  4. 区分大小写：小写 a 和大写 A 是两个完全不同的变量。

软性建议：不遵守不报错，但读起来费劲、不专业

就像在路上看到漂亮的小姐姐偷偷瞄一眼，不违法，就是显得有点猥琐。

小驼峰命名法
方法名、变量名		一个单词时全部小写：name；多个单词时，第一个单词首字母小写，从第二个单词起首字母大写：firstName
大驼峰命名法
类名		一个单词时首字母大写：Student；多个单词时每个单词首字母都大写：GoodStudent
见名知意
不管给什么起名		看到名字大概就知道它表示什么：name 可能是姓名，firstName 可能是第一个人的名字，Student 和学生有关。用 a~z 起名不报错，但过几天问你 w 是什么，自己都不记得了

    第 5 节

    小结

    两大类基本数据类型、引用数据类型（以后学）
    四类八种整数 byte short int long；浮点 float double；字符 char；布尔 boolean。整数默认 int，小数默认 double
    要记的范围byte：−128 ~ 127；大小关系 double > float > long > int > short > byte
    后缀long 加 L，float 加 F，建议大写
    标识符硬性要求数字、字母、_、$ 组成；不能数字开头；不能是关键字；区分大小写
    软性建议变量名、方法名小驼峰（firstName），类名大驼峰（GoodStudent），见名知意
    一句话 选类型看数据：整数 int、小数 double、一个字 char、是非 boolean、一串字 String；起名字看规矩：英文、小驼峰、见名知意。

    自测

    1. byte b = 200; 能编译吗？byte b = -128; 呢？
    第一个不行，byte 的范围是 −128 ~ 127，200 超出了（报"从int转换到byte可能会有损失"）。第二个可以，正好是最小值。
    2. long n = 12345678910; 为什么报错？怎么改？
    代码里的整数默认是 int，12345678910 超出了 int 的范围，报"整数太大"。在后面加 L：long n = 12345678910L;（建议大写 L，小写 l 容易和 1 混淆）。
    3. 把六种整数、小数类型按取值范围从大到小排一下。
    double > float > long > int > short > byte。
    4. 下面哪些不是合法的标识符：_2b、2b、Class、#itheima、ak47、class？
    2b（数字开头）、#itheima（# 不允许）、class（关键字）不合法。_2b 以下划线开头可以；Class 大写，和关键字 class 不是一个东西，可以；ak47 可以。
    5. "学生的年龄"做变量名、"好学生"做类名，按规范分别怎么写？
    变量用小驼峰：studentAge；类用大驼峰：GoodStudent。
