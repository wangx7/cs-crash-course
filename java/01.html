第 1 节 · P1

这门课学什么、怎么学

整套课分Java 基础和Java 进阶两大块，是以后做 Java 开发的地基。学完要掌握的东西，老师列了几条：

  • 面向对象思想：Java 近 30 年来最核心的思想，要能灵活运用。
  • 核心知识点：常用 API、集合、IO（BIO / NIO）、多线程、网络编程等。
  • 练习题：案例和课后作业取自斯坦福大学的 Java 题，还有一部分是力扣（LeetCode）上的算法题，很多公司面试也考这些。
  • 综合项目：拼图小游戏、学生管理系统、OA 管理系统、类似 QQ 的聊天软件，让你知道知识点在真实开发里怎么用。
  • 编码规范：所有代码按业内通用的《阿里巴巴 Java 开发手册》来写，从入门就养成好习惯。
  • 拔高内容：用 NIO 从零手写一个 Tomcat 服务器、虚拟机的内存结构和垃圾回收、常见数据结构的手写实现。

讲课方式上，最值得记住的一条是：先分析需求，再写代码。老师不会直接给你"第 1、2、3、4 步"，而是先分析；写的时候可能直接从第二步、第三步开始，写着写着发现需要第一步了，再回头补上。真实开发就是这样写代码的。

为什么"听得懂、写不出" 很多人看完别的课，案例稍微复杂一点就无从下手。原因往往不是知识点没学会，而是缺少编程思想：学的时候跳过了"怎么分析"。这门课在很多地方会把分析过程完整地走一遍，跟着走比背代码重要。

第 2 节 · P2

人机交互：图形界面是怎么来的

Java 是一种计算机语言，以后天天要和电脑打交道，所以先学怎么操作电脑。你可能会说：这还用学？想打开什么，鼠标双击不就行了。

可电视里的黑客，总是在一块黑屏幕上敲命令。Windows 里其实也有这样的黑屏幕，它叫 CMD。这一章学的就是用 CMD 操作电脑。先听一个小故事。

计算机刚出现的时候占地大、造价高、耗电多，基本只给军队和政府用。后来体积越做越小，出现了微型机，才走进普通家庭。早期给个人用的电脑没有图形界面，想打开一个文件夹，得在黑屏里输入命令。比较典型的是 1981 年 IBM 和微软推出的 MS-DOS，全程敲命令，没点计算机功底根本玩不转。

那么，第一个图形界面的操作系统是谁做的？不是微软，也不是苹果，而是一家叫施乐（Xerox）的公司。1981 年 4 月 27 日，施乐推出了 Xerox Star：可以同时开几个窗口干不同的事，可以建文件夹给东西归类，用的时候双击打开。今天的图形界面，基本就是它的样子。

这项技术让两位大佬相爱相杀。乔布斯看到了图形界面的前景，推出了 Apple Lisa；比尔·盖茨随后推出了 Windows 1.0。乔布斯当面指责盖茨抄袭，盖茨的回答成了名言，大意是：我们都有一个叫施乐的有钱邻居，我闯进他家想偷东西，却发现你已经先下手了。意思就是：咱俩都是抄别人的，谁也别说谁。

点一点：从命令行到图形界面

虚线框是视频里没讲、补充进来的节点

图形界面让电脑真正普及开来，但它也有代价：要额外加载很多图片，占用更多内存，速度也没有命令行快。所以顶尖的黑客大多用命令行，嫌图形界面又慢又不够灵活。Windows 也保留了命令行，就是 CMD：在 Windows 里用命令行的方式操作电脑，打开文件、打开文件夹、新建文件、新建文件夹，都可以。

几处时间线的细节 施乐更早在 1973 年就做出了实验机 Xerox Alto，它已经有窗口、图标和鼠标，只是没有正式卖；1981 年的 Star 是第一台商用的图形界面电脑。Apple Lisa 是 1983 年 1 月发布的，Windows 1.0 是 1985 年 11 月。盖茨那句名言出自 1983 年，当时微软刚宣布要做 Windows，原话里"偷的东西"是一台电视机。
第 3 节 · P3

打开 CMD：Win + R，输入 cmd，回车

关于 CMD 只要学两件事：怎么打开它，以及常用命令有哪些。打开分三步：

  1. 按 Win + R（Win 键在键盘左下角，印着 Windows 图标）。屏幕左下角会弹出"运行"窗口。
  2. 在运行窗口里输入 cmd。
  3. 按回车（或点"确定"）。

弹出来的黑色小窗口就是 CMD。窗口里光标前面有一串路径，比如 C:\Users\moon>，意思是现在正在操作哪个文件夹。默认是 C 盘 → Users → 你的用户名（老师的电脑叫 moon；如果你的叫 admin，就是 C:\Users\admin）。这就好比在图形界面里，我们默认是在桌面上操作的。

在"此电脑"（Win + E）里也能找到这个文件夹：C 盘里那个显示成"用户"的文件夹，地址栏一点就会变成 C:\Users，里面就有以你用户名命名的文件夹。

一个小扩展 Windows 的桌面其实也是一个文件夹，叫 Desktop，就在 C:\Users\你的用户名\ 里面。以后看到某个文件的路径里有 Desktop，就说明它放在桌面上。
别的打开方式 也可以点开始菜单直接输入 cmd 再回车，或者在资源管理器的地址栏里输入 cmd 回车，这样打开的 CMD 直接停在当前这个文件夹。Windows 11 默认用"终端"（Windows Terminal）来装 CMD，外观不一样，里面的命令完全相同。
第 4 节 · P4

8 个常用命令

常用命令一共 8 个，前 4 个是最基本的"换盘、看、进、退"，后 4 个是加强版和收尾：

命令作用图形界面里相当于
盘符名: 例如 E:切换到某个盘在"此电脑"里双击 E 盘
dir查看当前文件夹里的内容看着窗口里的图标
cd 目录进入一层文件夹双击一个文件夹
cd ..回到上一层点"返回上一级"
cd 目录1\目录2一次进入多层在地址栏直接输入路径
cd \一次退回到盘的根目录点地址栏里的盘符
cls清屏—
exit关闭 CMD 窗口点右上角的 ×

几个用法细节：

  • 盘符后面的冒号必须是英文冒号。输成中文冒号会报错。
  • 文件夹名太长不想打全？输入开头几个字母，按 Tab 会自动补全。
  • Windows 不区分大小写，cd QQ 和 cd qq 效果一样。
  • 按住 Ctrl 滚动鼠标滚轮，可以把 CMD 的字放大。

第 5 节 · P5 上半

练习：用 CMD 打开 QQ

学会了命令，做个小练习：用 CMD 打开电脑上的 QQ。先分析：要打开 QQ，得先知道它在哪儿。打开"此电脑"找一找，老师的 QQ 装在 D 盘的 QQ 文件夹里，但这一层没有启动程序，再进 Bin 文件夹，里面的 QQ.exe 才是。所以完整路径是 D:\QQ\Bin\QQ.exe。

知道了位置，步骤就出来了：

  1. 打开 CMD。默认在 C:\Users\moon，可 QQ 在 D 盘。
  2. 切换盘符：D:（英文冒号）。
  3. 进入 Bin：cd QQ\Bin（大小写无所谓）。
  4. 想打开谁，直接写它的名字：QQ.exe，回车，QQ 就启动了。

每次都要换盘、再钻进好几层文件夹，太麻烦了。能不能在任何目录下直接输入 QQ.exe 就打开它？正常情况下不行：比如在 C:\Users\moon 里直接输入 QQ.exe，CMD 会报错，说它"不是内部或外部命令，也不是可运行的程序或批处理文件"，因为当前目录里根本没有 QQ。

解决的思路是：把 QQ 所在的路径记在电脑的某个地方。下次输入 QQ.exe 时，当前目录里没有，就去那个地方记下的路径里找。电脑里专门记这些路径的地方，叫环境变量。

第 6 节 · P5 下半

环境变量：告诉 CMD 去哪儿找

输入一个程序名之后，CMD 按这个顺序找：

  1. 先在当前目录里找；
  2. 没有，就去环境变量 Path 里记的路径，从上往下一个一个地找；
  3. 全找完都没有，才报错。

所以只要把 D:\QQ\Bin 加进 Path，在哪个目录都能打开 QQ。配置步骤：

  1. 打开系统设置页面：在"此电脑"上点右键 → 属性（在桌面图标上右键，或打开此电脑后在空白处右键都行）。
  2. 点高级系统设置，在弹出窗口的"高级"选项卡里点环境变量。
  3. 窗口上半部分是用户变量，只对当前用户有效，电脑有多个用户时其他人用不了，所以别动它；找下半部分系统变量里的 Path，点编辑。
  4. 点新建，把 QQ.exe 所在的文件夹路径 D:\QQ\Bin 粘贴进去。
  5. （可选）点上移把它挪到最上面：因为是从上往下找的，放在第一个能更快找到。
  6. 一路点确定。然后重新打开一个 CMD 窗口，原来那个窗口不会生效。

    • 在左边窗口里运行一个程序名，这里会列出 CMD 依次查了哪些地方。

    环境变量的作用一句话就能说清：想在任意目录下都能打开某个软件，就把它所在的路径配置到 Path 里。这一节看着和 Java 没关系，其实是在提前铺路：下一篇装完 JDK，要在任意目录下使用 javac 和 java 这两个命令，用的就是同一套方法。

    为什么要重新打开窗口 每个程序启动时，会从系统那里复制一份环境变量带在身上。改了系统的 Path，已经打开的 CMD 手里还是旧的那份，所以必须关掉重开。模拟窗口里输入 path 可以看到"这个窗口自己的"Path。
    两个小技巧 .exe 可以省略：直接输入 QQ 也行。CMD 会自动试一遍 .exe、.bat 等可执行的扩展名（这个列表也在一个环境变量 PATHEXT 里）。
    更快打开环境变量窗口：点开始菜单，搜"环境变量"，选"编辑系统环境变量"，一步就到第 2 步的那个窗口。Windows 11 的设置界面改过几次，这条路一直有效。
    用 Mac 的话 macOS 对应 CMD 的是终端（Terminal），命令来自 Unix，名字不太一样：dir → ls（ls -a 显示隐藏文件），cd 用法相同但路径用正斜杠 /，cd \ → cd /（回到整个磁盘的根），cls → clear，没有盘符的概念。Mac 上也有 PATH 环境变量，查找规则一样（但不会先找当前目录，要运行当前目录的程序得写 ./程序名），一般在 ~/.zshrc 里加一行 export PATH="$PATH:/新路径" 来配置。
    第 7 节

    小结

    CMD在 Windows 里用命令行操作电脑。打开：Win+R → cmd → 回车。默认在 C:\Users\用户名
    8 个命令盘符:　dir　cd 目录　cd ..　cd 目录1\目录2　cd \　cls　exit
    打开程序直接写名字。先找当前目录，再按 Path 从上往下找
    环境变量 Path想在任意目录打开某个程序，就把它所在的文件夹加进系统变量 Path；改完要重开 CMD
    一句话 CMD 里打开一个程序，就是"写出它的名字"；它找不到时，要么自己 cd 过去，要么把路径告诉 Path。

    自测

    1. 刚打开的 CMD 默认在哪个文件夹？想切到 E 盘的根目录该输入什么？
    默认在 C:\Users\你的用户名。切到 E 盘输入 E:（英文冒号）再回车。注意 cd E:\ 不会换盘。
    2. 现在在 E:\，要一步进入 E:\base-code\day04-code，然后一步退回 E:\，分别怎么写？
    cd base-code\day04-code，然后 cd \。如果只想退一层，用 cd ..。
    3. 在 C:\Users\moon 里输入 QQ.exe，CMD 会去哪些地方找？按什么顺序？
    先找当前目录 C:\Users\moon；没有，再按系统变量 Path 里的路径从上往下逐个找；都没有才报"不是内部或外部命令"。
    4. 把 QQ 的路径加进 Path 之后，在原来开着的 CMD 里输入 QQ.exe 还是报错，为什么？
    已经打开的 CMD 在启动时复制了一份旧的环境变量，看不到新改的 Path。关掉它，重新打开一个 CMD 再试。
    5. 为什么配置时选"系统变量"里的 Path，而不是"用户变量"？
    用户变量只对当前登录的用户有效，电脑上有多个用户时，其他人用不了；系统变量对所有用户都有效。
