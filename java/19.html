第 1 节 · P19

什么是变量：存数据的小箱子

变量就是在程序执行过程中，值有可能发生改变的量。

举个场景：登录页面要输入用户名和密码。程序要把用户输入的和正确的用户名、密码做比较，可用户输入的东西是变化的，不是固定的，怎么办？可以定义两个变量。变量可以理解成程序里存储数据的小箱子（一小块空间）：第一个箱子存用户输入的用户名，第二个存密码。用户输入 heima / 123456 就存进去，输入别的也照样存进去。不管输入什么，存进对应的变量，再拿变量去和正确的值比较就行。

这就是变量的使用场景：某个数据经常发生改变时，用变量来存；数据再变，只要修改变量里记的值。这体现了变量的"变"字。

在代码里，变量有固定的定义格式：

数据类型给箱子加限定：只能存整数？只能存小数？
变量名箱子的名字，方便以后使用
=赋值：把右边的数据交给左边的变量
数据值真正存在箱子里的数据
;语句结束，像作文里的句号

举例：定义一个变量，相当于在内存里有了一个小箱子。以后要经常用里面的数据，所以给它起个名字叫 a；再给它加个限定：只能存整数。那么把 10 存进来没问题，10 是整数；把 10.1 存进来不行，违背了限定。这就是数据类型的作用。目前先学两种：

  • 整数类型写 int；
  • 小数类型（也叫浮点类型）写 double。

新建 VariableDemo1.java（Variable 就是"变量"，Demo 表示演示）。类名要和文件名一致，老办法：复制文件名再粘贴。

public class VariableDemo1 { public static void main(String[] args) { // 定义变量：数据类型 变量名 = 数据值; int a = 10; System.out.println(a); // 打印的是变量里的内容：10 } }

运行结果是 10，因为变量 a 里存的就是 10。注意 println(a) 的括号里没有引号：写 a 打印的是变量的值，写 "a" 打印的才是字母 a。

这里的 = 不是数学里的等于 数学里 a = a + 1 是不可能成立的式子，但在 Java 里很常见（第 4 节就会用到）：= 是赋值，意思是"先算右边，再把结果放进左边的箱子"。Java 里判断"是否相等"用的是两个等号 ==，后面学运算符时会讲。
第 2 节 · P20

变量的三种用法

变量定义好之后，可以这样用：

  1. 输出打印：输出语句里写变量名，打印变量里的值。变量可以反复使用，打印三次就出现三个 10。
  2. 参与计算：int a = 10; int b = 20;，然后打印 a + b，结果是 30。
  3. 修改记录的值：先 int a = 10;，再写 a = 20;，就是把 20 赋值给 a，原来的 10 被覆盖了。变量同时只能记录一个值。

新建 VariableDemo2.java 把三种用法写一遍。视频里第二段故意又写了一次 int a = 10;，编译时报错了：

VariableDemo2.java:13: 错误: 已在方法 main(String[])中定义了变量 a

意思是变量名不能重复。道理很简单：假如允许重复，上面的 a 记的是 10，下面的 a 记的是 30，那 a + b 到底拿哪个 a 去加？不知道了。所以第二段改用 b 和 c，打印 b + c。

变量的使用场景，总结起来有两个：

  • 某个值要重复使用：先用变量临时存起来，以后用到时不用再写一遍，直接用变量；
  • 某个数据经常发生改变：用变量存，变了就修改变量的值。
第 3 节 · P20

变量的注意事项

1只能存一个值：修改之后，原来的值被覆盖
2变量名不允许重复定义
3一条语句可以定义多个变量：int d = 100, e = 200, f = 300; 把分号换成逗号，表示语句还没结束，接着定义。三个变量都限定为 int。但一行写太多读起来费劲，了解即可，建议一行只定义一个变量
4变量在使用之前一定要赋值：只写 int g; 就打印 g，编译报错 可能尚未初始化变量g（"初始化"就是赋值）。赋值要写在用到它之前，写在打印后面也不行
5注意作用范围：现在还没有应用场景，学完判断和循环再讲

第 4 条里，int g; 和 g = 10; 其实是把定义和赋值分成两步写了，语法上可以，但写起来很怪。建议：定义变量时直接赋值，不要分开写。

回到上面的实验台，点"一行定义多个""没赋值就用"这些按钮，看看它们分别是什么效果。

报错时会发生什么 "变量名重复""没赋值就用""把 10.1 存进 int"这些都是编译期的错误：javac 检查到了就不生成 class 文件，一行代码都不会运行，哪怕错误在最后一行，前面的打印也不会执行。实验台也照这个规矩来。另外，"必须先赋值"说的是写在方法里的变量（叫局部变量）；以后学面向对象时会遇到另一种变量，它有默认值，到时再对比。
int 存不下 10.1，那 double 存得下 10 吗？ 可以。把整数 10 存进 double 变量，它会自动变成 10.0，打印出来也是 10.0，因为小数能表示所有这种整数，不会丢东西。反过来小数存进 int 会丢掉小数部分，所以 Java 不允许直接存，报错 不兼容的类型: 从double转换到int可能会有损失。这叫类型转换，P31 会细讲。在实验台里写 double h = 10; 试试。
第 4 节 · P21

练习：公交车上有几个人

用变量写一个带一点逻辑的小练习。以后每个练习都会先分析、再一点点用代码实现。可以听完分析自己先试着写，也可以看完再写，但代码一定要写，别说"下次一定"。

题目 一辆公交车，一开始车上没有乘客（不算司机）。第 1 站上去 1 人；第 2 站上去 2 人、下来 1 人；第 3 站上去 2 人、下来 1 人；第 4 站没人上、下来 1 人；第 5 站上去 1 人、没人下。到终点站时车上有几位乘客？

先分析。不学编程，用数学也能算出是 3 人。怎么算的？心里先记一个数 0（一开始没人），每到一站，按实际情况修改心里记的这个数，最后记的就是答案。代码里同样的道理：

  1. 用一个变量记录车上的乘客数，一开始是 0；
  2. 每到一站，按实际情况修改变量的值；
  3. 最后变量的值就是结果。

再写代码。老师提前准备了 VariableTest.java（Test 表示练习，Demo 表示知识点演示），题目和思路都写在注释里了。

  • 变量名起得有意义：别叫 a、b，时间一长就忘了是什么意思。叫 count（数量），一看就懂。
  • 第 1 站上去 1 人，不要直接写 count = 1;：这样没有计算过程，是直接把最终结果给了它。上去一个人，就是在原来的基础上加 1：count = count + 1;
  • 这行代码的执行顺序：先算等号右边，拿 count 里的 0 加 1 得到 1，再把结果赋值给左边的 count。这行执行完，count 就变成了 1。不确定的话，加一句输出打印看看。
  • 第 2 站上 2 下 1：count = count + 2 - 1;，后面每站同理。最后打印 count。

动手：开着公交车跑一趟

每点一次"下一站"，执行一行代码：先算右边，再存回 count。上下车人数可以改，代码会跟着变。

这道题对刚入门的同学有点难，注意两点：一是逻辑要捋顺，哪站上几个、下几个；二是要真正理解 count = count + 2 - 1; 这种代码是什么意思。这两点通了，这题就没问题了。

以后会学到的简写 count = count + 1; 太常用了，Java 有更短的写法：count += 1; 或 count++;，效果一样。P33、P34 学运算符时会讲。现在先用完整写法，把"先算右边、再赋值"的过程想清楚。
第 5 节

小结

是什么程序执行过程中值可能改变的量，相当于存数据的小箱子
定义格式数据类型 变量名 = 数据值;　整数 int，小数 double；= 是赋值
三种用法输出打印、参与计算、修改记录的值
使用场景值要重复使用；数据经常改变
注意事项只能存一个值；名字不能重复；一条语句可定义多个（不推荐）；使用前必须赋值；（作用范围以后讲）
一句话 变量是一个有名字、有类型限定的箱子；count = count + 1 的意思是"先拿出旧值算出新值，再放回同一个箱子"。

自测

1. 下面代码打印什么？
int a = 10; a = 20; a = a + 5; System.out.println(a);
25。a 先是 10，被 20 覆盖，再算 20 + 5 = 25 存回 a。
2. int a = 10; int a = 30; 能编译吗？为什么？
不能，报"已在方法 main(String[])中定义了变量 a"。变量名不能重复，否则后面用 a 时不知道指的是哪一个。想改值应该写 a = 30;（不带 int）。
3. int g; System.out.println(g); g = 10; 有什么问题？
打印 g 时它还没有赋值，编译报"可能尚未初始化变量g"。赋值必须在使用之前。更好的写法是定义时直接赋值：int g = 10;
4. int price = 9.9; 能存进去吗？double h = 10; 呢？
第一个不行：int 只能存整数，9.9 违背了类型限定（报"从double转换到int可能会有损失"）。第二个可以，h 里存的是 10.0。
5. 公交车题里，为什么第 1 站不直接写 count = 1;？
直接写 1 是自己在脑子里算好了结果，没有体现"在原来的基础上上去一个人"这个过程；写 count = count + 1; 不管原来是几，都能正确地加 1，每一站的写法也都统一。
