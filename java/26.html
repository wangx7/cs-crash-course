第 1 节 · P26

键盘录入：让数据灵活起来

为什么要键盘录入？为了让操作的数据更灵活。int a = 10; 里的 10 是手动写死的。能不能键盘上敲 10，a 就记 10；敲 123，a 就记 123？可以。

要不要自己写操作系统和键盘之间的代码，什么发现键盘、配对键盘、连接键盘？不用。Java 已经把这些代码写好了，放在一个叫 Scanner 的类里，我们只要学会怎么用它。关于键盘录入只要知道两点：

  1. Scanner 是什么：Java 写好的一个类，可以接收键盘输入的数字。
  2. 使用步骤：三步。
① 导包找到 Scanner 在哪（Java 写好的类太多了）import java.util.Scanner;必须写在类定义的上面
② 创建对象表示"我要开始用 Scanner 了"Scanner sc = new Scanner(System.in);只有 sc 是变量名，可以改
③ 接收数据真正开始干活int i = sc.nextInt();只有 i 是变量名，可以改

建议先把三步当成固定格式，写熟了再改变量名。在"键盘录入"文件夹里新建 ScannerDemo1.java：

import java.util.Scanner; // 1. 导包：写在类定义的上面 public class ScannerDemo1 { public static void main(String[] args) { Scanner sc = new Scanner(System.in); // 2. 创建对象 System.out.println("请输入整数"); // 提示一下，不然不知道该干嘛 int i = sc.nextInt(); // 3. 接收数据：变量 i 记录了键盘录入的数据 System.out.println(i); } }

第 3 步建议分两段理解：sc.nextInt() 才是真正接收数据的代码，键盘输入什么它就接收什么；接收到之后再赋值给左边的变量 i。

第一次运行时没加提示：程序跑起来什么都不显示，其实是在等你键盘录入，输入 123 回车，才打印出 123。没有提示不知道该干嘛，所以在 nextInt 上面加一句"请输入整数"。

注意：这种方式只能接收整数。输入小数或中文会报错。Scanner 也能接收字符串等其他东西，后面再学。

动手：程序停在 nextInt 等你

点"运行"。蓝色高亮的那行就是程序停下来等键盘的地方，在右边的控制台里输入后按回车。试试输入小数、中文，或者在一行里输入 10 20。

输错了会怎样 输入 3.14 或 你好，程序会崩溃，报 java.util.InputMismatchException（输入不匹配异常），后面的代码都不会执行。超出 int 范围的数（比如 99999999999）也一样。
另外，nextInt 是按"空格或回车"分开取数的：一行里输入 10 20 再回车，第一个 nextInt 拿到 10，第二个 nextInt 直接拿到缓冲区里剩下的 20，不会再停下来等。上面的模拟器也是这样。
java.util 是 Scanner 所在的包（第 4 节会讲包）；System.in 表示"标准输入"，也就是键盘。
第 2 节 · P26

练习：键盘录入两个整数求和

需求键盘录入两个整数，求出它们的和并打印。

复制 ScannerDemo1 成 ScannerTest.java，类名跟着改，原来的代码删掉。先写一遍三步，接收第一个数。第二个数要不要把三步全部再写一遍？分析一下：

  • 导包是为了找到 Scanner，找一次就够了，不用找两次；
  • 创建对象相当于打个招呼"我准备用 Scanner 了"，接收第一个数时已经准备好了，不用再准备一次；
  • 所以只需要再接收一次数据。但变量不能重名，第一个叫 number1，第二个叫 number2。
import java.util.Scanner; public class ScannerTest { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.println("请输入第一个数字"); int number1 = sc.nextInt(); System.out.println("请输入第二个数字"); int number2 = sc.nextInt(); System.out.println(number1 + number2); } }

运行，输入 10 和 20，结果 30。上面的模拟器选"ScannerTest"就是这段代码。

第 3 节 · P27

IDEA：更智能的开发工具

记事本和 Notepad++ 能写代码，但不够智能：最起码，单词忘了它不会提示。换一个高级工具：IDEA，全称 IntelliJ IDEA，是用于 Java 开发的集成环境，业内公认目前最好用的 Java 开发工具，几乎所有企业都在用。

集成环境：把代码编写、编译、执行、调试等多种功能综合到一起的开发工具。以前编写用记事本，编译运行在 CMD 里敲 javac 和 java；现在全都在 IDEA 里完成。它还有很多贴心功能：自动保存（不用 Ctrl+S）、自动编译（写完直接运行就能看结果）。以后在 IDEA 里只要关注两件事：写代码和看运行结果。

视频还展示了 2017 年起的开发工具市场占有率：IDEA 从 42% 一路涨到 2021 年的 74%；第二名 Eclipse 在 IDEA 出现之前几乎是 Java 程序员的标配，很多老项目是用它开发的，所以至今还有一定份额；第三是安卓开发工具 Android Studio（它其实就是基于 IntelliJ 平台做的）。

下载安装

  • 官网 www.jetbrains.com/idea（记不住就搜"idea"），点右上角 Download。
  • 两个版本：旗舰版（Ultimate）功能全，收费，可以免费试用 30 天；社区版（Community）完全免费，功能只有一部分。视频建议下旗舰版。
  • 一定要按自己的操作系统选（Windows / macOS / Linux）。Windows 下有 exe 和 zip 两种，视频说 zip 是"安装包加说明文件"，其实不是，选 exe 安装包就行。
  • 安装是傻瓜式的：安装路径改到之前放开发工具的文件夹，比如 E:\develop\idea；选项里只勾"创建桌面快捷方式"（64-bit launcher），其他不勾，点安装。
补充：版本和授权 zip 和 JDK 的 zip 一样，是免安装版，解压到哪就能从哪运行，不会创建开始菜单和快捷方式。
学这门课的 Java SE 部分，免费功能完全够用；旗舰版多出来的主要是 Web 开发、Spring、数据库等企业开发功能，以后课程下部会用到。在校学生可以用学校邮箱向 JetBrains 申请免费的教育授权。JetBrains 近几年调整过版本的划分方式，下载页面长什么样以你当时看到的为准。
Mac：下载页选 macOS，按芯片选 Apple Silicon 或 Intel 的 .dmg，拖进"应用程序"文件夹就装好了。
第 4 节 · P28

项目结构：项目 → 模块 → 包 → 类

第一次用 IDEA 有点麻烦，因为要先弄懂它的项目结构，否则用不了。一共四层，拿微信打比方：

项目 project整个微信就是一个项目，最大的一层
模块 module微信下面的四大功能"消息、通讯录、发现、我"互相独立，可以看成四个模块。一个项目包含一个或多个模块
包 package就是文件夹。消息模块里有文字、图片、动画等很多代码，把相同功能的代码放进同一个包，方便管理：文字一个包、图片一个包、动画一个包……
类 class包里面才是写代码的类

在 IDEA 里写代码，必须把这四层都建出来。约定：第一阶段的代码看作一个完整的项目（basic-code），每一天的代码是一个模块（今天第二天，叫 day02-code）。

  1. 首次启动：问要不要导入设置，选“不导入设置”（第一次用，没什么可导的）；选免费试用 30 天，点“继续”。
  2. 新建项目：新建项目 → 列表里的 空项目 → 名称 basic-code，位置保持默认 → 创建（如果提示文件夹不存在要不要创建，选“是”）。
  3. 新建模块：会自动弹出“项目结构”窗口（没弹出就点 文件 → 项目结构…）→ 模块 → 中间上方的 + → 新建模块（导入模块以后学）→ 选 Java → 名称 day02-code，位置保持默认 → 创建 → 确定。等右下角进度条读完。
  4. 新建包：展开模块，右键 src → 新建 → 软件包。包名不要乱写，习惯用公司域名反写 + 包的作用：黑马官网是 www.itheima.com，反过来去掉 www 就是 com.itheima，再加上作用 demo1，即 com.itheima.demo1。右键 → 打开于 → 访达（Windows 上是“资源管理器”）看本地文件夹会发现这是多级包：com 里有 itheima，itheima 里有 demo1，多级包之间用点隔开。
  5. 新建类：右键点包 → 新建 → Java 类，输入 HelloWorld，选“类”回车。注意：右键点谁就是在谁里面新建；要是右键点 src，类就不在包里了。

动手：一步步搭出四层结构

按顺序点按钮，左边是 IDEA 里看到的结构，右边是硬盘上实际的文件夹。包名可以改，看看多级包怎么变成多层文件夹。

包名：

右边的编辑区就可以写代码了。IDEA 写代码很爽，不用一个个单词地敲：打一个 p 就提示 public，打 s 就提示 static。更快的是：

  • psvm 回车：生成 main 方法（public static void main 四个单词的首字母）；
  • sout 回车：生成输出语句 System.out.println();。

动手：psvm 和 sout

在类的大括号里输入 psvm 按回车，再在 main 里输入 sout 按回车，然后在括号里写 "HelloWorld"。

HelloWorld.java已自动保存

代码写完不需要保存、不需要编译，直接运行：右键空白处 → 运行 'HelloWorld.main()'（也可以点代码左边的绿色小三角，老师觉得右键最保险）。下面弹出的窗口叫控制台，输出语句打印的内容都显示在这里。

补充：包名的规范、几个快捷键 包名全部小写，每一段都要符合标识符规则（不能数字开头、不能是关键字）。所以 com.itheima.Demo1 能用但不规范，com.itheima.1demo 直接报错。上面的演示会检查这些。
运行快捷键：Windows Ctrl+Shift+F10，Mac ⌃+⇧+R。新版 IDEA 里输入 main 回车也能生成 main 方法。新建项目的窗口这几年改过几次样子，“空项目”一般在左侧列表里。

AI 编程助手

为了降低学习压力，视频推荐在 IDEA 里装一个 AI 编程插件（豆包 MarsCode）。它的作用有四个：

  1. 生成代码：先写注释，AI 直接生成代码。比如写注释"定义一个变量记录整数 10"，回车就生成 int number1 = 10;，按 Tab 采纳；再写"两个整数相加"，就生成 int sum = number1 + number2;。
  2. 修改 bug：比如把 number2 改成 0 再做除法，运行报 ArithmeticException: / by zero（除数为零的数学运算异常），还写着出错的是第几行。代码简单还看得懂，复杂了就不一定了。可以把代码和报错信息粘贴给 AI，说"请帮我修改错误"。它指出问题出在除数不能为 0，给出的修改用了一个后面会学的判断：除数是 0 就提示"除数不能为零"，否则才相除。
  3. 解答学习中的疑问：相当于一个 24 小时在线的免费老师。比如问"很多知识点我能听懂，但无法独立写出代码，怎么办"，它给了多练习、理解代码、用调试工具等十条建议。
  4. 刷算法题：自带几百道算法题，可以选 Java 写；没思路时先看"思路提示"，还不会再看"代码提示"。

使用步骤：注册账号；在 IDEA 的 设置 → 插件 → Marketplace 选项卡（插件市场）里搜索插件名，点“安装”，重启 IDEA，登录后右侧会多出插件图标。

补充：怎么用 AI 学编程才不亏 AI 插件的名字和功能变化很快，以 IDEA 插件市场里当时能搜到的为准；IDEA 自己也有官方的 AI Assistant。不管用哪个，对初学者有一条很重要：别让 AI 替你写练习。这门课反复强调"先分析需求再写代码"，你卡住的那一下，正是在练思维。比较好的顺序是：自己先想、先写；卡住了让 AI 给思路提示（不要代码）；还是不会，再看代码，看完关掉自己重写一遍。报错时先自己读一遍报错信息（第几行、什么异常），再去问 AI，慢慢就会自己看懂了。

IDEA 的几项设置

默认的字体小、背景黑，看着不爽，可以改一改。这些是老师的习惯，可以跟着设，也可以保持默认。几乎所有设置都在 文件 → 设置… 里。

设置位置老师的做法
主题外观与行为 → 外观 → 主题默认是黑色的 Darcula；上课时用 Windows 10 Light（白色），方便大家看
字体编辑器 → 字体字体 Consolas（专门为程序员设计的），字号 18，行距默认。字号按自己喜欢调
注释颜色编辑器 → 配色方案 → 语言默认设置 → 注释默认是灰色斜体，看着难受。把“行注释”和“块注释”的斜体去掉，颜色改成深绿色。什么颜色都行，千万别用红色：IDEA 里只有代码出错才是红色
自动导包编辑器 → 常规 → 自动导入勾上两个选项（“动态添加明确的 import”“动态优化 import”）。以后写 Scanner，上面的 import 会自动加上
提示忽略大小写编辑器 → 常规 → 代码补全去掉“区分大小写”的勾。这样写小写 string 也会提示大写的 String
背景图片外观与行为 → 外观 → 背景图像…视频说是"朋友"喜欢的设置：选一张图片，透明度设 20 左右，一边写代码一边看

课程资料里有这五项设置的截图，操作太快跟不上可以照着截图设。

Mac 上的位置 Mac 版 IDEA 的设置在菜单 IntelliJ IDEA → 设置…（快捷键 ⌘+,），不在“文件”菜单里，里面的结构一样。Mac 没有 Consolas 字体，可以用默认的 JetBrains Mono 或 Menlo。"Windows 10 Light"是老版本的主题名，新版 IDEA 在主题下拉列表里选一个浅色主题即可。

类、模块、项目的常见操作

对象操作怎么做
类新建想建在哪个包里，就右键哪个包 → 新建 → Java 类 → 输入类名 → 回车
删除右键类 → 删除 → 确定
改名不能只改代码里的类名（文件名和类名要一致）。右键类 → 重构 → 重命名…，或快捷键 Shift+F6，改完点“重构”，文件名和类名一起改
模块新建（目前只学这个）文件 → 项目结构… → 模块 → + → 新建模块 → Java → 起名（如 day03-code）→ 创建 → 确定。删除、修改、导入以后再学
项目关闭文件 → 关闭项目，回到项目列表（IDEA 默认打开上次操作的项目）
新建项目列表里 新建项目 → 空项目 → 起名（如 basic-code2）→ 创建。项目列表里点哪个就进入哪个。打开、修改项目以后再学
为什么改名要用“重命名” “重命名”不只是同时改文件名和类名，以后项目大了，别的类里所有用到这个类的地方也会一起改掉。手动改的话，漏掉一处就编译报错。Mac 上 F 键默认是调亮度音量的，Shift+F6 可能要加 fn。
第 8 节

小结

ScannerJava 写好的类，接收键盘输入。三步：import java.util.Scanner;（写在类上面）→ Scanner sc = new Scanner(System.in); → int i = sc.nextInt();（只能收整数）
多次录入导包和创建对象只写一次，接收数据写多次，变量名不能重复
IDEA集成开发环境：编写、编译、运行、调试都在里面；自动保存、自动编译
四层结构项目 → 模块 → 包（文件夹，域名反写如 com.itheima.demo1）→ 类。右键点谁就在谁里面新建
快捷psvm 生成 main 方法，sout 生成输出语句；右键 → 运行；Shift+F6 重命名
一句话 Scanner 让程序停下来等键盘，nextInt 拿到什么变量就记什么；IDEA 里写代码先搭好"项目 → 模块 → 包 → 类"四层。

自测

1. 键盘录入的三步是什么？哪一步的代码要写在类定义的上面？
导包 import java.util.Scanner;、创建对象 Scanner sc = new Scanner(System.in);、接收数据 int i = sc.nextInt();。导包要写在 public class 的上面。
2. 要录入两个整数，三步要写两遍吗？
不用。导包（找到 Scanner）和创建对象（准备开始用）做一次就够了，只需要再写一次 int number2 = sc.nextInt();，注意变量名不能和第一个重复。
3. 运行 ScannerDemo1 后控制台什么都没显示，是卡住了吗？输入 3.14 会怎样？
没卡住，程序停在 sc.nextInt() 等你输入（所以最好先打印一句提示）。输入 3.14 会报 InputMismatchException，程序终止：nextInt 只能接收整数。
4. IDEA 的四层结构从大到小是什么？用微信怎么类比？
项目 → 模块 → 包 → 类。整个微信是项目；消息、通讯录、发现、我是四个模块；消息模块里把文字、图片、动画的代码分别放进不同的包（文件夹）；包里是写代码的类。
5. 包名 com.itheima.demo1 在硬盘上是什么样的？想把 HelloWorld 建在这个包里，应该右键点哪里？
是三层文件夹：src/com/itheima/demo1。要右键点这个包新建类；右键点 src 的话，类会直接建在 src 里，不在包里。
