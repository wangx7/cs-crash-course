第 1 节 · P17 上半

注释：写给人看的说明

第二天的内容是 Java 的基础语法：注释、关键字、字面量、变量，最后再深入讲变量。先说注释。

HelloWorld 很简单，但课程越来越深，代码越来越难。刚写完时你知道它什么意思，过几天再看可能一脸懵。编程圈有个梗：代码刚写完，只有我和上帝看得懂；一个星期后，只有上帝看得懂了。每个程序员都有过这种经历。所以写代码时，一般会在代码上面写一些解释说明的文字，方便别人读，也方便自己以后读。这种文字就是注释。

定义：注释是在程序指定位置添加的说明性信息，简单理解就是对代码的解释说明。一共三种：

种类格式说明
单行注释// 注释信息最常用。只能写在一行里
多行注释/* 注释信息 */一行写不下时用。开头 /*，结尾 */，中间可以写很多行
文档注释/** 注释信息 */暂时用不上，不用记

为什么文档注释现在不用学？它的使用场景是：以后你厉害了，写的代码要给别人用，代码太多，别人不方便一行行读。这时可以用 Java 自带的 javadoc 工具，根据代码自动生成一份说明文档，文档注释里写的解释、作者、版本都会出现在文档里。别人用你的代码时看文档就行。可咱们现在什么段位？刚下载游戏、还没资格打排位，能写出并跑通 HelloWorld 就算青铜。用不到的知识点先不占脑细胞，等用到了再详细讲。

用 Notepad++ 打开 HelloWorld，给第 2、3 行加上注释：

public class HelloWorld { // 叫做 main 方法，表示程序的主入口 public static void main(String[] args) { /* 叫做输出语句（打印语句） 会把小括号里面的内容进行输出打印 */ System.out.println("HelloWorld"); } }
  • main 方法是程序的主入口：程序一运行，会自动去找 main 方法，从它里面的第一行代码开始从上往下逐行运行。格式是固定的，稍微记一下。
  • 输出语句（打印语句）：把小括号里的内容输出。

注释内容一行写不下，有两个办法：在下一行开头再写一个 // 接着写；或者干脆改用多行注释 /* … */。加了注释再编译运行，结果和原来一模一样：注释对运行结果没有任何影响。

文档注释长什么样 先认个脸，以后会学： /** * 打印一句问候语。 * @author 阿伟 * @version 1.0 */ 写在类或方法上面，@author、@version 这些标记会被 javadoc 识别。你平时查的 Java 官方 API 文档，就是用 javadoc 从 JDK 源码里的文档注释生成的。
第 2 节 · P17 上半

注释的两个细节

细节一：注释不参与编译，也不参与运行。有同学会问：手一抖把代码注释掉了，HelloWorld 还会打印吗？对一个知识点不确定时，写代码验证一下。把输出语句那一行注释掉，编译没问题，运行也不报错，但什么都没打印。注释只存在于 .java 文件里，javac 编译出的 class 文件里根本没有注释，所以注释里写什么都不影响结果。正因为这样，可以用注释来调试代码（后面慢慢用）。不过注释一般只写和代码相关的内容。

细节二：注释不要嵌套。

  • 有人喜欢在单行注释后面再加一个 //，觉得前后是两段话。语法上没错，但没意义：分隔两段话用逗号、句号就行。
  • 多行注释嵌套会出错。/* 会找离它最近的 */ 作为结尾。外层的 /* 一路往后找，找到的是内层的 */，于是到这里注释就结束了；后面那段只剩一个 */，缺了开头，就报错。在 Notepad++ 里不用编译就能看出来：后半段的颜色变了。

所以养成习惯：不管单行还是多行注释，都不要嵌套。

Java 一共有 50 多个关键字，不用背。每个关键字都包含一个甚至多个知识点，现在背了也没用，课程往后都会一一学到。目前只要能认出代码里哪些是关键字就行。

  
第一个关键字：class。它的作用是创建（定义）一个类。类是 Java 最基本的组成单元，就像人体的细胞：一个完整的人由大量细胞组成，一个完整的 Java 项目由成千上万个类组成。别怕，以后写项目时都会从零开始讲。

  public class HelloWorld {   ← class 后面跟着的是类名
    …                     ← 所有代码都写在类的大括号里
}                         ← 大括号表示类的范围

  

    更正：true、false、null 严格说不是关键字
    视频后面（P18）写 true、false 时说它们高亮了，"表示它也是一个关键字"。按 Java 语言规范，true、false、null 是字面量（下一节就讲），不在关键字列表里，只是和关键字一样不能拿来当名字，编辑器也会给它们上色。反过来，String、System 首字母大写，不是关键字，是 Java 写好的类的名字，有的编辑器也会给它们上色。所以"高亮"只能作参考，"全小写"更可靠。

第 4 节 · P18

  
字面量：数据在代码里怎么写

  
有的资料把字面量叫"常量"或"字面值"，叫常量不太准确，最准确的叫法是字面量。它告诉程序员：数据在程序里的书写格式。代码里要写的数据很多，比如年龄 18、名字"尼古拉斯阿伟"、身高 1.93。一般分 6 类，分三组来学：

  

    
类型写法举例

    
      
整数直接写，不加任何符号666　-88

      
小数直接写，带小数点13.14　-5.21

      
字符串用双引号括起来，里面写什么、写多少都行，什么都不写也行"HelloWorld"　"黑马程序员"

      
字符用单引号括起来，里面有且只能有一个：数字、字母、汉字、标点都行'A'　'0'　'我'

      
布尔只有两个值true　false

      
空一个特殊的值，表示什么都没有null

    
  

  
考考你：" "（双引号里一个空格）、""（什么都没有）、'abc' 分别是什么类型？

  
    
    
  • 前两个都是字符串：凡是双引号括起来的，不管写什么、写多少，哪怕不写，都是字符串。
    • 
    
  • 'abc' 满足了"单引号"，但里面有三个，不满足"只能有一个"，所以不是字符，也不是任何一种字面量，是语法错误，写进代码会报错。
    • 
  

  
布尔值 true 表示正确、false 表示错误，在项目里用来表示判断的结果。比如用户登录，成功是 true、失败是 false，两种情况执行不同的代码。空值 null 先记住这个值，学面向对象时还会再讲。


  
在代码里写一遍。复制 HelloWorld.java，改名 ValueDemo1.java，类名一定要改成和文件名一致。小技巧：类名很长时对着写容易错，可以选中文件按 F2（重命名），Ctrl+C 复制文件名，再粘到代码里。数据光写一个 666 不行，得对它做点什么，目前只会打印，所以都放进输出语句：

  public class ValueDemo1 {
    public static void main(String[] args) {
        // 目标：掌握常见的数据在代码中是如何书写的
        System.out.println(666);
        System.out.println(-777);
        System.out.println(1.93);
        System.out.println(-3.71);
        System.out.println("黑马程序员");
        System.out.println("尼古拉斯阿伟");
        System.out.println('男');
        System.out.println('女');
        System.out.println(true);
        System.out.println(false);
        System.out.println(null);      // ← 编译报错！
    }
}
  
性别这种只有一个字的内容，以后在项目里就可以用字符表示。编译时最后一行报错：null 不能直接打印。真要打印出 null 这四个字母，只能写成字符串 "null"。（在 CMD 里按 ↑ ↓ 可以翻出刚才用过的命令，不用重新敲。）


  

    
动手：给字面量分类

    
每个数据选一个类型，选错了会告诉你为什么。

    

    

  


  

    为什么 println(null) 会报错
    报错信息是 错误: 对println的引用不明确，后面说 println(char[]) 和 println(String) 都匹配。println 其实有好几个"版本"，分别负责打印整数、小数、字符、字符串、字符数组……给它一个 null，编译器发现"字符串版"和"字符数组版"都能接收 null，不知道该选哪个，只好报错。等学了变量就知道：先把 null 存进一个字符串变量再打印，就会正常打印出 null。这里的"好几个版本"叫方法重载，后面会学。
  

  

    字符和字符串不是一回事
    'A' 和 "A" 打印出来一样，但类型不同：字符是"一个字"，字符串是"一串字"（可以是 0 个、1 个或很多个）。所以 ''（单引号里什么都没有）也是错的，编译器会说"空字符文字"；而 "" 是合法的空字符串。

特殊字符：\t 制表符

  
还有一些特殊的字符字面量，比如 \t、\r、\n，今天先说 \t，叫制表符。它可以用单引号括起来（'\t'，表示一个特殊字符），也可以写在双引号里。

  
很多人把制表符解释成"缩进""对齐""大空格"，老师说这些都不对。它的作用是：打印时把前面字符串的长度补齐到 8 或 8 的倍数，最少补 1 个空格，最多补 8 个。

  
    
    
  • "abc" + '\t'：前面长度 3，补 5 个空格到 8；
    • 
    
  • 前面长度 4，就补 4 个。
    • 
    
  • 它只看前面的字符串，和后面的多长没关系。
    • 
  

  
有什么用？打印表格一样的数据时让它对齐。比如第一行打印 name 和 age，第二行打印 Tom 和 23，不加制表符会挤在一起，看着很难受；中间加上 \t，name 长度 4 补 4 个空格，Tom 长度 3 补 5 个空格，后面的 age 和 23 就对齐了。所以专业名词一般都有特殊含义，"制表符"就是"制作表格用的符号"。

  public class ValueDemo2 {
    public static void main(String[] args) {
        // 目标：熟悉制表符的基本用法
        System.out.println("name" + '\t' + "age");
        System.out.println("Tom" + '\t' + "23");
    }
}
  
这里的 + 表示字符串拼接：把前后的内容拼成一个字符串再打印。

    补充：\t 的"补齐"其实是屏幕干的
    严格地说，Java 打印的只是一个制表符字符（编号 9），并没有真的打印几个空格。是 CMD、终端这些显示程序看到它，把光标跳到下一个"制表位"。CMD 的制表位每 8 格一个，所以看起来是"补齐到 8 的倍数"。有的软件制表位是 4 格（比如很多代码编辑器），同样的输出会对齐到 4 的倍数。

    还有，一个汉字在控制台里通常占 2 格，所以"姓名"按显示宽度算是 4 而不是 2，上面的演示也是按显示宽度算的。第一列内容如果长短差太多（比如一个 3 格、一个 10 格），它们会落在不同的制表位上，照样对不齐。

    \n 是换行，\r 是回车（光标回到行首），这类以反斜杠开头的叫转义字符。想打印一个双引号写 \"，打印反斜杠本身写 \\。
  







  
第 6 节

  
小结

  

    
      
注释对代码的解释说明。// 单行、/* */ 多行、/** */ 文档（暂不用）。不参与编译和运行，class 里没有注释；不要嵌套

      
关键字被 Java 赋予特定含义的英文单词，全部小写，编辑器有高亮。class 用来定义类，后面跟类名，大括号是类的范围

      
字面量数据的书写格式，6 类：整数、小数、字符串（双引号）、字符（单引号，有且只有一个）、布尔（true/false）、空（null）

      
两个特殊null 不能直接打印，要打印写成 "null"；\t 把前面的长度补齐到 8 的倍数，用来对齐表格数据

    
  


  

    一句话
    注释写给人看、编译时被扔掉；关键字是 Java 预留的小写单词；字面量决定数据怎么写：双引号是字符串，单引号里只能放一个字符。
  


  

    
自测

    

      
1. 把输出语句整行注释掉，编译会报错吗？运行结果是什么？

      
      
不报错，运行也不报错，只是什么都不打印。注释不参与编译和运行，编译出的 class 文件里没有这行代码了。

    

    

      
2. 下面这段为什么会出错？
/* 外层 /* 内层 */ 外层后半段 */

      
      
第一个 /* 会和离它最近的 */（内层那个）配对，注释到那里就结束了。后面的"外层后半段 */"变成了代码，那个 */ 没有开头，所以报错。多行注释不能嵌套。

    

    

      
3. String、class、main、static，哪些是关键字？

      
      
class 和 static 是关键字。String 首字母大写，是 Java 写好的类名；main 是方法名，都不是关键字。

    

    

      
4. " "、""、'abc'、'男' 分别是什么？

      
      
前两个都是字符串（双引号里写什么、写不写都是字符串）；'abc' 单引号里有三个，不是任何字面量，语法错误；'男' 是字符。

    

    

      
5. 在 CMD 里运行 System.out.println("abcd" + '\t' + "x");，abcd 和 x 之间有几个空格？换成 "abcdefgh" 呢？

      
      
abcd 长度 4，补 4 个空格到 8。abcdefgh 长度正好是 8，已经是 8 的倍数，但 \t 至少要补 1 个，所以一口气补满 8 个，到 16。这就是"最多补 8 个"的情况。
