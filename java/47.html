第 1 节 · P47

while 循环的格式和执行流程

while 的格式和 for 很像：写一个 while 关键字，然后把 for 的四个部分原样搬过来，只是换了位置：初始化语句写在最上面，小括号里只写条件判断语句，大括号里写循环体语句和条件控制语句。

for

for (初始化语句; 条件判断语句; 条件控制语句) {
    循环体语句;
}

while

初始化语句;
while (条件判断语句) {
    循环体语句;
    条件控制语句;
}

执行流程和 for 一模一样：先执行初始化语句；再执行小括号里的条件判断，为 true 就进大括号执行循环体和条件控制语句，然后回到上面再判断；为 false 循环结束，执行下面的其他语句。特点也一样：初始化语句只执行一次；判断为 true 循环继续，为 false 循环结束。

练习：用 while 打印 1~100。开始条件是 1、结束条件是 100：

int i = 1; while (i <= 100) { System.out.println(i); i++; }
第 2 节 · P47

for 和 while 有什么区别，什么时候用哪个

先说共同点：两者的运行规则一模一样。很多资料会说它们有一个唯一的小区别，在初始化语句上：

  • for 循环里控制循环的变量，归属于 for 的语法结构，循环结束后就不能再访问了（变量从内存中消失）；
  • while 循环里控制循环的变量写在循环外面，不归属于它的语法结构，循环结束后还能继续使用。

但这个说法并不绝对：for 也可以把初始化语句写到循环外面，小括号里那一栏空着不写（for (; i <= 100; i++)），这时两种循环就没有任何区别了。所以从实际开发的角度说：

  • 语法上没有区别：能用 for 的地方一定能用 while 改写，反过来也一样；
  • 区别在使用习惯：for 一般在知道循环次数或循环范围时用；while 在不知道次数、也不知道范围，但知道循环的结束条件时用。
for 的三栏都可以空 不只是初始化，三栏都能省略，但两个分号必须留着：for (;;) { } 就是一个停不下来的循环，和 while (true) { } 一样。下一篇讲无限循环时会再见到它们。

练习：打印折纸的次数

这是美国斯坦福大学的一道 Java 练习题。世界最高峰珠穆朗玛峰高 8844.43 米，也就是 8844430 毫米。假如有一张足够大的纸，厚度 0.1 毫米，请问折叠多少次，可以折成珠穆朗玛峰的高度？

别纠结"纸真能折那么多次吗"，这道题和折纸本身没关系，只是训练循环。要抓住核心：代码里怎么体现"折叠"这个动作？折一次，厚度变成原来的两倍：0.1 → 0.2 → 0.4 → 0.8……不停地折，只要厚度大于等于山峰的高度，循环就停止。

用 for 还是 while？知不知道循环次数？不知道。知不知道循环范围？也不知道。但能知道结束条件：纸张厚度 >= 山峰高度。所以用 while 更好。

步骤：① 定义变量记录山峰的高度；② 定义变量记录纸张的初始厚度；③ 循环折叠纸张，只要厚度小于山峰高度，循环就继续，每次 paper = paper * 2（也可以写 paper *= 2）。题目还要统计折了几次，所以 ④ 再定义一个统计次数的变量，每折一次就 ++。

double height = 8844430; // 单位要和纸的厚度统一，都用毫米 double paper = 0.1; int count = 0; // 不知道次数、不知道范围，只知道结束条件，用 while while (paper < height) { paper = paper * 2; count++; } System.out.println(count); // 27

结果是 27 次。觉得不可思议？视频里打开计算器从 0.1 开始一次次乘 2：折到第 26 次是 6710886.4 毫米，还不够；再折一次就超过珠峰了。别忘了每折一次，厚度都是原来的两倍。

练习：回文数（力扣算法题）

这是力扣（LeetCode）上的一道算法题，通过率大约 60%，能听懂并自己写出来，就超过了 40% 的程序员。需求：给你一个整数 x，如果是回文数打印 true，否则打印 false。回文数：从左往右读和从右往左读一样，比如 121 是，123 不是。

第一反应：把数字倒过来，和原来的数比一下。思路没错，关键是怎么把数字倒过来。

先试两位数：x = 12。用以前学的公式拿到个位 x % 10 = 2、十位 x / 10 % 10 = 1。直接 2 + 1 得 3，倒个什么呀；要把个位乘 10 再加十位：2 × 10 + 1 = 21，倒过来了。可 x 是写死的 12，换成 123、1234、12345 就不行了，所以要用循环。

用 for 还是 while？12345 要循环 5 次，换成 1234 就是 4 次，次数不确定，所以用 while。结束条件一时想不到可以先空着，先写循环体：

  1. 从右往左获取每一位：int ge = x % 10; 拿到最右边的一位；
  2. 去掉已经拿到的这一位：x = x / 10;。1234 / 10，Java 里整数相除只能得到整数，结果是 123，相当于把右边的 4 去掉了，下一轮就会拿到 3；
  3. 拼接到结果的最右边：在循环外定义 int num = 0;，循环里 num = num * 10 + ge;。

结束条件：1234 第一轮拿 4、x 变 123，第二轮拿 3、x 变 12，第三轮拿 2、x 变 1，最后一轮拿 1、x 变 0。不确定的话，可以先写 while (true) 在循环里打印 x 看看，确实最后变成 0。x 为 0 就没意义了，所以条件写 x != 0：x 里还有值就继续。打印 num，1234 变成 4321，12345 变成 54321。

最后一步：比较。直接 num == x？试一下，12345 打印 false，看起来对；可换成 121 还是 false！把 x 打印出来一看：x 已经变成 0 了，因为循环里一直在修改 x 的值。所以要在循环前定义一个临时变量 temp 记录 x 原来的值，专门用于最后的比较：

int x = 12345; int temp = x; // 临时变量，记录 x 原来的值，用于最后比较 int num = 0; // 记录倒过来之后的结果 while (x != 0) { int ge = x % 10; // 从右往左获取每一位 x = x / 10; // 去掉刚拿到的那一位 num = num * 10 + ge; // 拼接到结果的最右边 } System.out.println(num == temp);

这道题的核心思路很简单：把数字倒过来，和原来的数字比较；难点在循环里怎么倒过来。思路顺了，题目就不难。

力扣原题还多两个坑 这道是力扣第 9 题。① 负数：题目规定 -121 不是回文数（反过来读是 121-），但上面的代码会把 -121 倒成 -121，打印 true。最简单的办法是先判断 x < 0 直接 false。（在上面的演示里输 -121 试试。）② 溢出：int 最大 2147483647，像 1999999999 这种数倒过来是 9999999991，超出 int 范围，num 会算错。不过它本来就不是回文数，错的结果也不会等于 temp，所以这道题的答案碰巧不受影响；换成"把数字倒过来"这种题，就要用 long 或者提前判断了。

练习：求商和余数（力扣算法题）

需求：给定两个整数，被除数和除数（都是正数，且不超过 int 的范围）。将两数相除，要求不使用乘法、除法和 % 运算符，得到商和余数。

忘了哪个是被除数？不用给小学数学老师打电话：被除数 ÷ 除数 = 商 …… 余数。

思路：不能用除法，就用减法。被除数 100、除数 10：100 − 10 = 90，90 还比 10 大，接着减，80、70、60……最后 10 − 10 = 0。0 比 10 小，不能再减了，这个 0 就是余数；一共减了多少次，就是商。

次数和范围都不知道，用 while。只要被除数 >= 除数就一直循环，循环里用被除数减去除数，结果再赋值给被除数。循环结束后，被除数里剩下的就是余数。写到这里才发现还要商？想到多少写多少，用到什么再回头补，这才是正确的编程思维：在循环外补一个统计变量，每减一次就 ++，它就是商。

int dividend = 100; // 被除数 int divisor = 37; // 除数 int count = 0; // 统计相减了多少次 while (dividend >= divisor) { dividend = dividend - divisor; count++; // 减一次，统计变量就自增一次 } System.out.println("余数为" + dividend); // 余数为26 System.out.println("商为" + count); // 商为2

验证：100 和 10，余数 0；10 和 3，余数 1、商 3；100 和 37，余数 26、商 2。都和实际一样。这些算法题以后在企业面试中也可能碰到，刚接触觉得难很正常，不要慌，慢慢分析几遍就好。

第 6 节 · P48

do…while：先执行，后判断

循环的第三种格式，以后用得非常少，简单了解一下。

初始化语句; do { 循环体语句; 条件控制语句; } while (条件判断语句);

循环体和条件控制语句跑到了判断的上面。执行流程：先执行初始化语句；然后不判断，直接执行一次循环体和条件控制语句；最后才执行条件判断，true 就回到上面再来一轮，false 就结束。

所以 do…while 最大的特点是先执行后判断：就算条件第一次就是 false，循环体至少也会执行一次。而 for 和 while 第一次判断就是 false 的话，循环体一次机会都没有。

好比去饭店吃饭：for 和 while 是先摸摸兜里有没有钱，没钱就走；do…while 就很粗暴，不管怎样先吃一顿，吃完再看兜里有没有钱，没钱就走，有钱接着吃。

while 格式初始化; while (判断) { 循环体; 条件控制; }，流程和 for 一样

      
for 还是 while语法上可以互相改写；知道次数或范围用 for，只知道结束条件用 while

      
折纸"折叠"就是 paper *= 2；while (paper < height) 加 count++，27 次

      
倒过来ge = x % 10; x = x / 10; num = num * 10 + ge;，直到 x 为 0

      
temp循环会改掉 x，要比较原值就先用临时变量存一份

      
商和余数不断减除数，减的次数是商，剩下的是余数

      
do…while先执行后判断，循环体至少执行一次；几乎不用

1. 把 for (int i = 1; i <= 100; i++) { System.out.println(i); } 改写成 while。

      
      
int i = 1; while (i <= 100) { System.out.println(i); i++; }

    

    

      
2. "存款 1 万元，年利率 3%，多少年后翻倍"，用 for 还是 while？

      
      
while。不知道要循环几年，只知道结束条件：钱 >= 2 万。

    

    

      
3. 回文数的代码里，为什么不能直接写 num == x？

      
      
循环里一直在执行 x = x / 10，循环结束时 x 已经是 0 了。要提前用 temp 记录原来的值，最后和 temp 比。

    

    

      
4. 用"不断相减"的方法算 17 ÷ 5，循环执行几次？最后 dividend 和 count 各是多少？

      
      
3 次：17 → 12 → 7 → 2，2 < 5 停止。dividend = 2（余数），count = 3（商）。

    

    

      
5. int i = 10; do { System.out.println(i); i++; } while (i <= 5); 打印什么？

      
      
打印一次 10。do…while 先执行一次循环体，再判断 11 <= 5 为 false，结束。
