第 1 节 · P35

四种逻辑运算符

数学里"一个数大于 5、小于 15"可以写成 5 < x < 15，但在 Java 里不能连着写。要先拆成 x > 5 和 x < 15 两个式子，再用逻辑运算符合起来：x > 5 & x < 15，中间的 & 表示"并且"，x 要同时满足两个条件。这就是逻辑运算符存在的意义。

符号名字读作规则
&逻辑与并且、而且两边都为真，结果才是真（Shift+7）
|逻辑或或者两边都为假，结果才是假（Shift+回车上方的 \ 键）
^逻辑异或相同为 false，不同为 true（Shift+6）。用得非常少，了解即可
!逻辑非取反true 变 false，false 变 true

在 IDEA 里写四行 System.out.println(true & true); 再改成其他组合就能验证（Ctrl+D 可以把当前行向下复制一行）。实际开发中怎么选：

  • 并且：用户登录时用户名和密码都要正确才算成功。两边条件同时满足，用 &。
  • 或者：丈母娘说"有房子或者有车子，就可以娶走我女儿"，只要有一个就行，用 |。要是改口"房子和车子都要有"，就得换成并且。所以不能随便用，要看业务场景。
  • 异或，记忆小故事：民政局结婚登记，两个男生不行、两个女生也不行（相同为 false），一男一女才行（不同为 true）。
  • 取反：感叹号要么不写，要么只写一次。!!false 取两次反又回到 false，和不写一样，写三个和写一个一样，"程序员何苦为难程序员"。

第 2 节 · P36

短路逻辑运算符：左边能定就不算右边

用逻辑运算符写代码还能再优化。还是用户登录：先判断用户名，再判断密码。用户名正确，继续判断密码是必须的；可用户名都错了，还需要判断密码吗？不需要，不管密码对不对，整个表达式都是 false，登录失败。但用单个的 &，不管用户名对不对，都会去判断密码，效率低。

丈母娘也一样：先看房子，没房子才需要去看车子；房子已经有了，再去看车子就没意义了（"您老还看什么车子呢，够累的"）。单个的 | 不管左边真假，右边都会执行。

所以有了短路逻辑运算符：

符号名字结果短路效果
&&短路与和 & 一样左边为 false，右边不执行（结果一定是 false）
||短路或和 | 一样左边为 true，右边不执行（结果一定是 true）

两个符号连在一起，中间没有空格。运行结果和单个的完全一样，只是多了短路效果：左边的表达式已经能确定最终结果时，右边就不参与运行了，效率更高。

视频用自增（P33 学过的 ++）来证明右边到底有没有执行：

int a = 10; int b = 10; boolean result = ++a < 5 && ++b < 5; System.out.println(result); // false System.out.println(a); // 11 System.out.println(b); // 10 ← 右边根本没执行，b 没有自增

a 先自增成 11，11 < 5 是 false；&& 的左边是 false，结果已经确定，右边不执行，所以 b 还是 10。换成单个的 &，右边照样执行，b 就变成 11。

    这个过程听着有点懵也没关系，只要记住最后一句：以后最常用的逻辑运算符是三个：短路与 &&、短路或 ||、取反 !。

    补充：短路不只是快，还能防错 短路最大的用处其实是"先检查、再使用"。比如 b != 0 && a / b > 1：b 是 0 时左边为 false，右边的除法根本不会执行，也就不会出现"除以 0"的异常；要是写成单个 &，b 为 0 时程序直接崩溃。以后学到对象，str != null && str.length() > 0 这种写法会天天见。
    另外，单个的 &、|、^ 用在两个整数之间时，是按二进制位来运算的（位运算），这在 P38 讲完补码之后会更好理解。

    练习：数字 6

    需求（斯坦福大学 Java 入门练习）数字 6 是一个伟大的数字。键盘录入两个整数：如果其中一个为 6，输出 true；如果它们的和是 6 的倍数，也输出 true；其他情况输出 false。

    分析：第一步键盘录入两个整数（变量名起得有意义：number1、number2，别叫 a、b）。第二步判断。输出 true 的情况有几种？不是两种，是三种：

    1. number1 为 6；
    2. number2 为 6；
    3. 两数之和是 6 的倍数：和对 6 取模等于 0。

    三个条件满足其中一个就行。以前都是两个条件，三个能连吗？能：三个条件中间写两个 ||。

    Scanner sc = new Scanner(System.in); System.out.println("请输入一个整数"); int number1 = sc.nextInt(); System.out.println("请输入第二个整数"); int number2 = sc.nextInt(); boolean result = number1 == 6 || number2 == 6 || (number1 + number2) % 6 == 0; System.out.println(result);

    测试时除了测正常情况（6 和 10、1 和 6、2 和 4 都是 true），还要测不满足的情况（5 和 10 应该是 false），这样才能证明代码是对的。

      三元运算符：根据判断二选一

      这个知识点有点小难，认真听。定义一个变量记录整数 10，小菜一碟；如果要让变量记录两个整数中的较大值呢？得先比较，再把比较后的结果存进去。这个比较可以用三元运算符（也叫三元表达式）完成：根据判断的结果得到不同的内容。

      关系表达式 ? 表达式1 : 表达式2; int max = a > b ? a : b; // 把结果赋值给变量 System.out.println(a > b ? a : b); // 或者直接打印（括号里不加分号）

      计算规则：先算问号前面的关系表达式（一个判断）。结果为 true，表达式1 的值就是整个三元运算符的结果；为 false，表达式2 的值就是结果。

      注意：三元运算符的结果必须被使用：要么赋值给变量，要么直接打印。单独写一行 a > b ? a : b; 会报错。

      它的两个难点：格式长不好记，先花点时间记下来；运算规则容易忘，记住"问号前面是判断，真取冒号左边，假取冒号右边"。

      第 5 节 · P37

      两个练习：两只老虎、三个和尚

      两只老虎：动物园里有两只老虎，体重分别通过键盘录入获得，判断两只老虎的体重是否相同。

      直接写 weight1 == weight2 也能判断，但结果只能是 true 或 false。想看到"相同"或"不同"，就用三元运算符：两个结果都是字符串，所以用 String 变量接收。

      String result = weight1 == weight2 ? "相同" : "不同"; System.out.println(result);

      三个和尚：寺庙里住着三个和尚，身高分别是 150cm、210cm、165cm，获取三个和尚的最高身高。三个数怎么比？先拿前两个比，得到较大值，再拿这个较大值和第三个比。

      int height1 = 150; int height2 = 210; int height3 = 165; int temp = height1 > height2 ? height1 : height2; // 临时变量：1 和 2 中的较大值 int max = temp > height3 ? temp : height3; System.out.println(max); // 210

      代码排得不整齐时，按 Ctrl+Alt+L 自动格式化（会和 QQ、网易云音乐、百度网盘等软件的快捷键冲突，把它们关掉就行）。

      动手：三元运算符走的是哪条路

      补充：三元运算符的两个结果要"合得来" 冒号两边的表达式类型要能统一，因为整个三元运算符只能有一个结果类型。int max = a > b ? a : b; 两边都是 int 没问题；int x = flag ? 1 : "一"; 就会报错。三元运算符适合"二选一、结果很简单"的情况；条件一多、逻辑一复杂，下一章的 if 读起来更清楚。
      第 6 节 · P37

      运算符的优先级

      a + b * c 先算谁？小学说过先乘除后加减，所以先算 b * c，再加 a。但现在学了这么多运算符，它们都有优先级，视频给了一张完整的优先级表。让你背下来，内心是拒绝的吧？只要记住一点：小括号优先于所有。想让谁先算，就用小括号把它括起来：a + (b * c)。不管谁来看，都知道先算 b * c 再加 a，提高了阅读性。养成加小括号的习惯就好。

      补充：一张够用的优先级简表（从高到低）
      1()小括号
      2++ -- !、正负号、强制转换一元运算符
      3* / %乘除取模
      4+ -加减（也包括字符串拼接）
      5< <= > >=比较大小
      6== !=相等
      7& → ^ → |逻辑与、异或、或
      8&& → ||短路与比短路或高
      9? :三元
      10= += -= …赋值，最后算
      最容易踩坑的一条：&& 比 || 优先级高，a || b && c 实际是 a || (b && c)。混用时加括号最稳。还有：比较运算符比 && 高，所以 x > 5 && x < 15 不用加括号也是对的。
      第 7 节

      小结

      逻辑运算符& 两边都真才真（并且）；| 两边都假才假（或者）；^ 相同为 false、不同为 true（少用）；! 取反（最多写一个）
      短路&& 左边 false 右边不执行；|| 左边 true 右边不执行。结果和单个的一样，效率更高。常用：&& || !
      三元运算符关系表达式 ? 表达式1 : 表达式2。真取 1，假取 2；结果必须被使用
      三个数比较先比前两个得到较大值（temp），再和第三个比
      优先级小括号优先于所有，想先算谁就括起来
      一句话 用 && 和 || 连条件，左边能定就不看右边；用 ?: 在两个结果里挑一个；拿不准先后，就加括号。

      自测

      1. Java 里怎么写"x 大于 5 并且小于 15"？
      x > 5 && x < 15（用单个 & 结果也对，但推荐短路与）。不能写成 5 < x < 15。
      2. int a = 10, b = 10; boolean r = ++a > 5 || ++b > 5; 之后 r、a、b 分别是多少？
      r = true，a = 11，b = 10。左边 11 > 5 为 true，短路或的结果已经确定，右边不执行，b 不自增。
      3. 数字 6 练习里，为什么是三个条件、用两个 || 连起来？
      输出 true 的情况有三种：number1 是 6、number2 是 6、两数之和是 6 的倍数（(number1 + number2) % 6 == 0），满足任意一个就行，所以用"或者"连接，三个条件需要两个 ||。
      4. 单独写一行 a > b ? a : b; 为什么报错？
      三元运算符的结果必须被使用：赋值给变量（int max = a > b ? a : b;）或者直接打印。
      5. 用三元运算符求三个数 150、210、165 的最大值，思路是什么？
      先 int temp = h1 > h2 ? h1 : h2; 得到前两个的较大值 210，再 int max = temp > h3 ? temp : h3;，结果 210。
