# 计算机科学速成课（图文版）

把 PBS Digital Studios 的 **Crash Course Computer Science**（中文字幕由 1c7 翻译组整理）改成一集一页的图文版：正文据中文字幕整理，配手绘示意图，关键处附可以动手点的小演示，每集末尾有小结和自测题。

- 在线阅读：<https://wangx7.github.io/cs-crash-course/>
- 目录：`index.html`，可按"只看学习计划里的集"筛选
- 每集一个页面：`01.html` … `40.html`（当前 25 集，其余"制作中"）

## 目录结构

```
index.html   目录页
NN.html      第 N 集
cc.css       共用样式（含暗色模式）
cc.js        共用的 SVG / 交互辅助函数
```

纯静态页面，没有构建步骤，直接打开 `index.html` 即可。
