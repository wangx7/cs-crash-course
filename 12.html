第 0 节

语句和语法

上一集讲到，用原生机器码写程序、还得应付那么多底层细节，是编写复杂程序的巨大障碍。为了把这些底层细节抽象掉，人们开发了编程语言，让程序员专注于用计算解决问题，而少操心那些琐碎的硬件细节。今天我们接着这个话题，介绍几乎所有编程语言都提供的一些基本积木。

就像口头语言一样，编程语言也有语句（statement）。语句是一个个完整的意思，比如"我想要茶"或者"在下雨"。换用不同的词，可以改变意思，比如把"我想要茶"改成"我想要独角兽"。但我们不能把"我想要茶"改成"我想要在下雨"——这在语法上讲不通。规定一门语言中语句结构和组成方式的那套规则，叫语法（syntax）。英语有语法，所有编程语言也都有。

第 1 节

变量和赋值语句

a = 5 是一条编程语言语句，意思是一个名叫 a 的变量里存着数字 5。这叫赋值语句，因为我们在把一个值赋给一个变量。

要表达更复杂的东西，就需要一串语句，比如"a 是 5，b 是 10，c 等于 a 加 b"。这个程序告诉计算机：把变量 a 设为 5，变量 b 设为 10，最后把 a 和 b 加起来，结果 15 放进——你猜到了——变量 c。

注意，变量想叫什么都行。不叫 a、b、c，也可以叫 apples、pears、fruits。计算机不在乎，只要变量名不重复就行。不过最好起有意义的名字，以防别人想读懂你的代码。

程序是一列指令，有点像菜谱：烧水、下面、等 10 分钟、捞出来、开吃。程序也一样，从第一条语句开始，一次运行一条，往下一直走到结尾。

第 2 节

初始化变量和 if 语句

到目前为止，我们只是把两个数加了起来。无聊。我们来做个电子游戏吧！当然，现在想写一整个游戏还太早了，所以我们用这个例子写一些小代码片段，涵盖一些编程基础。

想象我们在做一款老派街机游戏：葛丽丝·霍普要在虫子钻进哈佛马克一号、把计算机搞崩溃之前抓住它们！每一关的虫子都会变多，葛丽丝得在它们磨坏机器里的继电器之前抓住它们。幸运的是，她有几个备用继电器可以用来修理。

开始之前，我们需要记录一堆对游戏很重要的值，比如玩家在第几关、得分、还剩几只虫子，以及葛丽丝手里还有几个备用继电器。所以我们要初始化变量，也就是设置它们的初始值："关卡等于 1，分数等于 0，虫子数等于 5，备用继电器等于 4，玩家名字等于 "Andre"。"

要做出可以交互的游戏，我们需要控制程序的流程，而不只是从上往下跑。为此我们使用控制流语句。它有好几种，最常见的是 if 语句。你可以把它理解成"如果 X 为真，就做 Y"。用日常语言举例："如果我累了，就去拿茶。"如果"我累了"为真，我就去拿茶；如果为假，我就不去。

if 语句就像路上的岔路口，走哪条路取决于表达式是真还是假，所以这些表达式叫条件语句。在大多数编程语言里，if 语句大概长这样："IF 表达式 THEN 一些代码，然后结束 if 语句"。比如，如果 level 是 1，就把分数设为 0，因为玩家才刚开始；同时把虫子数设为 1，先让游戏简单些。注意，依赖这个 if 条件的那几行代码，被嵌套在 IF 和 END IF 之间。

当然，我们可以把条件表达式改成任何想测试的东西，比如"分数大于 10"或"虫子数小于 1"。if 语句还可以和 ELSE 语句组合，表达式为假时由它兜底：如果 level 不是 1，就执行 ELSE 块里的代码，把葛丽丝要对付的虫子数设为关卡数的 3 倍。所以第 2 关有 6 只虫子，第 3 关有 9 只，以此类推。ELSE 块里没有修改分数，所以葛丽丝能保留已经挣到的分数。

动手：if / else

    score = 0

  score = 0;

}

    score = 0;
    bugs = 1;
} else {
    bugs = 3 * level;
}

    score = 0
    bugs = 1
Else

End If

第 3 节

while 循环

if 语句只执行一次：选好一条条件路径，程序就继续往下走。要让一些语句重复执行很多次，需要创建条件循环。一种方式是 while 语句，也叫 while 循环。你可能猜到了，它在条件为真的"期间"（while）反复执行一段代码。不管哪种编程语言，它们大概都长这样。

在我们的游戏里，假设到了某些时候，一位友善的同事会给葛丽丝补充继电器！好耶！要把他补货、直到补满 4 个的过程做成动画，可以用一个 while 循环。我们来走一遍这段代码。

首先假设同事进场时葛丽丝只剩 1 个继电器。进入 while 循环时，计算机做的第一件事是测试条件……继电器少于 4 个吗？继电器现在是 1，所以是的。现在进入循环！接着遇到这一行代码："relays 等于 relays 加 1"。这有点让人困惑，因为这个变量在赋值语句里用到了它自己，我们来拆开看。你总是先算等号右边：relays 加 1 等于多少？relays 现在是 1，1 加 1 等于 2。然后这个结果被存回变量 relays，覆盖旧值，所以 relays 现在存着 2。

到了 while 循环的末尾，程序跳回上面。和之前一样，测试条件看是否进入循环：relays 少于 4 吗？是的，relays 现在是 2，所以再次进入循环！2 加 1 等于 3，3 存进 relays。再循环：3 小于 4 吗？是的！再进入循环：3 加 1 等于 4，4 存进 relays。再循环：4 小于 4 吗？……不！条件现在为假，于是退出循环，继续执行后面的代码。这就是 while 循环的工作方式！

第 4 节

for 循环

还有常见的 for 循环。while 是由条件控制的循环，可以一直重复下去，直到条件为假；而 for 循环是由次数控制的，重复特定的次数。它们大概长这样。放一些实际的值进去：这个例子会循环 10 次，因为我们指定了变量 i 从 1 开始，一直到 10。for 循环的独特之处在于，每次遇到 NEXT，就给 i 加 1。当 i 等于 10 时，计算机知道已经循环了 10 次，于是退出循环。这个数想设成多少都行——10、42、十亿——由我们决定。

假设我们想在每一关结束时，根据玩家剩下的继电器数量给一笔奖励分。随着游戏越来越难，留下没用的继电器需要更高的技术，所以我们希望奖励分随关卡数呈指数级增长。我们需要写一段计算指数的代码——也就是把一个数自己乘自己特定的次数。循环正适合干这个！

首先初始化一个叫 bonus 的新变量，设为 1。然后创建一个 for 循环，从 1 循环到关卡数。在循环里，把 bonus 乘以继电器数，再把新值存回 bonus。比如 relays 等于 2，level 等于 3，for 循环就会循环三次，也就是 bonus 会乘以 relays……乘以 relays……再乘以 relays。在这个例子里就是乘 2、乘 2、再乘 2，奖励分是 8！也就是 2 的 3 次方！

第 5 节

函数：把代码打包起来

这段指数代码很有用，我们可能想在代码的其他地方也用它。到处复制粘贴、每次还得改变量名，会很烦。而且如果发现了 bug，就得到处找、把每个用到它的地方都改一遍。它还会让代码看起来更乱。少即是多！

我们想要的，是一种把指数代码打包起来的方式：可以使用它、拿到结果，却不必看到里面所有的复杂细节。我们又一次往上爬了一层抽象！为了把复杂性分隔、隐藏起来，编程语言可以把一段代码打包成有名字的函数（function），在不同的编程语言里也叫方法（method）或子程序（subroutine）。程序的其他任何部分，只要叫出它的名字，就能使用这个函数。

我们把指数代码变成函数！首先得给它起名字。叫什么都行，比如 HappyUnicorn（快乐独角兽），但既然这段代码是算指数的，就叫它 Exponent 吧。另外，不再使用 relays、level 这样特定的变量名，而是用 Base（底数）和 Exp（指数）这样通用的变量名，它们的初始值会从程序的其他部分"传"进函数。其余代码和之前一样，只是被收进了函数里、换了新的变量名。最后，我们需要把指数代码的结果送回给请求它的那部分程序。为此我们用 RETURN 语句，指明返回 result 里的值。

现在，只要叫出函数名、传进两个数，就可以在程序的任何地方使用这个函数。比如想算 2 的 44 次方，只要调用 Exponent(2, 44)，大约 18 万亿就返回来了。在幕后，2 和 44 被存进函数里的变量 Base 和 Exp，函数按需跑完所有循环，然后带着结果返回。

第 6 节

函数调用函数

用我们新做的函数来计算奖励分。首先把 bonus 初始化为 0，然后用 if 语句检查玩家还有没有剩下的继电器。如果有，就调用 Exponent 函数，传进 relays 和 level，它算出 relays 的 level 次方并返回结果，我们把结果存进 bonus。

这段计算奖励分的代码之后可能也有用，所以我们把它也包装成一个函数——CalcBonus！没错，一个调用函数的函数！然后，注意了……我们还能把这个函数用在一个更复杂的函数里。我们来写一个每次玩家打完一关都会调用的函数，叫 LevelFinished（关卡结束）。它需要知道剩下几个继电器、这是第几关，以及当前分数，这些值都得传进去。在函数里，我们用 CalcBonus 函数算出奖励分，加到累计分数上。另外，如果当前分数比游戏的最高分还高，就把新的最高分和玩家名字存起来。

现在变得相当花哨了：函数调用函数，再调用函数！当我们只写一行这样的代码时，复杂性都被隐藏了。我们看不到里面所有的循环和变量，只看到结果像变魔术一样返回来……总分 53。但这不是魔术，这是抽象的力量！

右边是"调用栈"：每调用一个函数就压上一层（橙框是正在执行的那层），它有自己的一套变量；RETURN 时这一层弹出，结果交回给下面那层

"调用栈"这个词 课程没有用这个词，但右边那列框就是它：函数被调用时，计算机给它分配一块空间放参数和局部变量，压在"栈"顶；返回时弹出。你在浏览器 DevTools 里打断点时看到的 Call Stack 面板，就是这个东西。第 14 集讲数据结构时会正式介绍"栈"。
第 7 节

模块化与库

如果你理解了这个例子，你就理解了函数的力量，以及现代编程的全部精髓。比如，把一个网页浏览器写成一长串巨大的语句是不可行的：那会有几百万行，没人能看懂！所以，软件是由成千上万个更小的函数组成的，每个负责不同的功能。在现代编程中，很少见到超过 100 行左右的函数，因为到了那个长度，很可能有些东西应该抽出来做成自己的函数。

把程序模块化成函数，不仅让一个程序员能独自写出整个 App，也让团队能高效地合作开发更大的程序：不同的程序员写不同的函数，只要每个人都确保自己的代码正确，拼在一起时整个程序也应该能正常工作！

而在现实中，程序员不会浪费时间去写指数这种东西。现代编程语言自带大量预先写好的函数，叫库（library）。它们由专家编写，经过优化和严格测试，然后提供给所有人使用。几乎什么都有库，包括网络、图形和声音——这些主题我们以后会讲。但在此之前，我们得先讲讲算法。好奇吗？你应该好奇！下周见。

在 JavaScript 里 算指数你只会写 2 ** 44 或 Math.pow(2, 44)——Math 就是语言自带的库。你用的 Vue、npm 上的各种包，也是"别人写好、测好、拿来就用"的函数集合。

合上页面，试着回答

1. relays = relays + 1 为什么不矛盾？relays 原来是 3，执行后是多少？
"=" 是赋值，不是数学里的"相等"。先算右边：3 + 1 = 4，再把 4 存回 relays，覆盖旧值。执行后是 4。
2. while 循环和 for 循环有什么区别？
while 由条件控制：每次先测条件，为真就再来一遍，可能一直重复下去。for 由次数控制：计数变量从起点走到终点，每次 NEXT 加 1，到了就停。
3. 把指数代码做成函数有什么好处？
不用到处复制粘贴、改变量名；发现 bug 只改一处；调用的地方只写一行 Exponent(2, 44)，看不到里面的循环，代码更好懂。这是又一层抽象。
4. 调用 LevelFinished(2, 3, 45) 时，函数是按什么顺序被调用和返回的？
LevelFinished 调用 CalcBonus，CalcBonus 调用 Exponent；Exponent 先返回（2³ = 8），CalcBonus 拿到 8 返回，LevelFinished 把 45 + 8 = 53 返回。后调用的先返回——这正是"栈"的特点。
