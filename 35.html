第 0 节

"拍照"不等于"看懂"

嗨，我是 Carrie Anne，欢迎收看计算机科学速成课！今天，我们先来想想视觉有多重要。大多数人要靠视觉来做饭、绕开障碍、读路牌、看这样的视频，还有成百上千件别的事。视觉是带宽最高的感官，源源不断地提供关于世界状态、以及如何对它采取行动的海量信息。正因如此，半个世纪以来，计算机科学家一直在设法让计算机拥有视觉，由此诞生了计算机视觉（computer vision）这个子领域。它的目标是让计算机能够从数字图像和视频中提取出高层次的理解。

每个用过数码相机或智能手机的人都知道，计算机已经非常擅长以惊人的保真度和细节拍下照片——事实上比人类强得多。但正如计算机视觉教授李飞飞最近说的："就像'听到'不等于'听懂'，'拍照'也不等于'看见'。"

复习一下：计算机上的图像，最常见的存储方式是一个由像素组成的大网格。每个像素由一种颜色定义，这个颜色存成三种加色三原色——红、绿、蓝——的组合。通过组合这三种颜色的不同强度，我们可以表示任何颜色，这叫 RGB 值。

第 1 节

最简单的算法：颜色跟踪

也许最简单的计算机视觉算法——也是个很好的起点——是跟踪一个有颜色的物体，比如一个亮粉色的球。我们要做的第一件事是记下球的颜色。为此，我们取最中心那个像素的 RGB 值。存好这个值后，就可以给程序一张图片，让它找出颜色最接近的像素。这样的算法可以从右上角开始，逐个检查每个像素，计算它和目标颜色的差异。看完每个像素后，最匹配的那个，很可能就是球上的一个像素。

我们不只能在一张照片上跑这个算法，还可以在视频的每一帧上跑，从而随时间跟踪这个球。

动手：在球场上找粉色的球

这张"照片"只有 160×100 个像素，放大了给你看。橙色十字是算法找到的最接近目标颜色的像素；播放视频时，青色轨迹是每一帧找到的位置。

当然，由于光照、阴影和其他因素的变化，球场上那个球几乎不可能和我们存的目标 RGB 值完全一样，只是最接近而已。在更极端的情况下，比如夜场比赛，跟踪效果可能会很差。而如果某一队的球衣和球用了同样的颜色，我们的算法就会彻底晕掉。由于这些原因，除非环境能被严格控制，颜色标记跟踪这类算法很少被使用。

（字幕把"右上角"译成了"左上角"。从哪个角开始其实无所谓，反正每个像素都要看一遍。本页的演示就按原文从右上角开始扫。）

"颜色差异"怎么算 最直接的是把 RGB 当成三维空间里的点，算两点距离：√((R₁−R₂)² + (G₁−G₂)² + (B₁−B₂)²)。它的毛病你在夜场里已经看到了：整体变暗时，粉色球的三个数一起变小，离"亮粉色"反而比白色场地线还远。实际中常把颜色换成 HSV（色相、饱和度、明度）来比，主要比"色相"，对明暗变化就没那么敏感——但影子、反光、同色球衣，照样会让它出错。
第 2 节

核与卷积：找出边缘

颜色跟踪的例子可以逐个像素地搜索，因为颜色就存在单个像素里面。但这种方法对大于一个像素的特征就不管用了，比如物体的边缘，它天生就是由很多像素组成的。为了在图像中识别这类特征，计算机视觉算法必须考虑一小块区域的像素，这叫块（patches）。

举个例子，我们来讲一个在场景中找垂直边缘的算法，比如用来帮助无人机安全穿过一片障碍物。为了简单起见，我们把图像转成灰度，不过大多数算法也能处理彩色。现在放大其中一根杆子，近距离看看边缘是什么样的。我们可以很容易地看出杆子的左边缘从哪里开始，因为那里有一个在垂直方向上贯穿很多像素的颜色变化。

我们可以更正式地定义这个现象，写一条规则：一个像素是垂直边缘的可能性，等于它左边一些像素和右边一些像素之间颜色差异的大小。这两组像素的颜色差异越大，这个像素越可能在边缘上。如果颜色差异很小，它大概根本不是边缘。

这个操作的数学写法是这样的，它叫核（kernel）或过滤器（filter）。它包含逐像素相乘用的数值，乘积的总和存进中心像素。我们来看看它对例子中的像素怎么起作用。我已经把所有像素都标上了灰度值。现在拿着核，把它的中心对准我们关心的像素。核指定了下面每个像素该乘以什么。然后，我们把所有这些数加起来。在这个例子里，结果是 147。这就成了我们的新像素值。这种把核应用到一块像素上的操作，叫卷积（convolution）。

这是杆子左边缘附近放大的一小块（数字是灰度值，越大越亮）。点任意一个不在最外圈的像素，把核的中心对准它。

现在我们把核应用到另一个像素上。这次的结果是 1，只有 1。换句话说，颜色差异非常小，不是边缘。如果把核应用到照片里的每个像素，结果就像这样：像素值最高的地方，就是有强烈垂直边缘的地方。注意，水平的边缘，比如背景里的那些平台，几乎看不见了。如果想突出那些特征，就得用另一个核——对水平边缘敏感的核。这两个增强边缘的核都叫 Prewitt 算子（Prewitt Operators），以发明者的名字命名。

这只是海量核里的两个例子，核可以做很多种不同的图像变换。比如，这个核能锐化图像，这个核能模糊图像。

你每天都在用卷积 CSS 的 filter: blur(4px)、手机修图里的"锐化"滑块、视频会议的背景虚化，底层都是拿一个核在图像上滑一遍。模糊核把周围像素平均一下，于是细节被"抹平"；锐化核是"自己 × 5，减去上下左右"，放大了和邻居的差别。核越大，模糊得越厉害，计算量也越大——所以 GPU 很适合干这个：每个像素的计算互不相干，可以同时做。
第 3 节

用核找形状：Viola-Jones 人脸检测

核也可以像小小的图像饼干模具一样使用，只匹配特定的形状。我们的边缘核找的是从右到左、或从上到下有强烈差异的像素块。但我们也可以做出擅长找线的核——两边都有边缘的线；甚至能找出被对比色包围的像素小岛。这类核可以开始描述简单的形状。

比如在人脸上，鼻梁往往比鼻子两侧更亮，所以对线敏感的核在这里的值会更高。眼睛也很有特点——一个暗色的圆，被更亮的像素围着——也有其他的核对这种模式敏感。当计算机扫描一张图片时（最常见的方式是滑动一个搜索窗口），它可以寻找那些表明这是一张人脸的特征组合。虽然每个核单独来看都是个很弱的人脸检测器，但组合起来就可以相当准确。如果不是一张脸，一堆像脸的特征恰好聚在一起的可能性不大。这就是一个早期且很有影响力的算法——Viola-Jones 人脸检测——的基础。

动手：滑动窗口找人脸

图里有一张简笔脸，还有几个"捣乱的"：一只孤零零的眼睛、一对像眼睛的圆点、一条亮线、一个空白椭圆。窗口在每个位置用 4 个弱检测器打分。你也可以直接点图片，把窗口放到任意位置看看。

Viola-Jones 为什么那么快 2001 年的这个算法用的"核"是一些黑白相间的矩形（叫 Haar 特征），比如"上面一条暗、下面一条亮"对应眼睛和脸颊。它有两个妙招：一是"积分图"，预先算好一张累加表，之后任意矩形的像素和都只要做 4 次加减；二是"级联"，先用两三个最便宜的特征快速排除掉绝大多数明显不是脸的窗口，只有过了关的窗口才接受更多特征的检查。于是它能在 2000 年代初的普通电脑和数码相机上实时找脸——相机取景框里那个跟着脸走的小方框，很长一段时间都是它的功劳。
第 4 节

卷积神经网络

如今最热门的新算法是卷积神经网络（Convolutional Neural Networks）。如果需要复习，上一集我们讲过神经网络。简单说，人工神经元——神经网络的基本构件——接收一系列输入，把每个输入乘以一个特定的权重，然后把这些值全部加起来。这听起来应该有点耳熟，因为它很像卷积。事实上，如果我们给神经元输入的是二维的像素数据，而不是一维的输入列表，那它就和卷积一模一样。输入权重就相当于核里的数值。但和预先定义好的核不同，神经网络可以自己学出有用的核，用来识别图像里有意思的特征。

卷积神经网络用成组的这种神经元来处理图像数据，每个神经元输出一张新图像，本质上是被不同的、学出来的核"消化"过的。这些输出再被后续几层神经元处理，于是就有了卷积之上的卷积之上的卷积。

最开始的第一个卷积层可能会找到边缘这样的东西，因为正如我们讨论过的，单次卷积就能识别出这些。下一层可能有一些神经元，在这些边缘特征上做卷积，识别出由边缘组成的简单形状，比如角。再往上一层，可能在这些角特征上做卷积，包含能识别简单物体的神经元，比如嘴巴和眉毛。就这样不断进行下去，复杂度一层层累积，直到某一层做一次卷积，把所有东西拼在一起：眼睛、耳朵、嘴巴、鼻子，全套齐活，然后说："啊哈，这是一张脸！"

卷积神经网络不一定要有很多层，但通常都有很多层，以识别复杂的物体和场景。这就是为什么这项技术被看作深度学习。Viola-Jones 和卷积神经网络都可以用于人脸之外的很多图像识别问题，比如识别手写文字、在 CT 扫描里发现肿瘤、监测道路上的车流。不过我们还是接着说人脸。

李飞飞和 ImageNet 开头那句"拍照不等于看见"的李飞飞，带领团队建了 ImageNet：一千多万张人工标注过的图片，分成上万个类别。2012 年，一个叫 AlexNet 的卷积神经网络在 ImageNet 识别比赛中把错误率大幅拉低，用的正是 GPU 训练——这常被看作深度学习浪潮的起点。上一集说的"标记数据"有多重要，这就是一个例子。
第 5 节

面部标志点：从"有张脸"到"读出表情"

不管用的是什么算法，一旦我们在照片里把一张脸分离出来，就可以用更专门的计算机视觉算法来精确定位面部标志点（facial landmarks），比如鼻尖和嘴角。这些数据可以用来判断很多事情，比如眼睛是不是睁着——有了标志点，这就很简单了，不过是点和点之间的距离而已。我们也可以跟踪眉毛的位置：眉毛相对于眼睛的位置，可以表示惊讶或者高兴。根据嘴部标志点的形状，检测微笑也相当直接。

动手：用标志点读表情

橙色点是标志点，虚线是算法量的距离。右边的"判断"只是几条按距离写的 if 规则，真实的情感识别算法复杂得多，但用的原料就是这些点。

所有这些信息都可以交给情感识别算法来解读，让计算机能推断你是开心、忧伤、沮丧还是困惑等等。反过来，这又能让计算机聪明地调整自己的行为……比如在你困惑时给些提示，在你沮丧时别弹窗让你装更新。这只是视觉让计算机具备情境感知能力——也就是感知周围环境——的一个例子。不只是物理环境，比如你是在上班还是在火车上；还有社交环境，比如你是在正式的商务会议上，还是在朋友的生日派对上。你在这些环境里的举止不一样，计算设备如果够聪明，也应该如此。

面部标志点还捕捉了你脸的几何形状，比如两眼之间的距离、前额的高度。这是一种生物识别数据，让带摄像头的计算机能认出你。不管是手机看到你就自动解锁，还是政府用监控摄像头追踪人，人脸识别的应用似乎无穷无尽。最近在手部和全身的标志点跟踪上也有突破，让计算机能解读用户的肢体语言，以及他们对着联网微波炉疯狂比划的是什么手势。

两个要记住的点 ① 第 31 集说过，生物识别数据的问题是没法重设：密码泄露了可以换，脸的几何特征泄露了不行。所以人脸数据比一般数据更需要谨慎保存，很多国家和地区对它有专门的法律限制。② 作为前端，你现在就能在浏览器里玩这些：navigator.mediaDevices.getUserMedia() 拿到摄像头画面，再用 Google 的 MediaPipe 之类的库在页面里实时算出几百个面部、手部标志点——计算都在用户自己的设备上完成，画面不必上传。
第 6 节

视觉的抽象层次

正如这个系列里多次说过的，抽象是构建复杂系统的关键，计算机视觉也一样。在硬件层面，工程师在造越来越好的摄像头，让计算机的视力一年比一年好——这一点我自己可做不到。用摄像头的数据，计算机视觉算法处理像素，找出脸和手这样的东西。然后，用这些算法的输出，还有更专门的算法来解读用户的表情和手势之类的东西。在此之上，有人在打造全新的交互体验，比如能响应手势和情绪的智能电视、智能辅导系统。每一层都是活跃的研究领域，每年都有突破。而这只是冰山一角。

如今计算机视觉无处不在——无论是商店里扫描条形码、在红灯前等待的自动驾驶汽车，还是 Snapchat 里给你加上胡子的滤镜。而最令人兴奋的是，计算机科学家们其实才刚刚起步，超快的 GPU 这类计算技术的最新进展让这一切成为可能。拥有人类般视觉能力的计算机，将彻底改变我们和它们交互的方式。当然，如果它们还能听和说就更好了，这是我们下周要讨论的。到时见！

第 7 节

本集小结

概念要点
计算机视觉从图像和视频中提取高层次的理解；拍照 ≠ 看懂
颜色跟踪逐个像素找最接近目标 RGB 的；怕光照变化、怕同色物体，只适合严格控制的环境
块边缘之类的特征跨越很多像素，要一小块一小块地看
核 / 过滤器、卷积核对准一个像素，逐个相乘再求和，存回中心像素；对每个像素都做一遍就是卷积
Prewitt 算子分别突出垂直边缘和水平边缘的两个核；其他核能锐化、模糊
Viola-Jones滑动窗口 + 多个弱特征（鼻梁亮线、暗色眼睛……）组合，判断是不是脸
卷积神经网络神经元输入二维像素 = 卷积，权重就是核，但核是学出来的；层层卷积：边缘 → 角 → 五官 → 脸
面部标志点鼻尖、嘴角等点；点之间的距离能判断睁眼、惊讶、微笑，也能做人脸识别
抽象层次摄像头 → 找脸找手 → 解读表情手势 → 新的交互体验
  1. 1970Judith Prewitt 提出 Prewitt 边缘检测算子
  2. 2001Viola-Jones 人脸检测算法发表，能实时找脸
  3. 2009李飞飞团队发布 ImageNet 图像数据集
  4. 2012卷积神经网络 AlexNet 用 GPU 训练，在 ImageNet 比赛中大幅领先
一句话 计算机视觉的核心手法是卷积：拿一个小小的核在图像上逐个位置"乘了再加"，就能找出边缘、线条、暗色小岛这类局部特征；把很多弱特征组合起来就能认出人脸。卷积神经网络更进一步，让网络自己学出该用什么核，一层层从边缘拼到整张脸。找到脸后，再用标志点之间的距离读出表情。

合上页面，试着回答

1. 颜色跟踪算法是怎么找球的？为什么现实中很少用？
先记下球中心像素的 RGB 值，然后逐个像素计算和这个颜色的差异，最接近的那个像素很可能在球上；对每一帧都这样做就能跟踪。但光照、阴影会让球的颜色变化，夜里尤其差；场上有同色的东西（比如球衣）时算法会彻底混乱。所以只适合环境能严格控制的场合。
2. 垂直边缘核左列是 −1、中列是 0、右列是 1。它为什么能找出垂直边缘？为什么对水平的平台几乎没反应？
它算的是"右边三个像素之和 − 左边三个像素之和"，左右差别越大结果越大，正好对应一条竖着的明暗分界。水平边缘是上下有差别、左右差不多，左右两列相减几乎抵消，结果接近 0。要找水平边缘得把核转 90°，用上下相减的水平 Prewitt 核。
3. 卷积神经网络和上一集的人工神经元有什么关系？它比手工设计的核强在哪？
神经元把输入乘权重再求和；当输入是一块二维像素时，这就是卷积，权重就是核的数值。区别是手工核要人来设计，而卷积神经网络的核是从标记数据里学出来的，而且可以一层叠一层：先学边缘，再在边缘上学角，再学五官，最后认出整张脸。
4. 找到人脸以后，怎么判断一个人的眼睛是不是睁着？
用面部标志点算法定位眼睛上下眼睑的点，然后量这两个点之间的距离：距离大就是睁着，接近 0 就是闭着。类似地，眉毛到眼睛的距离、嘴角相对嘴中间的高低，可以用来判断惊讶、微笑等表情。
